# Hominal.cc

Hominal.cc 是一个极简的成人级高级认知生命创生实验项目，目标是在真实有限的 Ubuntu 身体中，以 Proto-Hominal（候生体）为 G0 形态，构造能够持续产生意识表现行为、内生张力、具身行动、个人连续性并接受现实后果修正的认知组织。

G0 阶段一至阶段七及 7.1 已完成。当前工程基线已经在真实 Ubuntu 身体中通过一小时运行，形成“内生张力—注意—行动意愿—现实结果—经验与方法更新”的连续闭环；下一步讨论阶段八“自生关切与叙事自我成长”。设计基线和阅读顺序见 [docs/README.md](docs/README.md)，可编码契约见 [G0 最小架构](docs/mvp-architecture.md)，当前实施路线见 [创生实验计划](docs/genesis-plan.md)。制定新实验或调整认知内核以前，先阅读 [项目研究记忆](lineage/research-memory.md)，避免重复已经证伪的结构。
