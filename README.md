# Hominal.cc

Hominal.cc 是一个极简的成人级高级认知生命创生实验项目，目标是在真实有限的 Ubuntu 身体中，以 Proto-Hominal（候生体）为 G0 形态，构造能够持续产生意识表现行为、内生张力、具身行动、个人连续性并接受现实后果修正的认知组织。

当前项目处于 G0 阶段一“创生契约与架构冻结”。设计基线和阅读顺序见 [docs/README.md](docs/README.md)，可编码契约见 [G0 最小架构](docs/mvp-architecture.md)，研究对象、Ubuntu 身体、agent 生命卷、Genesis Lab、代际档案与恢复体系见 [项目架构](docs/project-architecture.md)。

## Development

This repository is synchronized to its development server with Mutagen.  The
local configuration is stored one directory above the repository in
`xconfig.yaml` and is intentionally not committed.
