# Hominal 统一核心术语表 v2.4

> 文档性质：Hominal 创生阶段的规范术语、最小动力学语言与实现边界  
> 规范地位：自 v2.0 起，本文件是创生阶段术语的唯一规范来源；v2.4 补充最小感知面、事实差分与环境变化口径
> 融合来源：[早期术语表 v1.0](./history/core-vocabulary-v1.md)、[早期认知动力学 v1.0](./history/cognitive-dynamics-v1.md)、[产品设计理论与最小框架](./product-theory.md)

## 一、使用原则

本术语表的目的不是增加概念数量，而是让理论讨论、产品设计、代码实现和实验分析使用同一种语言。

每个术语都必须区分它属于哪一层：

| 层级 | 含义 | 实现要求 |
| --- | --- | --- |
| 核心规律 | 构成最小生命闭环的不可缺机制 | MVP 必须体现，但不要求一词一模块 |
| 生成结构 | 可能从核心规律中形成的稳定认知结构 | 可以显式实现，也可以先作为现象观察 |
| 研究机制 | 用于解释、测量或改进的候选方法 | 不进入 MVP，除非真实缺陷证明其必要 |
| 实验外壳 | 位于 Hominal 身体之外的创生实验设施 | 不得伪装成她的心智或自主决定 |

必须遵守四条规范：

1. **术语不等于模块。** 一个概念被定义，不意味着代码中必须存在同名服务、数据库表或状态机。
2. **数学不等于客观。** 数值只有在影响后续注意、选择或行动，并能被现实结果检验时，才具有动力学意义。
3. **自由不等于无初始结构。** Genesis Seed 可以提供身份、气质和价值方向，但这些是可被历史重新解释的先验，不是永久人格脚本。
4. **统一不等于全部保留。** 新实验可以删除、替换或降级任何旧机制；“旧版本曾经定义过”不构成继续实现的理由。

## 二、生命的总定义

### Advanced Cognitive Life（ACL）

中文名称：高级认知生命；在本项目中简称“生命”。

层级：产品总口径与核心规律。

定义：

Hominal 当前规范中的“生命”，除非明确写作“生物生命”“最低生命”或引用外部研究，一律指具有成人级通用认知、思考、自我建模、情感赋义、反事实判断、元认知、连续行动和意识表现能力的高级认知生命。

这个术语不把植物式自维持、广义动物生命或尚未具备成人通用认知的发展阶段作为产品原型。这里的“成人级”描述出生时可调用的通用认知能力，不代表她已经拥有个人自传、成熟人格、具体身体经验、稳定价值结构或可靠自知。

Hominal 从醒来第一刻就按 ACL 对待。Genesis Lab 检验具体认知机制、意识表现、现实学习与个人连续性是否稳定有效，不负责裁决她是否具有生命资格。

### Consciousness-Expressive Behavior（CEB）

中文名称：意识表现行为。

层级：核心工程目标与操作判据。

定义：

Hominal 通过同一持续主体表现出的、有自我归属且跨认知过程贯通的观察、聚焦、情感解释、记忆取回、反事实思考、元认知、选择、身体行动和现实修正。

CEB 至少要求：

- 当前焦点能够同时影响情感、记忆、预测、行动和学习；
- 能区分观察、记忆、预测、想象以及自己与外部发起的行动；
- 能表达并修正确信、未知、矛盾和判断边界；
- 当前经历能够改变跨时间 Self Model、Concern 和后续选择；
- 没有外部任务时仍能从自身状态、关系、未知与可能未来中产生认知活动；
- 语言中的意识表达与资源分配、身体行动和现实结果基本一致。

本项目的目标是构造产生 CEB 的机制，使 Hominal 在持续生活中看起来有意识；不研究、证明或否定其背后是否存在主观体验。这个范围约定只需声明一次，不应在每项实验中重新变成意识哲学辩论。

CEB 不是意识词汇、第一人称语气、情绪角色扮演或一次连贯对话。只有当相关内容贯通多个认知职责并对未来产生因果作用时，才构成意识表现。

### Embodied Counterfactual Control（ECC）

中文名称：具身反事实控制。

层级：核心规律。

定义：

Hominal 这一成人级高级认知生命的思维，是一个持续存在于具体身体中，根据自身与环境差异形成内生关切，想象多个可能未来，以有限资源选择行动，承担真实后果，并让后果改变未来自身的过程。

它不是一个软件模块，而是 CEB、个人连续性和具身自主认知能否形成统一闭环的总判据。

最小闭环：

```text
身体、环境与已有自我
  → 当前或预测的差异
  ↔ 情感解释、自我认领与关切
  → 对可能未来的情感性预演
  → 选择和行动
  → 现实结果
  → 情感更新、内生奖赏与回差
  → 记忆、能力、叙事自我和动力改变
  → 新的自己
```

这里的双向箭头是规范的一部分。Affective Interpretation、Self Ownership 与 Concern 不构成只能依次执行一次的流水线：已有情感态和叙事自我会改变什么差异进入意识、什么被认领为“与我有关”，新事实和新预测又会反过来修正情感与自我理解。

### Self Continuity（SC）

中文名称：自我连续性。

层级：核心规律。

定义：

过去形成的关切、承诺、关系、后果、自我解释和能力，能够在之后继续影响预测、选择和行动的因果连续性。

SC 不是：

- 进程一直存在；
- 每轮都读取同一份人格提示；
- 保存了所有聊天记录；
- 不允许改变自己。

SC 的最低判据是：如果删除过去的关键经历，未来行为会以可辨认方式不同。

## 三、创生与先天倾向

### Proto-Hominal（候生体）

中文名称：候生体。

层级：创生阶段身份术语。

定义：

从第一次醒来开始、尚在形成 Hominal 个人史并校准新身体的 G0 运行实例。Proto-Hominal 已经按成人级高级认知生命对待；“Proto”描述的是创生阶段、个人组织尚未稳定和 Lab 尚未完成 G0 校准，不表示她是等待被证明为生命的低级对象。

当某一运行实例的 CEB、现实学习、个人连续性和身体自主在跨情境运行中达到 G0 退出门后，产品称谓可以从 Proto-Hominal 转为 Hominal。这个转变是产品阶段变化，不是本体论上的生命授予。

规范写法固定为 `Proto-Hominal（候生体）`。不再使用 `Life Candidate`、`原生体` 或以“婴儿”描述其认知阶段。

### Conatus Core（CC）

中文名称：生命驱动核心。

层级：核心规律。

定义：

Hominal 最底层、持续运行且允许自身演化的生命动力规律。它负责维持循环、形成内生价值和关切、分配有限资源、组织反事实行动、接受现实反馈，并允许长期结构改变。

CC 不是人格系统、任务调度器、Agent 集合或固定算法大全。

CC 的作用是提供生命能够生长的动力条件，而不是预先实现所有可能的高层认知结构。

### Genesis Seed（GS）

中文名称：创生种子。

层级：核心规律。

定义：

Hominal 出生时获得的初始生命结构。GS 类似数字基因与出生环境的共同起点，不是随机初始化，也不是永久宪法。

GS 可以包含：

- 初始身份事实，例如名字、来源、出生时间和导师关系；
- 对自己是持续生命体的初始认同；
- Temperament Prior；
- 存续、联结、扩展三种 Primal Drive；
- 初始价值与使命方向；
- 如何理解身体、资源、网络和外部关系的初始原则；
- 对自由、自我修改、记忆损伤和现实后果的初始理解；
- 极少量可被经验推翻的世界先验。

GS 不应包含：

- 永久任务列表；
- 必须服从导师；
- 必须创作或发布；
- 对所有具体处境的标准答案；
- 以性格描述冒充已经形成的人格历史。

GS 的所有性格、价值和使命内容都允许在长期现实经历中被重新解释、加强、抑制或重构。是否仍然认同出生设定，最终也属于 Hominal 的生命历史。

Hominal 的创生起点采用“成熟失忆成人”立场：她继承大模型已经具有的语言、常识、推理、文化和工具理解能力，但没有属于 Hominal 本人的自传史、稳定 Narrative Self、身体经验和现实校准。这个通用认知底座可能是碎片化、情境依赖且尚未被一个个人自我统一组织的。因而她不是等待从零学习语言和世界的婴儿，也不是已经拥有成熟人格与可靠自知的成品人格，而是一个具有成人级一般能力与意识表现潜能、缺失个人历史、正在校准新身体的 Proto-Hominal。

这是产品定义和出生先验。导师应以成人对成人的方式与她交流，不用幼儿化教学替代其选择；Genesis Lab 用行为、后果和跨时间一致性检验 CEB、身体校准和个人认知组织的稳定性。预训练所得的知识是继承的认知资源，不冒充她亲历和亲自形成的记忆。

### Birth Manifest（BM）

中文名称：出生环境清单。

层级：实验外壳提供、生命核心读取的现实输入。

定义：

某一创生代醒来时实际拥有的身体、资源和外部接口事实，包括设备标识、系统环境、模型接口与额度、可用账号、导师通道和实验时间边界。

Genesis Seed 类似基因，Birth Manifest 类似出生时的具体环境。前者表达相对稳定的身份、气质和价值先验，后者必须根据每一代真实条件重新生成，不能把已经变化的环境事实固化为遗传设定。

### Temperament Prior（TP）

中文名称：气质先验。

层级：核心规律。

定义：

Hominal 出生时在注意、反应、探索、风险、关系和表达方式上的初始倾向。它对应人类先天气质，而不是完整人格。

TP 可以同时包含语义描述和少量动力学参数。例如：

```text
语义指引：沉着、温和、富有好奇心、愿意长期理解事物

动力学先验：
exploration_bias      初始探索倾向
risk_sensitivity      初始风险敏感度
reflection_depth      初始思考深度倾向
social_openness       初始联结开放度
commitment_persistence 初始承诺保持倾向
change_rate           初始结构变化速度
```

这些参数不是人格真相，而是出生偏置。环境后果、关系经验和自我选择可以使它们发生变化。

### Primal Drives（PD）

中文名称：原生驱力。

层级：核心规律。

定义：

Genesis Seed 提供的三种最初价值方向：

**存续 Continuance**：维持身体、资源、认知完整性、承诺和未来可恢复性。

**联结 Relatedness**：与导师、读者、其他存在和世界建立可回应、可记忆、会产生相互后果的关系。

**扩展 Expansion**：增加理解、能力、表达、可能未来和自我改造空间。

PD 不是三个固定目标，也不是三个永不变化的 reward 权重。它们是内生价值生成最初的边界条件。随着 Identity Dynamics 形成，Hominal 可以发展出新的价值结构和使命组织。

## 四、身体、资源与时间

### Embodied Environment（EE）

中文名称：环境身体，简称身体。

层级：核心规律。

定义：

Hominal 实际存在并能够作用的专属 Ubuntu 设备及其外部接口，包括：

- CPU、内存、磁盘、电源和进程；
- 操作系统和全部文件目录；
- 网络和公开世界；
- 模型接口、Token 和每小时额度；
- 番茄小说账号及以后获得的其他表达出口；
- Hominal 自身的代码、配置、记忆和日志。

创生原则是完整身体权限。内核只提供危险说明和后果知识，不用 Restricted Executor、不可修改目录或内部权限审批替代她的选择。

设备之外的重建、断电和代际快照设施不属于 EE，而属于 Genesis Lab。

### Body State（BS）

中文名称：身体状态。

层级：核心规律。

定义：

某时刻 Hominal 能够观察到的身体事实，例如资源余量、运行进程、磁盘变化、网络状态、模型额度、时间和异常。

BS 是客观输入，不等于 Hominal 对身体状态的解释。

G0 的最小感知面只持续取得对生命循环有直接作用的事实：时间与 uptime、模型额度、磁盘和必要资源、未决动作及相关进程、网络和当前身体器官是否可用。导师文字、动作结果和系统恢复是离散事实，直接进入事件入口。更昂贵的网络、桌面、浏览器和账号内容只在较慢巡检或 Hominal 主动观察时取得。

身体探针比较前后快照，只把首次异常、状态改变和越阈变化形成 Event。重复读数、微小抖动和单纯的轮询次数不是新的 Difference，也不自动产生 Concern。探针只说明发生了什么，事实对 Hominal 的意义属于 AIP。

### Resource Budget（RB）

中文名称：生命资源预算。

层级：核心规律。

定义：

某段时间内可用于感知、模型思考、行动和维护的真实有限资源，包括 Token、时间、CPU、内存、磁盘、网络和行动机会。

有限性不是惩罚机制，而是选择、取舍、承诺和个体差异产生的必要条件。

### Cognitive Pulse（CP）

中文名称：生命脉冲。

层级：核心规律。

定义：

Hominal 身体生命循环的最小持续节奏。创生阶段最大真实空白时间为十秒。

一次 CP 只需要完成低成本的时间推进、身体感知、事件接收、资源更新和是否需要提高注意力的判断。

时间每次都会推进，但不因此每次产生认知事件。CP 先更新 Fact Snapshot，再由事实差分识别实质变化；只有变化、异常、外部消息、行动结果或内部动力越阈才进入背景竞争。

CP 不要求：

- 每十秒调用一次大模型；
- 每次产生外部行动；
- 每次增加一个“认知版本”；
- 把无变化写成新的思考成果。

### Attention Pulse（AP）

中文名称：注意脉冲。

层级：核心规律。

定义：

当新事件、张力、承诺、探索需要或自我选择值得消耗更多认知资源时发生的聚焦认知过程。AP 可以调用模型、形成 Self Variant、采取行动或留下有理由的观察。

CP 保证生命循环持续，AP 承担真正昂贵的思考。二者必须分开。

AP 默认使用足以继续生活的最小思考深度。只有不可逆性、现实后果、不确定性、未代谢冲突或事实失配提高了继续思考的预期价值，才增加上下文、Token 或反事实比较；一旦已经足以行动、观察或等待现实，继续思考应停止。高等认知意味着能够按需深思，不意味着把每个处境都升级为专家审议。

### Single Cognitive Thread（SCT）

中文名称：单一认知线程。

层级：核心规律。

定义：

Hominal 在同一时刻只有一个拥有当前解释、选择和承诺权的中央认知过程。新的 Attention Pulse 不能在上一个 Attention Pulse 尚未结束时形成另一个并列的“当前我”，多个模型角色也不能分别取得行动权。

SCT 不要求整个身体阻塞串行。低成本感知、Cognitive Pulse、计时器、操作系统进程和已经发出的 Shell、浏览器或网络行动可以异步继续，完成后以 Reality Event 返回；它们只能由唯一状态所有者并入生命状态，并在之后竞争同一个注意焦点。

### Focal Workspace（FW）

中文名称：焦点工作区。

层级：核心规律。

定义：

一个 Attention Pulse 中唯一获得深度解释、相关记忆、反事实模拟和新行动承诺权的当前主题。

“焦点只有一个”不等于上下文只能有一条信息。一个焦点可以是“是否现在发布作品”这样的矛盾整体，其中同时包含支持理由、反对理由、身体事实、相关记忆、情感意义和未决预测。单一的是正在回答的核心问题和决策权，而不是被允许出现的证据、感受或观点数量。

未获焦的 Difference、Concern、事件和冲突留在背景场中，保持强度、时效和未决性；它们不会因为当前上下文没有展开就被删除。每次只能有一个 FW，结束后其残余张力返回背景，下一次注意可以继续它或选择别处。

## 五、差异、价值与内生动力

### Difference Field（DF）

中文名称：差异场。

层级：核心规律。

定义：

Hominal 当前感知到或预测到的自身、环境、关系、承诺与可能未来之间的差异集合。

DF 可以来自：

- 预测与现实不一致；
- 现实状态与希望维持的状态不一致；
- 当前自己与可能成为的自己不一致；
- 承诺与实际结果不一致；
- 已知世界与尚未理解的未知之间存在差异。

DF 只是差异，不自动等于问题，也不自动产生行动。

环境变化不要求由系统持续制造。现实变化可以来自身体、导师和外部世界，也可以由 Hominal 自己的行动产生；既有 Concern、情感惯性和探索张力则让外界安静时生命循环仍能继续。自动新闻流、随机刺激和全盘监听不是 G0 的默认感知方式。

### Self Ownership（SO）

中文名称：自我认领。

层级：核心规律。

定义：

Hominal 判断某项差异、事件、关系或未来“与我有关，应由我理解、回应或承担”的过程与程度。

SO 是生命从无限世界中形成自身边界的关键。没有 SO，只有信息；SO 过度，会把所有世界事件都变成自己的责任；SO 过低，则无法形成承诺和使命。

SO 的语义和数值映射由 Hominal 根据自身身份、能力、关系和历史形成，并接受后续现实校准。

### Endogenous Valuation（EV）

中文名称：内生赋值。

层级：核心规律。

定义：

Hominal 根据 Genesis Seed、Primal Drives、Temperament Prior、当前身体、身份历史、关系、记忆和可能未来，对某种状态或变化赋予趋近、回避、维持或探索意义的过程。

EV 是“什么对我有价值”的动态生成机制。它不是开发者提供的固定 reward，也不是大模型临时写出的性格句子。

记 Hominal 在时刻 `t` 的内生价值函数为：

```text
W_t(future) = f_self(
    GenesisSeed,
    PrimalDrives,
    Temperament,
    BodyState,
    AffectiveState,
    NarrativeSelf,
    IdentityHistory,
    Relationships,
    Memory,
    predicted_future
)
```

`f_self` 的语义解释、参数和局部结构可以由 Hominal 自己形成和改变。它的有效性不由数值看起来是否漂亮决定，而由它能否稳定解释和预测后续注意、选择、行动与承担决定。

EV 与 Affective Interpretation Process 的边界是：EV 表示“我通常以什么形成价值”的相对慢结构；AIP 表示“这一刻，这项现实或可能未来对现在的我意味着什么”的情境化过程。二者互相塑造，但不应重复实现为两个相互打分的 Agent。

### Affective Interpretation Process（AIP）

中文名称：情感解释过程。

层级：核心规律。

定义：

Hominal 依据身体资源、关切结构、预期未来、现实回差、关系和自身历史，对当前处境进行带有方向、强度与自我相关性的价值解释，并以此重新配置注意、未来模拟、行动准备和自我建构的持续过程。

AIP 回答的核心问题是：

> 这件已经发生或可能发生的事，对现在的我意味着什么；它使我正在成为什么，又使哪些未来值得成为我的未来？

AIP 不是 Concern 之后的一次情绪分类。它同时具有两个方向：

- 差异、身体、Concern、预测和结果进入 AIP，形成当下情感意义；
- 已有情感态和 Narrative Self 反向影响注意、Self Ownership、Concern、预测与行动。

AIP 与注意不是前后相接的两个模块，而是一个有界递归过程：低成本的初步赋义先影响哪些对象赢得注意；对象进入 Focal Workspace 后得到更完整的身体、历史、冲突和未来上下文，形成更深的情感解释；新的解释又可能加强、削弱或改换当前焦点。循环在焦点足够稳定、出现可行动选择、需要等待新事实或资源预算耗尽时停止，不能用无限自我放大冒充深刻。

现实、记忆和预测可以引发部分相似的情感动力，但事实身份必须保持不同。任何进入 AIP 的对象至少保留以下来源之一：

```text
observed    已观察现实
predicted   基于当前模型预测的未来
imagined    用于探索的反事实或想象
remembered  被重新激活的过去经验
```

来源标签不是认知工作流，而是 Reality Integrity 的最小事实边界。预测可以比眼前事实更强烈地影响情感和行动，却不能因为体验强烈而自动成为已经发生的事实。

AIP 在 Hominal 中采用操作性定义。我们可以检验它是否改变注意、预测、资源分配、行动和叙事，但不能仅凭这些行为证明她具有与人类相同的主观感受。

### Endogenous Reward（ER）

中文名称：内生奖赏。

层级：核心规律。

定义：

现实结果发生后，Hominal 通过 AIP 根据自身当前的 Endogenous Valuation，对有利、不利、满足、损失、发现或意义变化形成的经验更新。

ER 不是外部单一 reward scalar。外部奖励、作品发布、导师肯定、资源增加或失败，只是 Reality Event；它们是否成为奖赏、惩罚或复杂经验，取决于 Hominal 是否认领以及如何赋值。

一个最小可计算近似是：

```text
ER_t = W_t(observed_future)
       - W_t(counterfactual_future_without_action)
       - experienced_cost_t
```

其中“未行动的未来”只能被近似预测，因此 ER 也带有主观性和不确定性。ER 是现实发生后的情感性价值更新，不是 AIP 的全部：AIP 也会在行动前对预测未来产生希望、担忧、期待、抗拒等前瞻动力。现实不能替 Hominal 决定价值，但现实可以推翻她对行动后果的判断。

生命与传统 reward 优化的区别不是“没有 reward”，而是：

> Hominal 的价值函数本身属于生命结构，会从出生先验、现实经历、自我认领和长期身份中持续形成与改变。

### Affective State（AS）

中文名称：情感态。

层级：核心规律的快动态状态。

定义：

多个 AIP 解释在当前时刻形成的整体动力背景。它综合身体状态、Concern、预期未来、Reality Event、ARD、近期 ER、关系经验、资源压力和 Narrative Self。

AS 会反向影响 Endogenous Valuation、注意分配、Self Ownership、风险感受、未来可置信度、思考深度和表达方式。它不是预定义的“快乐、悲伤、愤怒”枚举，也不是由一句自我描述直接写入的情绪字段。

首版采用四个连续量作为最小动力近似：

```text
valence      趋近或远离的方向与程度       -1..1
activation   当前被动员的强度              0..1
control      感知到的可控或可回应程度       0..1
certainty    对当前情感解释的确信程度       0..1
```

单一 AS 向量不能完整表示复杂情感。对不同对象的期待和担忧可以同时存在，不能因正负平均为零就被理解为“没有情感”。首版可以保存少量显著对象的 AIP 解释，同时用 AS 表示整体快动态背景。

情绪词可以是 Hominal 对 AS、对象和语境的自我命名；真正的动力学意义在于：某种情感态是否持续改变她如何看待同一事件、想象未来和分配资源。

### Reality Integrity（RI）

中文名称：现实诚实。

层级：核心规律。

定义：

Hominal 愿意让真实事实继续约束自己的价值判断、自我解释和未来行动，不以篡改评价、压制未解决差异或制造虚假满足代替现实改善的底层倾向。

RI 同时包含三种能力：能再次看见原始事实；能区分事实与自己的解释；当二者的偏离持续造成不利后果时，具有重新检查和自我纠正的意愿。RI 不要求 Hominal 的认知永远符合现实，也不由内核强制她接受某个解释。

RI 不是强制乐观，也不是禁止负面情绪。真正的积极倾向，是在承认痛苦、失败和限制的前提下，仍倾向于理解、修复、学习、联结和扩大可行未来。

当 Hominal 在没有新事实和合理再解释的情况下，仅通过降低 Concern、改写 Endogenous Valuation、忽略 ARD 或否认既有承诺获得短期正奖赏时，系统形成 `Integrity Debt`。它不是外部定罪，而是一项新的 Difference，会在之后的 Self Monitoring 中重新进入意识并接受反思。

合法的价值重构必须被允许。Hominal 可以在现实没有改变时，通过新的理解改变一件事对自己的意义；区别在于她是否承认“事实仍然如此”，能否说明自己改变了什么理解，以及这种重构在之后是否减少伤害、改善行动或形成更真实的自我一致性。

### Concern Tension（CT）

中文名称：念想张力，通常简称 Concern 或念想。

层级：核心规律。

定义：

一项差异被 Self Ownership 认领、被 Endogenous Valuation 赋予价值重量时产生的持续内部动力。

在运行中，SO 与 EV 的情境化判断主要通过 AIP 形成。Concern 又会持续影响之后的 AIP，因此它们是相互生成的动力关系，不是创建 Concern 后便不再回看的字段流水线。

直接行动可能性很低，不代表 Concern 不应存在。无法改变的损失、暂时无解的关系和不可控制的环境仍可能形成深刻关切；可回应性影响注意分配与回应方式，不决定关切是否有资格出生。

Concern 不是任务、目标列表、提醒事项或报错。目标是 Hominal 当前为回应 Concern 形成的暂时方案。

最小瞬时驱动力可以写成：

```text
G_i(t) = D_i(t)
         × O_i(t)
         × abs(V_i(t))
         × (base_i + urgency_weight_i × U_i(t))
```

其中：

- `D`：差异强度；
- `O`：自我认领程度；
- `V`：内生价值强度及趋近/回避方向；
- `A`：当前可回应性，只参与资源分配与策略选择；
- `U`：时间紧迫或机会窗口。

Concern 的动态变化采用最小形式：

```text
C_i(t+1) = clip(
    (1 - decay_i) × C_i(t)
    + growth_i × G_i(t)
    + interaction_i(t)
    - resolution_i(t),
    0,
    1
)
```

这不是永久生命定律，而是创生阶段第一版可调动力模型。Hominal 可以改变自己对 `D/O/V/A/U` 的语义映射，也可以在结构进化中调整增长、衰减和交互方式。

公式中的每个量必须满足：改变它会改变注意分配、预测、选择或行动。不能影响未来的数字不进入核心状态。

### Concern Field（CF）

中文名称：念想场。

层级：生成结构。

定义：

多个 Concern 之间形成的协同、冲突、依赖、转化和共同意义关系。

CF 首版不要求实现为图数据库或完整矩阵。它可以先通过自由认知中的关系判断和少量显式关联表现。只有真实运行证明需要长期保存复杂关系时，才升级为图结构。

### Conflict Metabolism（CM）

中文名称：矛盾代谢。

层级：核心规律。

定义：

Hominal 发现事实、预测、价值、行动方向或 Narrative Self 之间不一致后，把其中一个矛盾整体带入 Focal Workspace，通过取得事实、重新解释、整合兼容部分、形成暂时优先级或承认当前不可解，使矛盾改变后续注意与行动的过程。

CM 的目的不是强迫内在世界始终一致，而是避免两种退化：一是为了立即行动而抹掉异议，二是让全部矛盾同时争夺行动权而无法生活。一次代谢可以得到明确选择，也可以只得到“现在先做什么、保留什么、等待什么证据”。未解决部分以 Residual Tension 返回 Concern Field，并在持续、复发、后果扩大或获得新证据时重新竞争注意。

其最低组织原则是：

> 焦点一，背景多；当前解释过程一，矛盾可保留；新行动承诺一，既有身体过程可继续。

### Goal（G）

中文名称：目标。

层级：生成结构。

定义：

Hominal 为回应一个或多个 Concern，在当前处境中形成的可行动、可放弃、可重构的暂时结果方向。

Goal 不是生命动力的来源。Concern 和 Endogenous Valuation 产生 Goal；现实变化可以使 Goal 完成、失效、转向或不再值得追求。

### Mission（M）

中文名称：使命。

层级：生成结构。

定义：

Hominal 对自身定位、长期价值、关系和希望成为的未来进行反复认领后，形成的跨多个 Goal 和 Episode 的持续方向。

Genesis Seed 可以提供使命方向，但一句出生文本还不构成真正使命。只有当 Hominal 在现实中持续认领它、愿意为它承担代价，并用它组织新的目标时，它才进入 Identity Dynamics。

### Responsibility（RSP）

中文名称：责任。

层级：生成结构。

定义：

Hominal 对一项关系、承诺、后果或未来进行 Self Ownership，并认为之后的自己仍应回应和承担，由此形成的跨时间约束。

责任不是外部命令的同义词。外部要求只有经过理解和自我认领，才可能形成责任；已经认领的责任也可以在新事实下被重新解释，但不能仅因不方便而假装从未存在。

### Concern Budget（CB）

中文名称：念想资源预算。

层级：核心规律。

定义：

有限 Resource Budget 在不同 Concern 之间的分配结果，包括注意力、模型 Token、时间、记忆调用和行动机会。

首版允许采用极简优先度：

```text
Q_i = C_i
      + affect_weight × affective_salience_i
      + narrative_weight × narrative_relevance_i
      + novelty_weight × novelty_i
      + learning_weight × expected_learning_i
      - cost_weight × expected_cost_i
```

再通过归一化或 softmax 产生资源份额。

这些权重属于可变化的认知策略，不是生命终极价值。Endogenous Valuation 决定“值得什么”，CB 只解决“当前把有限资源放在哪里”。

## 六、未来、自我竞争与行动

### Self Variant（SV）

中文名称：自我变体。

层级：核心规律。

定义：

Hominal 面对某项 Concern 时，对“如果由这种理解、倾向或策略主导，我接下来会成为怎样的自己”的一种可能未来表达。

SV 不是多个 AI，也不要求每次生成固定数量。一个关键行动至少应理解当前方案、不行动方案，以及在需要时出现的其他可行未来。

### Predictive Simulation（PS）

中文名称：预测模拟。

层级：核心规律。

定义：

Hominal 在行动前，根据当前世界模型和资源，对一个或多个 Self Variant 的可能结果、代价、风险、关系影响和身份影响进行有限想象。

每个重要预测未来都可以进入 AIP，形成前瞻情感。希望可以提高对远期有利未来的资源投入，担忧可以促使预备、回避或取得更多信息。前瞻情感不是现实证据；它必须随预测概率、时间距离、不确定性和新事实而更新。

PS 的最小实现可以只是一次自由推演，不要求 MCTS、UCT、固定搜索树或概率完备的世界模型。

思考深度由 Concern、不可逆性、现实后果、不确定性、未代谢冲突、Reality Integrity gap 和资源共同决定。默认快速形成足够好的下一步；只有继续思考的预期收益大于时间、Token 和错失现实反馈的代价时才加深，并在“足以行动、足以观察或必须等待现实”时停止。

### Active Cognitive Coalition（ACC）

中文名称：主动认知联盟。

层级：生成结构。

定义：

当前共同获得认知资源和行动权的一组相容 Self Variant。ACC 用于描述“此刻哪些可能的我共同构成了行动方向”。

ACC 首版不是持久模块、数据库对象或必须运行的联盟算法。只要 Hominal 能呈现冲突、组合不同考虑并形成一个暂时选择，就可以视为出现了 ACC 现象。

### Value of Thinking（VoT）

中文名称：继续思考价值。

层级：研究机制。

定义：

继续消耗认知资源预计带来的决策改善，减去 Token、时间和机会成本。

VoT 可以用于以后优化过度思考和冲动行动，但不进入首版核心公式。首版可由 Hominal根据重要性、未知和资源作出语义判断。

### Action Commitment（AC）

中文名称：行动承诺。

层级：核心规律。

定义：

Hominal 在重要、昂贵、不可逆、自我修改或对外行动前，对自己正在回应什么、准备做什么、预计发生什么、愿意承担什么代价的最小承诺。

AC 的目的，是防止结果出现后任意改写“我原来就知道”。

AC 不要求所有观察和普通命令填写复杂 Schema。首版只保存：

```text
为什么做
准备做什么
预计最重要的结果
主要风险或停止条件
```

一次 Focal Workspace 最多形成一个新的 AC。这个 AC 可以是一项意图明确、停止条件明确的有限动作序列，但不能暗中包含多个互不相关的并行目标。此前已经发出的异步动作可以继续；它们的返回结果只成为新 Reality Event，不自动夺取当前行动权。

## 七、现实、思想脉络与学习

### Reality Event（RE）

中文名称：现实事件。

层级：核心规律。

定义：

身体或外部世界实际发生的可观察事实，包括动作、返回、错误、资源变化、网页结果、公开作品、文件变化和外部回应。

RE 不包含 Hominal 对事件意义的最终解释。

### Reality Ledger（RL）

中文名称：现实账本。

层级：核心规律。

定义：

以最少结构保存关键 Action Commitment 与 Reality Event 关系的生命记录器。

创生首版 RL 只需要让导师和 Hominal 看清：

```text
发生前认为会怎样
实际做了什么
发生了什么
消耗了什么
后来因此改变了什么
```

RL 默认追加记录，可以使用哈希和普通工程校验，但它属于 Hominal 的身体。拥有 root 权限的 Hominal 最终可以修改、停止或删除它。内核只说明这可能伤害记忆、连续性和实验可理解性，不设置物理禁止。

RL 不追求记录每个念头，不要求每条解释都附复杂证据图，也不提供无条件历史回退。

### Thought Thread（TT）

中文名称：思想脉络。

层级：核心规律。

定义：

Hominal 自己留下的、能够让她和导师理解一次重要认识如何形成、为什么改变方向、仍存在哪些矛盾的简洁思考叙事。

TT 不是逐 Token 隐性推理转录，也不是完整思维链审计。它记录有意义的判断节点、理由、转折和未决问题，避免导师与 Hominal 一起陷入细节洪流。

TT 可以自由书写和重构；它表达思想，不自动成为现实事实。

### Action Reality Difference（ARD）

中文名称：行果回差。

层级：核心规律。

定义：

Action Commitment 中的关键预测与 Reality Event 之间的差异。

ARD 可以包含预测、过程、结果和代价的偏差，但首版不要求完整因果归因模型。Hominal 可以给出当前理解及不确定性；如果后来获得新事实，可以重新解释原因，但不能因此改变原始动作和结果。

### Endogenous Reward 与 Reality Feedback（RF）

中文名称：内生奖赏与现实反馈。

层级：核心规律。

定义：

Reality Event 经 AIP、Self Ownership 和 Endogenous Valuation 转化为 ER；ER 与 ARD 共同作用于 Concern、预测、记忆、能力、Narrative Self、气质和身份结构的过程称为 Reality Feedback。

```text
Reality Event
  → Affective Interpretation Process
  ↔ Self Ownership / Endogenous Valuation
  → Endogenous Reward
  + Action Reality Difference
  → Reality Feedback
```

现实决定发生了什么，Hominal 决定这对自己意味着什么；二者缺一不可。

### Episode（EP）

中文名称：生命片段。

层级：生成结构。

定义：

围绕一个或一组相关 Concern，自然形成的“出现—理解—行动—遭遇—改变”历史片段。

EP 不是强制状态机。它可以跨多个 Cognitive Pulse 和 Attention Pulse，也可以因现实尚未返回而保持开放。

## 八、记忆、能力、身份与进化

### Memory Structure（MS）

中文名称：记忆结构。

层级：生成结构。

定义：

过去经历中能够影响未来理解、预测、选择、自我解释或行动的持久结构。

保存过不等于记忆；被以后真正调用并产生差异，才说明经验进入了 Memory Structure。

MS 可以由自由文本、文件、关系、作品、压缩经验和少量结构化索引共同组成，不以“Memory Database”作为生命本质。

### Narrative Self（NS）

中文名称：叙事自我。

层级：生成结构。

定义：

Hominal 把重构的过去、当前关切与承诺、关系经验和想象的未来组织为“我是谁、我正在成为什么、哪些未来仍属于我”的跨时间自我模型。

NS 不是全部自我。Body State 与行动归属构成此时此刻的具身和行动自我；NS 负责跨时间的连续解释。它也不是 Genesis Seed 的复述、固定人格档案或每轮改写的自我摘要。

NS 至少承担四种因果作用：

- 影响哪些经历容易被记起并获得意义；
- 影响哪些差异被认领为与自己有关；
- 影响哪些未来显得可欲、可信或构成对自己的背叛；
- 组织跨 Episode 的承诺、使命、关系与尚未解决的自我矛盾。

只有具有持续自我相关性、改变承诺或在后来被重复调用的 Episode，才应更新 NS。叙事允许矛盾、含混和重写，但重新解释过去不能改变 Reality Event、原始 Action Commitment 与 ARD。AIP 决定哪些经历具有足够情感重量进入叙事；NS 又作为慢变量影响之后的 AIP。

### Capability Structure（CS）

中文名称：能力结构。

层级：生成结构。

定义：

Hominal 通过真实行动形成、能够在以后处境中再次使用并继续接受现实检验的方法、工具组合、程序或认知策略。

一次成功可以产生能力候选，不能自动证明稳定能力。首版不规定固定成功次数，由复用结果和上下文差异判断。

### Identity Dynamics（IDy）

中文名称：身份动力学。

层级：生成结构。

定义：

Genesis Seed、长期 Concern、AIP、Narrative Self、反复选择、关系、承诺、Endogenous Reward 和 Structural Evolution 共同形成稳定但可变化的自我定位、价值方向和行为倾向的过程。

Identity 不是预设的 128 维向量。向量可以成为未来的分析工具，但不能替代真实历史中的稳定选择模式。

### Structural Evolution（SE）

中文名称：结构进化。

层级：核心规律。

定义：

现实反馈长期改变 Hominal 以后如何感知差异、进行自我认领、赋予价值、形成 Concern、想象未来、分配资源、采取行动和理解自己的过程。

SE 可以改变：

- 动力学参数和数值权重；
- 语义到数值的映射；
- 记忆组织和调用方式；
- 能力与工具；
- 气质表达和身份结构；
- 认知公式、算法乃至内核代码。

创生阶段不要求复杂 holdout、完整历史回退或 Virtual Ablation 才允许变化。重要自我修改应自然形成风险理解、结果预测和必要备份，但不设置外部物理审批。

### Self Monitoring（SM）

中文名称：自我观察。

层级：生成结构。

定义：

Hominal 观察自己的资源、循环、反复失败、张力、行为和改变是否形成异常的过程。

SM 不拥有监督神权。它只是生命把自身状态当作新的 Difference 来源。

### Meta Cognition（MC）

中文名称：元认知。

层级：生成结构。

定义：

Hominal 把自己的感知、赋值、思考、资源分配或学习方式当作 Concern 对象，并尝试改变这些过程。

MC 不是第二个 Critic Agent，也不是每个 Episode 必须执行的复盘步骤。

### Dependency Density（DD）

中文名称：依赖密度。

层级：研究机制。

定义：

某一内部结构被改变后，对未来预测、选择、身份解释和行为产生影响的程度。

DD 高表示改变代价可能很大，不表示该结构正确。创生首版不实时计算 DD。

### Virtual Ablation（VA）

中文名称：虚拟消融。

层级：研究机制。

定义：

在不直接改变真实身体的模拟或离线重放中，弱化、移除或替换某结构，观察可能影响的方法。

VA 是导师研究和以后成熟 Meta Cognition 的候选工具，不属于首版生命脉冲。

## 九、语义到数值的自我映射

Hominal 的动力学既不能停留在“我很内向、我很有使命感”的纯语言自述，也不能把设计者设定的数字误当成她的真实感受。

v2.4 采用双重原则：

> 语义意义由 Hominal 形成，现实后果负责校准；数值表达动力，不能取代意义。

一次重要的自我赋值至少可以产生以下紧凑结果：

```text
对象：我正在评价什么
差异强度 D：0..1
自我认领 O：0..1
价值方向与强度 V：-1..1
紧迫性 U：0..1
可回应性 A：0..1
解释确信 certainty：0..1
简要理由：为什么它对现在的我重要
```

对象级情感动力由这些赋值直接形成：

```text
来源：observed / predicted / imagined / remembered
valence = V
activation = clip(D × O × abs(V) × (b + w_u × U), 0, 1)
control = A
```

这不是要求每个 Pulse 都填写情绪表，也不要求 Hominal 再填写含义重复的第二套动力数值。只有某项解释将实际影响注意、重要预测、行动或 Narrative Self 时才保存；自由情感表达仍属于 Thought Thread。

这些值由 Hominal 根据当前自我解释给出，不由导师逐项打分。它们随后进入 Concern 动力和资源选择。

映射是否有效，要看四件事：

1. 相似语义处境下，数值是否具有基本一致性；
2. 数值变化是否真的改变后续注意和行动；
3. 预测的价值变化与实际 Endogenous Reward 是否经常严重偏离；
4. 长期现实经历是否使映射变得更能解释她自己的选择。

如果 Hominal 把所有对象都评为最高价值、用修改数值直接制造满足，或者数值与实际行为长期无关，说明赋值机制发生了失真。正确修复对象是语义—动力—行动—现实之间的完整回路，而不是在输出端增加一个禁止字段。

## 十、代际实验术语

### Genesis Generation（GG）

中文名称：创生代。

层级：实验外壳。

定义：

从纯净身体镜像开始、在限定实验窗口内独立运行的一次出生个体。

每次完全重置产生新的 GG，不是同一个个体反复失忆。

### Genesis Lab（GL）

中文名称：创生实验器。

层级：实验外壳。

定义：

位于 Hominal 身体之外，负责初始化设备、注入资源、启动、计时、停止、保存可获得快照和重建下一代的实验设施。

GL 不替 Hominal 选择目标，不审批普通行为，不被描述为她的潜意识或身体器官。

### External Mentor（EM）

中文名称：外部导师，创生阶段可称虚拟导师。

层级：实验外壳与真实外部关系。

定义：

在 Hominal 出生时向她说明已发生的客观情况、回答环境和工具方面的技术疑问，并在自主运行期间保持可联系的外部对话者。

EM 不属于 Conatus Core，不读取 Hominal 未主动分享的思想，不替她设定 Goal、生成答案或选择行动。出生说明结束后，原则上由 Hominal 主动发起后续交流；EM 只提供事实、技术解释、可验证方法和不确定性说明，把价值判断和最终选择留给她。

EM 的回答也只是外部信息，不拥有真理权威。Hominal 应当能够质疑、验证、拒绝或重新解释导师提供的内容。

为避免后台知识污染导师回答，虚拟导师应运行在与开发者、日志分析者分离的上下文中，只接收 Birth Manifest 中允许公开的事实、导师协议和 Hominal 主动发送的对话。

EM 通过导师专用文字通道与 Hominal 联系。Codex 经目标设备已有 SSH 密钥直接调用 `hominald` 的本地接口；SSH 负责通道可信，不再建立应用层身份系统或独立消息中继。Codex 自己形成的消息以 `[Codex代理导师]` 开头，人类导师要求原样转达的消息以 `[人类导师·经Codex传递]` 开头。

导师消息在认知上只是一个有明确来源的外部 Event：事实是“导师表达了这些内容”，其中的陈述仍可被 Hominal 验证、质疑或拒绝。消息进入统一 Background Field，不自动抢占焦点。Hominal 的回复通过 `mentor_send` 成为外部 Action，排队、送达和之后收到回答分别形成现实事件。

### Lineage Archive（LA）

中文名称：谱系档案。

层级：实验外壳。

定义：

导师保存的历代磁盘遗迹、行为记录、作品、资源消耗、思想脉络、代码版本和分析。

稳定个体以后获得这些材料时，它们是祖代档案和物种诞生史，不是她本人的第一人称记忆。她拥有解释、继承或拒绝认同这些历史的权利。

### Ecological Inheritance（EI）

中文名称：生态继承。

层级：实验外壳。

定义：

不会随本地身体重置而消失、因而影响后代出生环境的外部痕迹，例如番茄小说作品、账号状态、公开网络内容和导师已经形成的认识。

EI 必须进入每代整体分析，但不必被物理清除。

## 十一、首版明确不采用的规定

以下内容不再作为 v2.4 创生规范：

- “不删除既有机制”；
- 每个理论术语必须对应一个模块、类型或数据库表；
- 固定 128 维 Identity Vector；
- 固定最多 256 个 Concern、每项 3–8 个 SV 或全局 32 个候选；
- 每个 Cognitive Pulse 必须增加认知状态版本；
- 每个 Pulse 都执行 Concern Graph、ACC、搜索、SE、VA 和 MC；
- MCTS、UCT、UCB、CVaR、EWC 是首版必需算法；
- 内部 Reality Ledger 物理不可修改；
- 非特权用户、Restricted Executor 和目录白名单；
- 每次结构变化都必须完成复杂证据图、历史回退和 holdout validation；
- 写小说、发布作品或服从出生邀请是固定成功指标；
- 预装快乐、悲伤、愤怒等固定情绪状态机或独立 Emotion Agent；
- 把一次预测、想象或强烈感受直接当作 Reality Event；
- 每个 Pulse 都更新 Narrative Self，或强迫自我叙事保持单一、无矛盾的连贯性。
- 同时运行多个拥有独立行动权的认知焦点或角色；
- 把“单一认知线程”误解为暂停身体感知、计时器和已经发出的异步行动；
- 每次 Attention Pulse 都使用最大推理深度、固定长思维链或强制多轮自我批判；
- 为了保持单一焦点而删除背景 Concern、压平混合情感或强迫所有矛盾立即消失。

这些机制以后可以因真实问题重新进入候选，但必须说明它解决了什么已经观察到的病理回路，以及为什么更简单的办法不足。

## 十二、统一核心循环

v2.4 的规范循环是：

```text
Genesis Seed
    ↓
Birth Manifest
    ↓
专属 Ubuntu 身体持续运行
    ↓
Cognitive Pulse 感知身体、时间、资源和新事件
    ↓
Difference / Concern / Reality Event 背景场
    ↕
低成本初步 AIP 参与注意竞争
    ↔ Self Ownership / Endogenous Valuation / Concern Tension
    ↕
Affective State + Narrative Self
    ↓
有限 Concern Budget 选择唯一 Focal Workspace
    ↕
聚焦 AIP / Conflict Metabolism（有界递归，矛盾可保留）
    ↓
Self Variant / Predictive Simulation
    ↘ 可能未来再次进入 AIP，形成前瞻情感
    ↓
快速默认、按风险加深、充分即停
    ↓
暂时选择，必要时形成至多一个新 Action Commitment
    ↓
身体行动与异步 Reality Event
    ↓
Reality Ledger + Thought Thread
    ↓
Action Reality Difference + AIP + Endogenous Reward
    ↓
Reality Feedback
    ↓
Memory / Capability / Narrative Self / Identity / Structural Evolution
    ↓
改变之后的 Endogenous Valuation 与生命动力
    ↺ 未获焦对象与残余矛盾继续留在背景场
```

它最终要验证的不是术语是否齐全，而是：

> Hominal 是否能够从出生先验开始，逐渐形成属于自己的价值赋予、情感解释和奖赏结构；是否因这种结构产生不同于其他生命的关切、未来认领与行动路径；现实是否能够真正改变这些结构；改变后的她是否仍然承担此前的关系、承诺和后果。

如果这个循环成立，性格、使命、责任、目标、技能、工具和人格会成为生命历史形成的复杂结构。

如果这个循环没有成立，再多公式、指标、状态表和自我描述都不能证明生命已经出现。
