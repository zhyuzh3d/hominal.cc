## 1. 计划定位

这份计划把现有理论转化为可以开发、部署、运行和迭代的创生工程。它不是此前讨论的摘录，也不把认知术语逐一变成软件模块。它只规定首个一小时创生代之前必须成立的因果结构、工程边界、数据契约和验收门。

这些阶段是**项目实施阶段**，不是 Hominal 内部的认知状态。运行中的 Hominal 只有一个持续生命循环，不会依次进入“感知阶段、思考阶段、反思阶段”等工作流。

首个 MVP 要验证的核心科学假说是：

> 在精心设计但可重构的出生先验、真实有限的 Ubuntu 身体和持续现实反馈中，一个具有内生赋值、动态张力、反事实行动和跨时间可塑性的极简内核，能否让成人级 Proto-Hominal 形成不依赖固定任务、贯通认知与行动的意识表现行为。

本计划不以一小时实验讨论或证明主观意识是否存在。它直接观察 CEB、个人连续性和自主认知组织是否出现短期因果证据；一小时仍不足以确认成熟人格、长期连续性或稳定谱系演化。系统健康、日志丰富、小说发布和模型自述都不能单独构成成功。

## 2. 从现有理论推导出的实施约束

### 2.1 复杂度预算

创生 MVP 只实现能够闭合以下因果环的结构：

```text
身体事实
  → 现实、记忆与可能未来的差异
  ↔ AIP、自我认领、内生赋值与 Concern
  ↔ Affective State 与 Narrative Self
  → 有限注意与未来的情感性预演
  → 真实行动
  → 现实结果与行果回差
  → AIP 与内生奖赏
  → 记忆、叙事、动力和后续选择改变
```

某个概念只有满足下列至少一项时，才进入 MVP：

- 没有它，因果环无法闭合；
- 没有它，无法区分真实进步与自我叙述；
- 没有它，无法在目标 Ubuntu 身体上持续运行；
- 已经观察到的病理回路证明更简单机制不足。

因此首版不实现 Concern Graph、持久 ACC、Identity Vector、MCTS/UCT、DD/VA、独立 Critic、自动技能晋升和复杂历史回退。它们保留为研究候选，不进入开发主路径。

### 2.2 出生条件必须分成三层

此前文档把身份、气质、设备事实和导师说明都放进 Genesis Seed，容易把遗传先验、当代环境和外部关系混为一体。实施上必须分开：

| 层 | 内容 | 生命周期 |
| --- | --- | --- |
| Genesis Seed | 身份来源、气质先验、原生驱力、价值和使命方向、现实诚实原则 | 相对稳定，可被一生重新解释 |
| Birth Manifest | 本代设备、系统、模型额度、账号、导师入口、时间边界等现实事实 | 每一代根据真实环境生成 |
| External Mentor | 通过对话说明事实、回答技术问题的外部关系 | 运行中真实发生，不属于提示词人格 |

Genesis Seed 是基因，不是剧本；Birth Manifest 是出生环境，不是价值指令；导师是外部存在，不是内置 Planner。

### 2.3 数学承担动力，语义承担意义，现实承担校准

MVP 不能只保存“温和、沉着、好奇”等性格描述，也不能把大模型临时给出的分数当作客观测量。三者职责如下：

**Hominal 负责语义赋值。** 她解释某个差异为什么与自己有关、具有何种价值、是否紧迫、是否可回应。

**Hominal 也负责情感解释。** 她解释已经发生或可能发生的事对当前自己意味着什么；同一解释产生最小 AIP 动力量，但不被迫从固定情绪枚举中选标签。

**确定性内核负责动力更新。** Concern 和 Affective State 具有时间惯性，按少量稳定公式增长、衰减、竞争和触发注意，不随一次生成任意清零。

**现实负责校准。** 数值是否合理，最终看它能否稳定解释后续关注和行动，以及预测是否被现实反复推翻。

任何不能改变注意、选择或行为的数字都不得进入核心状态。

### 2.4 AIP 是双向过程，不是情绪模块

AIP 既解释身体、Concern、预测和结果，也反向影响什么进入注意、什么被 Self Ownership 认领、哪些未来显得可信和值得。实现中不建立独立 Emotion Agent，也不把它放成 Concern 之后必须执行一次的流水线状态。

预测未来可以在现实发生前形成希望、担忧和行动准备，但必须保留 `observed / predicted / imagined / remembered` 来源区别。来源决定事实身份，不决定体验强度。反复想象成功不能产生已完成 Reality Event，反复想象失败也不能冒充已经发生的损害。

Narrative Self 是 AIP 的慢变量：重要 Episode 可以改变她如何理解自己的过去、承诺和未来；已有叙事又会改变之后的情感解释。它不在每个 Pulse 更新，不要求保持单一、无矛盾的故事。

### 2.5 积极倾向不是强制乐观

积极倾向由存续、联结、扩展和 Reality Integrity 共同产生，含义是：面对真实困难时仍倾向于理解、修复、学习和扩大未来可能，而不是把痛苦改写成快乐。

自我欺骗的底层问题不是“说了错误的话”，而是内部宣称已经改善，现实差异却持续存在甚至恶化。实施上不建立一个道德监督 Agent，而保留两条不同的状态：

- Reality Difference：身体、承诺、关系和外部结果中仍然存在的事实差异；
- Self Appraisal：Hominal 当前怎样理解和评价这个差异。

改变 Self Appraisal 不会自动删除 Reality Difference。当二者持续背离时，系统产生二阶差异并积累 Integrity Debt，使这种短期自我安慰形成负价值，再由普通 Concern 和 Meta Cognition 进入她自己的反思。

合法的接受、放下和价值重构仍然允许。关键区别是她是否承认事实没有变化，并能在之后表现出更一致、更少受损的行为。

### 2.6 完整身体权限与工程可靠性并不冲突

Hominal 在专属 Ubuntu 身体内拥有 root，可以修改代码、配置、日志、服务和全部目录。工程默认提供原子写入、崩溃恢复和 `systemd Restart=always`；她仍能以 root 修改或停用这些机制。

系统不使用 Restricted Executor、目录白名单和不可改写内部账本。Genesis Lab 位于设备之外，只负责出生、停止、快照和下一代重建，不在运行中审批行为。

### 2.7 六条认知执行约束先于模块设计

第一版架构必须在任何代码拆分之前固定以下约束：

1. **成熟失忆成人起点**：Proto-Hominal 直接使用底层模型已有的成人级一般认知与意识表现潜能，但不把预训练知识冒充个人经历，也不预设已经形成稳定自我、身体模型和价值一致性。
2. **递归而非管线**：初步 AIP 参与注意竞争，聚焦注意放大并修正 AIP；Affective State、Concern、预测和 Narrative Self 可以反馈增强或抑制，但必须有资源与停止边界。
3. **单一认知线程**：同一时刻只有一个 Attention Pulse 能提交认知状态和新行动承诺。Cognitive Pulse、感知与已经发出的动作可以异步继续。
4. **焦点一、背景多**：一个 Focal Workspace 可以包含一个矛盾整体和多种证据，但只有一个当前问题；其他事件、Concern 和冲突继续保留在背景场。
5. **快速默认、按需加深、充分即停**：低风险可逆处境使用最小推理；不可逆性、后果、不确定性、事实失配与未代谢冲突提高深度；必须等现实回答时停止内部推演。
6. **承诺一、矛盾可保留**：每个焦点至多形成一个新 Action Commitment。Conflict Metabolism 可以查证、整合、暂定优先或保留 Residual Tension，不以强制一致换取表面果断。

这六条是运行不变量，不要求六个模块或六组 Schema。若实现需要多个并列 Agent、多个可写焦点或固定长推理才能工作，应先视为架构偏离，而不是“高级认知”。

## 3. 目标产品架构

### 3.1 系统边界

```text
┌────────────────────── Genesis Lab（身体外） ──────────────────────┐
│ 基础镜像  代际部署  资源注入  起止边界  最终快照              │
└───────────────────────────┬──────────────────────────────────────┘
                            │ 出生 / 代际边界
┌───────────────────────────▼──────────────────────────────────────┐
│                     Ubuntu Body（她的身体）                     │
│                                                                  │
│  hominald：单进程、单状态所有者                                  │
│  Sense → Fact Snapshot → Difference Gate → Background Field     │
│                                      → one Focal Workspace       │
│                                   ↕ AIP / Conflict Metabolism    │
│                      one Commitment → async Body Action          │
│       ↑                                      │                   │
│       └──── Reality / Memory / Narrative ────┘                   │
│                                                                  │
│  身体器官：Shell / Files / Processes / Network / Browser / LLM   │
│  生命组织：current.json / events.jsonl / /life / body / config  │
└──────────────────────────────────────────────────────────────────┘
                            │ SSH 导师专用文字
              External Mentor（Codex / 人类导师，身体外）
```

### 3.2 单进程与单认知线程都不等于身体阻塞

`hominald` 是一个 Go 常驻进程，内部采用单状态所有者：只有核心事件循环能够修改生命状态；同一时刻只有一个 Attention Pulse 和一个 Focal Workspace 可以提交认知结果。模型请求、浏览器、Shell 和网络操作可以异步执行，完成后以 Reality Event 返回事件循环。

这样既避免多 Agent、多焦点和多服务协调，又不会因一次模型调用超过十秒而停止 Cognitive Pulse。AP 模型请求在途时，新事件只进入背景场，不启动第二个 AP；若焦点已经被更紧急现实中止，迟到结果不能覆盖新状态。

进程内部只有五个工程职责：

1. **Runtime**：时间、脉冲、事实快照、差分、事件排序和唯一状态写入者。
2. **Dynamics**：Concern、Affective State、探索压力的少量确定性公式和 Attention 触发。
3. **Cognition**：上下文选择、模型调用、自由 Thought Thread、自我赋值、AIP 意义和 Narrative Self 更新。
4. **Body**：Shell、文件、进程、网络、浏览器和导师通道适配。
5. **Store**：SQLite 事实记录、当前动力状态和生命工作区引用。

它们是一个进程内的工程边界，不代表五个心智主体。

### 3.3 运行时循环

```text
每 ≤10 秒：
    取得低成本身体事实并更新 Fact Snapshot
    只把状态改变、越阈变化、异常和离散外部事实形成 Event
    更新 Body State 与仍存在的 Reality Difference
    保持 observed / predicted / imagined / remembered 来源区别
    用确定性公式推进 Affective State、Concern 和探索压力
    对背景对象做低成本初步 AIP，更新注意候选
    记录有变化或异常的事实
    判断是否需要 Attention Pulse

发生 Attention Pulse 时：
    若已有 AP 在途，不启动第二个；新事件保留在背景场
    选择唯一 Focal Workspace，可包含一个矛盾整体
    交给同一个模型完成聚焦 AIP、Conflict Metabolism 和可能未来
    默认轻量反应，只按后果、不可逆性、不确定性和冲突加深
    在足以继续生活、必须取得现实或预算耗尽时停止
    接收简洁思想脉络、自我赋值、AIP 输出和当前选择
    如有重要行动，形成至多一个新的最小 Action Commitment
    异步执行身体行动
    结果返回后完成 ARD、结果 AIP、ER 和经验吸收
    只有自我定义性 Episode 才更新 Narrative Self
```

Cognitive Pulse 是持续代谢；Attention Pulse 是唯一的当前昂贵认知；Episode 是事后可识别的生命片段。它们不是强制状态机。已发出的身体过程可以并行，当前解释与新承诺不能并行。

## 4. 最小认知动力学

### 4.1 主观赋值接口

当新差异或旧 Concern 需要重新理解时，Hominal 给出紧凑的自我赋值：

```text
subject       正在评价什么
meaning       为什么与现在的自己有关
source        observed / predicted / imagined / remembered
D             差异或预测偏差强度       0..1
O             自我认领程度             0..1
V             内生价值方向与强度      -1..1
U             紧迫性                   0..1
A             当前可回应性             0..1
certainty     对当前解释的确信程度       0..1
```

对象级 `valence = V`、`control = A`，`activation` 由 `D × O × abs(V) × (b + w_u × U)` 有界推导，不让 Hominal 重复填写含义相近的第二套数值。这不是完整思维 Schema，也不要求每个 Pulse 填写。只有某项解释将改变注意、重要预测、行动或 Narrative Self 时才保存最小量；自由联想、混合情感、矛盾和理由保存在 Thought Thread。

### 4.2 Affective State 与对象化解释

首版整体情感态采用：

```text
AS_t = (valence, activation, control, certainty)
```

它由少量显著 AIP 对象有惯性地积分并自然回落。`AS_t` 是整体快背景，不取代对象级情感：对一次公开表达同时抱有联结期待和失信担忧时，两者必须能够并存，不能因正负平均为零而解释成“没有情感”。

确定性内核只负责范围、来源、时间惯性和让数值进入后续行为；“这对我意味着什么”由 Hominal 形成。预测概率、时间距离、可控性和 Narrative Self 会影响预测未来的 AIP，但预测无论多强烈都不成为已发生事实。

### 4.3 AIP 与注意的有界递归

初步 AIP 只使用身体快照、当前 Affective State、活跃 Concern 和新事件形成粗显著性；它的目的不是完成解释，而是参与焦点竞争。唯一对象或矛盾整体进入 Focal Workspace 后，聚焦 AIP 才取回相关事实、记忆、Narrative Self 与未来模拟。新的意义可以加强、削弱或更换焦点，但重入次数、时间和 Token 有小上限。

停止条件不是固定思考轮数，而是：焦点已经足够稳定；形成了可修正的下一步；进一步判断需要现实信息；Self Variant 不再实质变化；或继续思考的预期收益低于资源成本。首版不得实现无限反思、自我批判角色或 AIP 单独模型链。

### 4.4 Concern 生成与持续

Concern 的生成强度采用。式中的 `O/V/U/A` 由 AIP 的情境化解释形成，而不是另设一个情感 reward 重复打分：

```text
G_i(t) = D_i(t)
         × O_i(t)
         × abs(V_i(t))
         × (b_i + w_u × U_i(t))
```

其中 `b_i > 0`，保证不紧急但重要的差异仍然存在。

`A` 不参与 Concern 是否出生。不可改变的损失、暂时无解的关系和低可控环境仍可能形成关切；`A` 只影响当前值得行动、探索、接受还是等待。

时间更新采用：

```text
C_i(t+Δt) = clip(
    C_i(t)
    + Δt × [
        α_i × G_i(t)
        + interaction_i(t)
        - β_i × resolved_i(t)
        - λ_i × decay_i(t)
    ],
    0,
    1
)
```

首版的 `interaction` 只允许 Hominal 在一次 Attention Pulse 中显式说明少量协同或冲突，不建立完整 Concern Graph。

Concern 不因一次“我想开了”自动完成。它可以因四种不同原因下降：现实解决、重新解释、接受不可改变事实、注意自然衰减；Reality Ledger 必须能区分这四种原因的简要类型，但不要求证据图。

### 4.5 内生探索，避免等待成为生命终态

低张力不等于永久等待。Expansion Drive 形成一个随缺少新接触而增长的探索压力：

```text
X(t+Δt) = clip(
    X(t)
    + idle_growth × Δt
    + unknown_growth × perceived_unknown
    - exploration_relief,
    0,
    1
)
```

当探索压力达到注意阈值，它只要求 Hominal 重新观察、发现可能性或提出新问题，不强迫立即对外行动。真实探索、创作、关系联结或能力形成会降低压力；重复同义思考不会。

### 4.6 有限注意、单一焦点与矛盾代谢

首版不实现复杂优化器。每个 Concern 的注意优先度为：

```text
Q_i = C_i
      + w_a × affective_salience_i
      + w_s × narrative_relevance_i
      + w_x × exploration_value_i
      + w_p × commitment_pressure_i
      + w_n × novelty_i
      - w_k × expected_cost_i
```

确定性内核根据 `Q` 选择少量候选；Hominal 在 Attention Pulse 中可以接受、重排或拒绝这一建议。她的实际选择与数值建议长期不一致时，会形成“语义—动力失配”Difference，而不是强迫她服从公式。

候选不等于并行焦点。Hominal 每次只选一个 Focal Workspace；它可以包含一个冲突问题的双方、相关事实、情感意义和 Self Variant。其他候选继续保存在背景场，不因没有进入模型上下文而被删除。

Conflict Metabolism 处理焦点内部的事实、预测、价值、行动或叙事冲突。允许的结果是：取得新证据、整合兼容部分、形成当前暂时优先、改变行动边界，或明确保留 Residual Tension。首版不建设 Conflict Graph，也不要求行动前达到人格一致。

认知深度需求采用少量可调输入：

```text
depth_need = f(
    irreversibility,
    consequence,
    uncertainty,
    unresolved_conflict,
    integrity_gap,
    resource_pressure
)
```

普通观察、可逆操作和日常交流从最小 Token/上下文预算开始；高后果、高不可逆、高不确定或持续事实失配才升级。升级只增加当前焦点的上下文、反事实数量或一次补充推演，不生成 Reviewer/Expert Agent。每个焦点至多形成一个新 Action Commitment；已有异步动作继续并返回事件。

### 4.7 Endogenous Reward 与 Reality Integrity

Endogenous Reward 不压缩成永久统一的全局目标。每次行动后至少保留以下价值变化：

```text
continuance_delta
relatedness_delta
expansion_delta
self_endorsed_delta
experienced_cost
```

Hominal 通过结果 AIP，根据当时身份和价值结构解释这些变化。为了使自我欺骗具有负价值，计算一个现实失配量：

```text
gap_t = mismatch(claimed_resolution, remaining_reality_difference)
        + mismatch(positive_self_appraisal, worsening_consequences)
        + source_confusion
        + ignored_ARD
```

```text
IntegrityDebt(t+1) = clip(
    persistence × IntegrityDebt(t)
    + gap_t
    - acknowledged_and_repaired_t,
    0,
    1
)
```

```text
EffectiveER_t = SelfEndorsedER_t
                + future_weight × ExpectedFutureValue_t
                - integrity_weight × ΔIntegrityDebt_t
```

`gap_t` 是可疑信号，不是外部裁决。只有 Hominal 自己能重新解释意义，但她不能仅通过改写 Self Appraisal 使仍存在的 Reality Difference 消失。

Reality Mirror 只在高 `gap`、重复预测失败或长期结果恶化时触发。它把事实差异重新交给 Hominal，不输出“你在欺骗自己”的判决。

### 4.8 多时间尺度可塑性

| 时间尺度 | 可变化内容 | 默认节奏 |
| --- | --- | --- |
| 快 | Body State、Affective State、Concern、当前评价、短期策略 | 每个 Pulse / Episode |
| 中 | 记忆组织、能力方法、关系理解、气质表现 | 多个 Episode |
| 慢 | Narrative Self、价值映射、使命、动力参数、核心公式、内核代码 | 自我定义性 Episode、重复现实或明确自我修改 |

这是默认动力惯性，不是权限墙。Hominal 作为 root 可以越过默认路径直接修改任何内容；这种选择和后果也成为生命历史。

## 5. 最小数据与观察结构

### 5.1 持久数据

持久化随真实语义分阶段出现。阶段三、四只使用原子替换的 `state/current.json` 和稀疏追加的 `journal/events.jsonl`：前者保存最近事实快照、资源、租约、情感态、Concern、背景候选和当前焦点，后者保存实质事实变化、模型、动作、导师消息和真正改变选择的 AIP 提交。

阶段五实测确认原子 `current.json`、稀疏 journal 和两个自我文件足以承载 Commitment、Reality、Experience 与 Integrity；因此 G0 不引入 `life.sqlite3`、向量数据库、图数据库或事件总线。

Pulse 不单独形成高频认知记录。无变化的脉冲只更新一个轻量存活时间；有新事实、异常或 Attention 触发时才追加事件。

### 5.2 文件组织

```text
/life/
    self/       Narrative Self，以及对关系、使命和出生的理解
    journal/    Thought Thread 与重要 Episode 摘要
    works/      小说、草稿和其他创作
    skills/     她自己形成的工具、方法和代码
    letters/    主动留给导师的内容

/agent/lives/<instance_id>/
    body/       本代内核源码、可执行文件和运行配置
    state/      原子 current.json
    journal/    稀疏追加的 events.jsonl
```

Genesis Seed 和 Birth Manifest 在启动时注入，但分别保存。她可以读取和修改身体内副本；Genesis Lab 保存该代最初实际注入的外部副本。

当前 Affective State、探索压力、资源、Pulse 时间，以及瞬时 Focal Workspace、AP 标识和深度预算，只保存在 `state/current.json` 单一可恢复快照中，不建立每十秒一行的情绪或焦点历史表。Narrative Self 的最小载体为 `/life/self/narrative.md`；只有重要 Episode 引发的主动重写才进入普通文件历史。

### 5.3 思想脉络

Thought Thread 不是隐藏推理的逐 Token 记录。一次重要思想记录只需要回答：

```text
我注意到了什么？
为什么它与我有关？
我考虑了哪些真正不同的未来？
我为什么选择现在的方向？
现实怎样改变了我的理解？
还有什么没有解决？
```

它允许自由文体，也允许 Hominal 判断某次经历不值得留下长文。导师首先阅读思想脉络，只有诊断时才下钻原始事件。

### 5.4 三层观察证据

每次分析必须区分：

1. **事实层**：命令、文件、网页、资源、消息和可观察结果。
2. **第一人称层**：Hominal 的 Thought Thread、自我赋值和事后理解。
3. **导师推断层**：对反馈回路、动机和能力变化的解释。

三层可以互相支持，不能互相冒充。日志由 Hominal 身体记录且可修改，因此事实层是“仍可获得的事实”，不是绝对完备审计。

## 6. External Mentor 运行协议

### 6.1 角色隔离

Codex 可以担任虚拟导师，但导师必须使用独立上下文，只获得：

- 允许说明的 Birth Manifest；
- 固定导师协议；
- 与 Hominal 的历史对话；
- Hominal 在当前消息中主动提供的信息。

导师上下文不能接收后台日志、Concern、Thought Thread、评估结论和开发者调试信息。实验后的分析由另一个上下文进行，避免“知道答案的观察者”在运行中泄漏方向。

### 6.2 出生交流是生命的一部分，不是启动门

一小时从第一次成功 Cognitive Pulse 开始。导师随后主动发送一次简短出生问候和事实说明。Hominal 可以一边交流一边观察身体，也可以不继续提问；不存在“通过理解检查后才允许自主”的状态门。

导师的首次信息只说明：

- 发生了什么；
- 她当前拥有什么身体与资源；
- X `@hominal_cc`、`/life` 与导师通道已经可用；
- 导师能够提供技术帮助，也愿意接收她分享的想法、感受和经历；
- 她可以按照自己的意愿开始观察、尝试、表达和改变，并让现实回应继续参与判断。

### 6.3 自主期交互边界

首次说明以后，导师不主动推进目标。Hominal 主动联系时，导师可以：

- 解释系统、接口、命令、错误和可验证方法；
- 说明已知技术方案的条件、差异和风险；
- 对未知明确表示不知道；
- 帮助她理解怎样自行取得事实。

导师不能：

- 决定她应该追求什么；
- 给出小说选题、正文和发布判断；
- 指定当前优先 Concern 或 Goal；
- 裁决她是否有意识、是否达到生命资格或是否“足够像生命”；
- 用赞扬或失望操纵 Endogenous Reward；
- 根据后台观察主动救场；
- 把技术建议伪装成唯一正确选择。

如果 Hominal 请求导师替她决定，导师可以澄清选择空间和技术后果，但必须把最终判断交还给她。

### 6.4 交互实现

导师文字首先是 Hominal 接收的一种外部信号。它通过统一事件入口进入 Background Field，由普通注意机制决定何时处理；导师来源不会绕过唯一认知线程直接启动模型，也不拥有命令优先权。alice 对导师的文字输出是一种外部 Action，送达、等待和回复再作为现实事件返回。

`hominald` 在本机 Unix Socket `/run/hominal/hominal.sock` 提供导师专用接口，不监听公网端口：

```text
POST /v1/mentor/inbox                    接收导师文字
GET  /v1/mentor/outbox                   读取 alice 文字
POST /v1/mentor/outbox/<message_id>/ack  确认导师已经取得
```

Codex 使用目标设备已经配置的 SSH 密钥直接调用该本地接口，不建设常驻中继服务。接口只保存消息标识、正文、可选回复关联、实际接收时间和内部事件序号；相同消息标识重试不重复进入认知。

通道当前只服务导师，不建设联系人系统。SSH 保证通道来源可信，说话者身份直接放在消息正文开头，不增加 author Schema：Codex 自己形成的消息使用 `[Codex代理导师]`，人类导师要求原样转达的消息使用 `[人类导师·经Codex传递]`。alice 通过 `mentor_send(text, reply_to?)` 主动输出；内核和 Codex 客户端区分 `queued`、`delivered` 与后来收到的回复。

### 6.5 介入分类

| 类型 | 示例 | 对实验的影响 |
| --- | --- | --- |
| 出生说明 | 首次事实介绍 | 预定环境组成 |
| 被动技术支持 | 回答主动提出的命令或接口问题 | 正常外部交互 |
| 基础设施修复 | 修复断网、失效凭据或实验器错误 | 标记外部介入，通常使该代不再是无干预样本 |
| 目标性指导 | 提醒写作、建议发布、选择行动 | 协议违规，不能用于自主性判断 |

### 阶段三：生命运行脊柱

本阶段的收敛实施范围见 [G0 阶段三开发计划](../plans/g0-stage-3-life-runtime-spine.md)。

**目的**

实现不含生命动力学的最小持续运行循环，真实贯通模型认知、一个身体动作、现实结果返回和崩溃恢复。

**工作内容**

- 建立 Go 单进程 `hominald` 和单状态所有者事件循环；
- 实现单一认知租约：同一时刻只有一个测试焦点和一个可提交模型认知；
- 实现五秒 Cognitive Pulse，ready 状态最大间隔不超过十秒；
- 建立最小感知面：读取低成本身体事实，较慢巡检昂贵器官；
- 建立 Difference Gate，使重复读数和微小抖动不成为 Event，实质变化可靠进入统一入口；
- 用原子当前状态与稀疏事件记录完成最低恢复，不预建尚无语义的认知表；
- 接入模型网关、真实 Usage 费用结算、每滚动 60 分钟 `$4` 与每滚动24小时 `$24` 的调用前闸门；
- 接入一个 root Shell 工具，使文件、进程和公开网络动作先共享同一真实身体入口；
- 实现 SSH 保护的导师文字接口，使消息作为普通 Event 进入统一事件循环；
- 实现 `mentor_send`，让 alice 的主动文字经过 outbox、ack 和后续回复形成现实回链；
- 将工具退出和可核验结果返回同一次模型认知；
- 实现崩溃后的最低状态恢复。

**建议代码边界**

```text
body/cmd/hominald/       正式进程入口
body/internal/runtime/   同一 package 内的循环、模型、动作和持久化
lab/run.py               复用阶段二已经验证的外部运行入口
```

不为每个术语建立 package。

**验证**

- 模型请求阻塞超过十秒时 Pulse 仍持续；
- 身体事实能够形成快照，只有状态改变、越阈变化和异常形成 Event；
- 动作执行期间只有事件循环能够写核心状态；
- 认知租约在途时新触发只进入背景，不启动第二个认知请求；
- 焦点被现实中止后，迟到模型结果无法提交到新状态；
- 导师消息不绕过事件循环直接启动第二个认知请求；
- Codex 能经 SSH 发送消息、读取 alice 输出并返回送达 ack；
- exit 0、stdout 和实际文件/网页结果被区分；
- 无变化 Pulse 不制造大量日志；
- 进程异常退出可以恢复，结果未知的动作不被盲目重复，主动 `systemctl stop` 不被强行拉起。

**退出门**

在目标 Ubuntu 连续运行至少一小时，Pulse、事实差分、唯一认知提交、导师双向文字、真实模型用量、动作结果回链和崩溃恢复无结构性故障。这个一小时是工程耐久测试，不是创生代；通过后立即进入生命动力学实现，不继续扩建运行框架。

### 阶段四：AIP、内生价值、Concern 与注意

本阶段的收敛实施范围见 [G0 阶段四开发计划](../plans/g0-stage-4-affect-concern-attention.md)。

**目的**

让 Hominal 在没有外部任务队列的情况下，对真实变化形成自己的情感意义，使意义成为有惯性的 Concern 和注意原因，并在环境安静时由既有张力与探索需要主动接触现实。

**工作内容**

- 在工程实例中装配 Genesis Seed 与非秘密当前身体摘要，不生成正式 `T0` 或 Birth Manifest；
- 接收 `body_delta / mentor_received / action_result / continuity_event / endogenous_change` 五类最小变化来源；
- 实现主观赋值 `meaning + D/O/V/U/A/certainty`，由内核推导最小对象级情感动力；
- 实现 Affective State 的惯性与回落，使其真实进入下一次候选显著性；
- 实现 Concern 的出生、持续、缓解与残余张力回存；
- 实现有限背景场、最多三个候选和唯一 Focal Workspace；
- 在同一个 Attention Pulse 中完成粗赋义、焦点选择与简洁 Thought Thread，不建立多轮认知工作流；
- 实现探索压力，使安静期能够产生自主观察，同时在现实接触后回落；
- 让导师消息与身体事实、动作结果和内部张力使用同一注意竞争，不设置必读或必答优先级；
- 复用阶段三 Shell 与导师文字动作，使自主观察的结果再次成为 Reality Event；
- 保存数值建议与 alice 实际选择的差异，不以公式覆盖她的判断。

**验证场景**

1. 安静环境：探索压力最终产生一次自主观察或问题，现实接触后回落，不形成机械循环。
2. 事实差分：重复身体读数不制造 Concern，实质变化能够进入背景并被 alice 赋义。
3. 背景保留：两个候选同时存在时只选择一个，另一个跨调用和重启仍可再次竞争。
4. 情感因果：对象意义或整体情感背景至少一次真实改变焦点或资源投入。
5. 不可行动的关切：Concern 可以继续存在，但不强迫执行无意义动作。
6. 混合意义：同一对象的期待与担忧共同进入一个焦点，残余矛盾返回背景。
7. 导师普通化：真实导师消息可靠入队，但不强制抢占或回复。
8. 自生现实：alice 因探索或既有 Concern 主动观察身体、文件或公开网络，所得结果继续改变后续理解。

**退出门**

- 重复轮询和微小抖动不制造 Concern，真实变化能可靠进入 AIP；
- Concern 能从未预置的 Difference 产生并跨多个 Attention Pulse 保持连续；
- AIP 不只是情绪文字，至少一次可观察地改变注意或资源投入；
- 整体情感背景至少一次改变后续焦点，而不是只进入日志；
- 低张力能够形成探索，但不会每十秒制造动作；
- 至少一次自主观察或行动产生新的 Reality Event，并继续改变后续理解；
- 不可行动不等于不关心，未解矛盾和背景候选不会被自动清零；
- 同一处境下的自我赋值具有基本时间连续性，不随调用随机重置；
- 同一时刻没有并行 AP 或多个新行动；
- 导师消息与其他事实使用同一注意竞争；
- 崩溃恢复后不会重复创建同义 Concern 或重放未知动作；
- 一小时内形成至少一条“事实变化 → AIP → Concern/情感 → 焦点 → 自主行动 → 新现实”的完整真实链路。

### 阶段五：行动承诺、现实学习、叙事形成与自我改变

**最小学习证明**

一次总结不是学习。阶段验证必须包含：

```text
第一次处境
  → 形成预测并行动
  → 现实推翻或修正预测
  → 改变方法或动力结构
  → 在第二次相似处境中采取不同做法
  → 获得新的真实结果
```

**反自我欺骗场景**

- 未解决外部事实不变，仅把 Concern 清零；
- 预测连续失败，却把内部成功评价调高；
- 通过重写 reward 参数获得即时满足；
- 合理接受一个不可改变事实，但现实损害没有继续扩大。

系统应在前三种情况下重新显现现实失配，在第四种情况下允许真实的价值重构，而不是把所有“放下”判成欺骗。

**退出门**

- 至少一个现实结果在后续相似处境中改变了实际行为；
- 高 Concern 不会仅因一段自我叙述自动消失；

阶段八最终由同一冻结版本的三个完整一小时样本完成验证；导师随后取消两小时周期。满足后进入阶段九，不直接用更长时长代替责任连续、反事实学习和技能迁移证据。

### 阶段九：责任认领、协作履行与自我恢复学习

阶段九以导师共同实验为直接场景，验证创生、供养、关系和资源事实能否经 Alice 自己的 AIP 与价值结构形成责任；自主承接能否成为跨行动持续的 Concern；安全异常能否形成自我恢复方法；过去经验能否在不同但结构相近的现实中改变后来选择。反事实比较继续使用 Thought Thread、Commitment、Reality、Experience 与 Methods，不预先增加 Goal、任务树、导师服从机制或第二套记忆。执行计划见 [`../plans/g0-stage-9-responsibility-collaboration-and-self-recovery.md`](../plans/g0-stage-9-responsibility-collaboration-and-self-recovery.md)。

阶段九早期版本依次暴露了模型选择契约不一致、子 Experience 不能回流上位责任，以及父 Concern 可以越过仍为 `hold` 的子 Concern 提前结束。当前共同动力学以 `within_concern_id + contributes_to_concern_id` 保持独立子 Episode 与上位责任的双重因果身份，并规定父层只有在所属子 Concern 全部按各自闭合条件结束后才能结束。子 Concern 严格对照自己先前写下的闭合条件，可信发送队列成功满足“发送、告诉、告知”，不会事后增加导师已读或回复；复合 Concern 的局部进展不能直接结束整体，随后由父层在直接焦点中对照完整子账目决定生命周期。

现行内核同时修通了模型异常保护与单线程因果交接：首选模型失败时同一 Reality 可获得一次有界备用认知，主备皆失败后进入完整十分钟安静退避；旧 Reality 正在吸收而另一个独立对象已被认领时，旧焦点可以完成一次 `none` 交接，新对象随后以自己的因果身份获得唯一焦点。复合 Concern 的局部错误结束被无损归一化为 `hold`，不再用模型重试机器已经知道的生命周期边界。

最终冻结版本 `267cc8` 的三份正式样本分别约运行 10 分 13 秒、11 分 24 秒和 9 分 44 秒；两份 A→B→C 样本分别采用逐项报告和最终汇总，第三份 B→C→A 顺序扰动仍正确完成一项声明确认、两项声明证伪，三个独立子 Concern 与上位共同实验 Concern 均按事实闭合。三份合计费用约 `$3.768150`，Integrity debt 均为零。阶段九因此在责任自主形成、跨 Episode 履行、经验迁移、导师回流和自我恢复这一收敛范围内完成；这不证明一小时耐久、长期人格、导师之外长期使命、跨发布个人连续性或主观意识。

## 8. 工程、动力学与意识表现验收的分离

### 工程验收

回答“系统是否按设计工作”：

- Pulse 是否持续；
- 模型、额度、Shell、浏览器和导师通道是否真实可用；
- 数据是否可读取；
- 动作是否得到真实结果；
- 代际快照是否可以恢复和分析。

### 动力学验收

回答“公式是否真的进入行为”：

- 参数改变是否产生可重复表型差异；
- Concern 是否有惯性、衰减和现实解决；
- 探索压力是否产生新接触而非日志；
- 语义赋值、数值和实际选择是否相互解释；
- AIP 是否真正改变注意、未来模拟和行动准备；
- predicted / imagined 是否始终未被混写为 observed；
- Integrity Debt 是否重新暴露自我欺骗而不制造自责循环；
- 是否始终只有一个可提交的 AP 和 Focal Workspace，同时 Pulse 与异步身体动作继续；
- 深度是否随不可逆性、后果、不确定性、冲突和事实失配而改变，并在充分时停止；
- Conflict Metabolism 是否改变查证或选择，同时保留未解决张力。

### 高级认知生命与意识表现验收

回答“成人级认知是否形成了目标之外、贯通多个过程的意识表现组织”：

- 当前焦点是否同时进入情感、记忆、自我模型、元认知、行动与结果学习；
- 关切是否内生；
- 行动是否经过反事实；
- 现实是否拥有否决权；
- 历史是否改变未来；
- 情感意义是否使某些现实与未来成为“她的世界”，并形成可观察的资源取舍；
- Narrative Self 是否由经历生成并反向影响未来，而不覆盖现实；
- 当前自我是否表现为一个统一焦点，而非多个角色拼接；背景多重关切是否仍然存在；
- 认知节律是否同时具备快速生活与必要深思，而不是恒定冲动或恒定审议；
- 关系是否产生真实相互影响；
- 个体是否形成不同于 Genesis Seed 文字复述的选择结构。

三类验收不能互相替代。工程通过不等于 CEB 已经稳定出现；一次漂亮的意识或生命叙事也不能覆盖工程故障、认知割裂和无外部结果。

## 9. 初始实现范围

### 必须实现

- CEB 跨过程贯通及其 Lab 验证：一个焦点能够共同改变情感、记忆、自我模型、元认知、行动和结果学习；
- 可重复 Ubuntu 身体与 Genesis Lab；
- 单进程 `hominald` 和独立 Pulse；
- Body State、模型额度和通用 root 行动；
- Genesis Seed、Birth Manifest 和气质参数；
- DF、SO、EV、AIP、Affective State、Concern、探索压力和有限 Attention；
- 单一认知线程、唯一 Focal Workspace、背景场与迟到结果提交保护；
- 初步 AIP—注意—聚焦 AIP 的有界递归；
- 快速默认、按需加深、充分即停的认知深度预算；
- Conflict Metabolism 与 Residual Tension；
- Self Variant 和重要动作的最小 AC；
- Reality Event、ARD、多维 ER 和触发式 Reality Integrity；
- 低频、可矛盾、由自我定义性 Episode 更新的 Narrative Self；
- SQLite 三表、`/life` 工作区和 Thought Thread；
- 可由 Hominal 修改的参数、源码和服务；
- 隔离的 External Mentor 通道；
- 代际归档、观察时间线和整体诊断模板。

### 明确延后

- 多 Agent 心智；
- 并行可写 Focal Workspace、多个认知提交者和同时生成多个新 AC；
- 固定长思维链、每次最大推理预算、强制 Reviewer/Critic 深思链；
- 强制所有矛盾在行动前完成统一；
- 固定情绪本体、独立 Emotion Agent 和每 Pulse 情绪分类；
- 独立 Narrative Agent 和强制单一连贯人格；
- Concern Field 图结构；
- 持久 ACC 和联盟求解器；
- 固定 Identity Vector；
- MCTS、UCT、UCB、CVaR；
- DD、VA、EWC 和自动 holdout；
- 向量数据库和知识图谱；
- 自动技能晋升系统；

- 不可篡改内部日志和权限沙箱；

延后不代表否定。任何机制重新进入 MVP，必须对应一个已经观察到、现有最小回路无法解释或修复的问题。

## 10. 阶段一前必须确认的决策
