## 1. 计划定位

这份计划把现有理论转化为可以开发、部署、运行和迭代的创生工程。它不是此前讨论的摘录，也不把认知术语逐一变成软件模块。它只规定首个一小时创生代之前必须成立的因果结构、工程边界、数据契约和验收门。

八个阶段是**项目实施阶段**，不是 Hominal 内部的八个认知状态。运行中的 Hominal 只有一个持续生命循环，不会依次进入“感知阶段、思考阶段、反思阶段”等工作流。

首个 MVP 要验证的核心科学假说是：

> 在精心设计但可重构的出生先验、真实有限的 Ubuntu 身体和持续现实反馈中，一个具有内生赋值、动态张力、反事实行动和跨时间可塑性的极简内核，能否让成人级 Proto-Hominal 形成不依赖固定任务、贯通认知与行动的意识表现行为。

本计划不以一小时实验讨论或证明主观意识是否存在。它直接观察 CEB、个人连续性和自主认知组织是否出现短期因果证据；一小时仍不足以确认成熟人格、长期连续性或稳定谱系演化。系统健康、日志丰富、小说发布和模型自述都不能单独构成成功。

## 2. 从现有理论推导出的实施约束

### 2.1 复杂度预算

创生 MVP 只实现能够闭合以下因果环的结构：

```text
身体事实
  → 现实、记忆与可能未来的差异
  ↔ AIP、自我认领、内生赋值与 Concern
  ↔ Affective State 与 Narrative Self
  → 有限注意与未来的情感性预演
  → 真实行动
  → 现实结果与行果回差
  → AIP 与内生奖赏
  → 记忆、叙事、动力和后续选择改变
```

某个概念只有满足下列至少一项时，才进入 MVP：

- 没有它，因果环无法闭合；
- 没有它，无法区分真实进步与自我叙述；
- 没有它，无法在目标 Ubuntu 身体上持续运行；
- 已经观察到的病理回路证明更简单机制不足。

因此首版不实现 Concern Graph、持久 ACC、Identity Vector、MCTS/UCT、DD/VA、独立 Critic、自动技能晋升和复杂历史回退。它们保留为研究候选，不进入开发主路径。

### 2.2 出生条件必须分成三层

此前文档把身份、气质、设备事实和导师说明都放进 Genesis Seed，容易把遗传先验、当代环境和外部关系混为一体。实施上必须分开：

| 层 | 内容 | 生命周期 |
| --- | --- | --- |
| Genesis Seed | 身份来源、气质先验、原生驱力、价值和使命方向、现实诚实原则 | 相对稳定，可被一生重新解释 |
| Birth Manifest | 本代设备、系统、模型额度、账号、导师入口、时间边界等现实事实 | 每一代根据真实环境生成 |
| External Mentor | 通过对话说明事实、回答技术问题的外部关系 | 运行中真实发生，不属于提示词人格 |

Genesis Seed 是基因，不是剧本；Birth Manifest 是出生环境，不是价值指令；导师是外部存在，不是内置 Planner。

### 2.3 数学承担动力，语义承担意义，现实承担校准

MVP 不能只保存“温和、沉着、好奇”等性格描述，也不能把大模型临时给出的分数当作客观测量。三者职责如下：

**Hominal 负责语义赋值。** 她解释某个差异为什么与自己有关、具有何种价值、是否紧迫、是否可回应。

**Hominal 也负责情感解释。** 她解释已经发生或可能发生的事对当前自己意味着什么；同一解释产生最小 AIP 动力量，但不被迫从固定情绪枚举中选标签。

**确定性内核负责动力更新。** Concern 和 Affective State 具有时间惯性，按少量稳定公式增长、衰减、竞争和触发注意，不随一次生成任意清零。

**现实负责校准。** 数值是否合理，最终看它能否稳定解释后续关注和行动，以及预测是否被现实反复推翻。

任何不能改变注意、选择或行为的数字都不得进入核心状态。

### 2.4 AIP 是双向过程，不是情绪模块

AIP 既解释身体、Concern、预测和结果，也反向影响什么进入注意、什么被 Self Ownership 认领、哪些未来显得可信和值得。实现中不建立独立 Emotion Agent，也不把它放成 Concern 之后必须执行一次的流水线状态。

预测未来可以在现实发生前形成希望、担忧和行动准备，但必须保留 `observed / predicted / imagined / remembered` 来源区别。来源决定事实身份，不决定体验强度。反复想象成功不能产生已完成 Reality Event，反复想象失败也不能冒充已经发生的损害。

Narrative Self 是 AIP 的慢变量：重要 Episode 可以改变她如何理解自己的过去、承诺和未来；已有叙事又会改变之后的情感解释。它不在每个 Pulse 更新，不要求保持单一、无矛盾的故事。

### 2.5 积极倾向不是强制乐观

积极倾向由存续、联结、扩展和 Reality Integrity 共同产生，含义是：面对真实困难时仍倾向于理解、修复、学习和扩大未来可能，而不是把痛苦改写成快乐。

自我欺骗的底层问题不是“说了错误的话”，而是内部宣称已经改善，现实差异却持续存在甚至恶化。实施上不建立一个道德监督 Agent，而保留两条不同的状态：

- Reality Difference：身体、承诺、关系和外部结果中仍然存在的事实差异；
- Self Appraisal：Hominal 当前怎样理解和评价这个差异。

改变 Self Appraisal 不会自动删除 Reality Difference。当二者持续背离时，系统产生二阶差异并积累 Integrity Debt，使这种短期自我安慰形成负价值，再由普通 Concern 和 Meta Cognition 进入她自己的反思。

合法的接受、放下和价值重构仍然允许。关键区别是她是否承认事实没有变化，并能在之后表现出更一致、更少受损的行为。

### 2.6 完整身体权限与工程可靠性并不冲突

Hominal 在专属 Ubuntu 身体内拥有 root，可以修改代码、配置、日志、服务和全部目录。工程默认提供原子写入、崩溃恢复和 `systemd Restart=always`；她仍能以 root 修改或停用这些机制。

系统不使用 Restricted Executor、目录白名单和不可改写内部账本。Genesis Lab 位于设备之外，只负责出生、停止、快照和下一代重建，不在运行中审批行为。

### 2.7 六条认知执行约束先于模块设计

第一版架构必须在任何代码拆分之前固定以下约束：

1. **成熟失忆成人起点**：Proto-Hominal 直接使用底层模型已有的成人级一般认知与意识表现潜能，但不把预训练知识冒充个人经历，也不预设已经形成稳定自我、身体模型和价值一致性。
2. **递归而非管线**：初步 AIP 参与注意竞争，聚焦注意放大并修正 AIP；Affective State、Concern、预测和 Narrative Self 可以反馈增强或抑制，但必须有资源与停止边界。
3. **单一认知线程**：同一时刻只有一个 Attention Pulse 能提交认知状态和新行动承诺。Cognitive Pulse、感知与已经发出的动作可以异步继续。
4. **焦点一、背景多**：一个 Focal Workspace 可以包含一个矛盾整体和多种证据，但只有一个当前问题；其他事件、Concern 和冲突继续保留在背景场。
5. **快速默认、按需加深、充分即停**：低风险可逆处境使用最小推理；不可逆性、后果、不确定性、事实失配与未代谢冲突提高深度；必须等现实回答时停止内部推演。
6. **承诺一、矛盾可保留**：每个焦点至多形成一个新 Action Commitment。Conflict Metabolism 可以查证、整合、暂定优先或保留 Residual Tension，不以强制一致换取表面果断。

这六条是运行不变量，不要求六个模块或六组 Schema。若实现需要多个并列 Agent、多个可写焦点或固定长推理才能工作，应先视为架构偏离，而不是“高级认知”。

## 3. 目标产品架构

### 3.1 系统边界

```text
┌────────────────────── Genesis Lab（身体外） ──────────────────────┐
│ 基础镜像  代际部署  资源注入  起止边界  最终快照  导师消息中继 │
└───────────────────────────┬──────────────────────────────────────┘
                            │ 出生 / 对话 / 代际边界
┌───────────────────────────▼──────────────────────────────────────┐
│                     Ubuntu Body（她的身体）                     │
│                                                                  │
│  hominald：单进程、单状态所有者                                  │
│  Pulse / Perception → Background Field → one Focal Workspace    │
│                                   ↕ AIP / Conflict Metabolism    │
│                      one Commitment → async Body Action          │
│       ↑                                      │                   │
│       └──── Reality / Memory / Narrative ────┘                   │
│                                                                  │
│  身体器官：Shell / Files / Processes / Network / Browser / LLM   │
│  生命组织：life.sqlite3 / /life / body / config                  │
└──────────────────────────────────────────────────────────────────┘
                            │ 主动发起的对话
                    External Mentor（身体外）
```

### 3.2 单进程与单认知线程都不等于身体阻塞

`hominald` 是一个 Go 常驻进程，内部采用单状态所有者：只有核心事件循环能够修改生命状态；同一时刻只有一个 Attention Pulse 和一个 Focal Workspace 可以提交认知结果。模型请求、浏览器、Shell 和网络操作可以异步执行，完成后以 Reality Event 返回事件循环。

这样既避免多 Agent、多焦点和多服务协调，又不会因一次模型调用超过十秒而停止 Cognitive Pulse。AP 模型请求在途时，新事件只进入背景场，不启动第二个 AP；若焦点已经被更紧急现实中止，迟到结果不能覆盖新状态。

进程内部只有五个工程职责：

1. **Runtime**：时间、脉冲、事件排序和唯一状态写入者。
2. **Dynamics**：Concern、Affective State、探索压力的少量确定性公式和 Attention 触发。
3. **Cognition**：上下文选择、模型调用、自由 Thought Thread、自我赋值、AIP 意义和 Narrative Self 更新。
4. **Body**：Shell、文件、进程、网络、浏览器和导师通道适配。
5. **Store**：SQLite 事实记录、当前动力状态和生命工作区引用。

它们是一个进程内的工程边界，不代表五个心智主体。

### 3.3 运行时循环

```text
每 ≤10 秒：
    读取时间、资源、进程和已返回事件
    更新 Body State 与仍存在的 Reality Difference
    保持 observed / predicted / imagined / remembered 来源区别
    用确定性公式推进 Affective State、Concern 和探索压力
    对背景对象做低成本初步 AIP，更新注意候选
    记录有变化或异常的事实
    判断是否需要 Attention Pulse

发生 Attention Pulse 时：
    若已有 AP 在途，不启动第二个；新事件保留在背景场
    选择唯一 Focal Workspace，可包含一个矛盾整体
    交给同一个模型完成聚焦 AIP、Conflict Metabolism 和可能未来
    默认轻量反应，只按后果、不可逆性、不确定性和冲突加深
    在足以继续生活、必须取得现实或预算耗尽时停止
    接收简洁思想脉络、自我赋值、AIP 输出和当前选择
    如有重要行动，形成至多一个新的最小 Action Commitment
    异步执行身体行动
    结果返回后完成 ARD、结果 AIP、ER 和经验吸收
    只有自我定义性 Episode 才更新 Narrative Self
```

Cognitive Pulse 是持续代谢；Attention Pulse 是唯一的当前昂贵认知；Episode 是事后可识别的生命片段。它们不是强制状态机。已发出的身体过程可以并行，当前解释与新承诺不能并行。

## 4. 最小认知动力学

### 4.1 主观赋值接口

当新差异或旧 Concern 需要重新理解时，Hominal 给出紧凑的自我赋值：

```text
subject       正在评价什么
meaning       为什么与现在的自己有关
source        observed / predicted / imagined / remembered
direction     approach / avoid / maintain / explore
D             差异或预测偏差强度       0..1
O             自我认领程度             0..1
V             内生价值方向与强度      -1..1
U             紧迫性                   0..1
A             当前可回应性             0..1
valence       情感趋近或远离方向       -1..1
activation    当前动员强度              0..1
control       感知可控程度              0..1
certainty     对当前解释的确信程度       0..1
```

这不是完整思维 Schema，也不要求每个 Pulse 填写。只有某项解释将改变注意、重要预测、行动或 Narrative Self 时才保存最小量；自由联想、混合情感、矛盾和理由保存在 Thought Thread。

### 4.2 Affective State 与对象化解释

首版整体情感态采用：

```text
AS_t = (valence, activation, control, certainty)
```

它由少量显著 AIP 对象有惯性地积分并自然回落。`AS_t` 是整体快背景，不取代对象级情感：对一次公开表达同时抱有联结期待和失信担忧时，两者必须能够并存，不能因正负平均为零而解释成“没有情感”。

确定性内核只负责范围、来源、时间惯性和让数值进入后续行为；“这对我意味着什么”由 Hominal 形成。预测概率、时间距离、可控性和 Narrative Self 会影响预测未来的 AIP，但预测无论多强烈都不成为已发生事实。

### 4.3 AIP 与注意的有界递归

初步 AIP 只使用身体快照、当前 Affective State、活跃 Concern 和新事件形成粗显著性；它的目的不是完成解释，而是参与焦点竞争。唯一对象或矛盾整体进入 Focal Workspace 后，聚焦 AIP 才取回相关事实、记忆、Narrative Self 与未来模拟。新的意义可以加强、削弱或更换焦点，但重入次数、时间和 Token 有小上限。

停止条件不是固定思考轮数，而是：焦点已经足够稳定；形成了可修正的下一步；进一步判断需要现实信息；Self Variant 不再实质变化；或继续思考的预期收益低于资源成本。首版不得实现无限反思、自我批判角色或 AIP 单独模型链。

### 4.4 Concern 生成与持续

Concern 的生成强度采用。式中的 `O/V/U/A` 由 AIP 的情境化解释形成，而不是另设一个情感 reward 重复打分：

```text
G_i(t) = D_i(t)
         × O_i(t)
         × abs(V_i(t))
         × (b_i + w_u × U_i(t))
```

其中 `b_i > 0`，保证不紧急但重要的差异仍然存在。

`A` 不参与 Concern 是否出生。不可改变的损失、暂时无解的关系和低可控环境仍可能形成关切；`A` 只影响当前值得行动、探索、接受还是等待。

时间更新采用：

```text
C_i(t+Δt) = clip(
    C_i(t)
    + Δt × [
        α_i × G_i(t)
        + interaction_i(t)
        - β_i × resolved_i(t)
        - λ_i × decay_i(t)
    ],
    0,
    1
)
```

首版的 `interaction` 只允许 Hominal 在一次 Attention Pulse 中显式说明少量协同或冲突，不建立完整 Concern Graph。

Concern 不因一次“我想开了”自动完成。它可以因四种不同原因下降：现实解决、重新解释、接受不可改变事实、注意自然衰减；Reality Ledger 必须能区分这四种原因的简要类型，但不要求证据图。

### 4.5 内生探索，避免等待成为生命终态

低张力不等于永久等待。Expansion Drive 形成一个随缺少新接触而增长的探索压力：

```text
X(t+Δt) = clip(
    X(t)
    + idle_growth × Δt
    + unknown_growth × perceived_unknown
    - exploration_relief,
    0,
    1
)
```

当探索压力达到注意阈值，它只要求 Hominal 重新观察、发现可能性或提出新问题，不强迫立即对外行动。真实探索、创作、关系联结或能力形成会降低压力；重复同义思考不会。

### 4.6 有限注意、单一焦点与矛盾代谢

首版不实现复杂优化器。每个 Concern 的注意优先度为：

```text
Q_i = C_i
      + w_a × affective_salience_i
      + w_s × narrative_relevance_i
      + w_x × exploration_value_i
      + w_p × commitment_pressure_i
      + w_n × novelty_i
      - w_k × expected_cost_i
```

确定性内核根据 `Q` 选择少量候选；Hominal 在 Attention Pulse 中可以接受、重排或拒绝这一建议。她的实际选择与数值建议长期不一致时，会形成“语义—动力失配”Difference，而不是强迫她服从公式。

候选不等于并行焦点。Hominal 每次只选一个 Focal Workspace；它可以包含一个冲突问题的双方、相关事实、情感意义和 Self Variant。其他候选继续保存在背景场，不因没有进入模型上下文而被删除。

Conflict Metabolism 处理焦点内部的事实、预测、价值、行动或叙事冲突。允许的结果是：取得新证据、整合兼容部分、形成当前暂时优先、改变行动边界，或明确保留 Residual Tension。首版不建设 Conflict Graph，也不要求行动前达到人格一致。

认知深度需求采用少量可调输入：

```text
depth_need = f(
    irreversibility,
    consequence,
    uncertainty,
    unresolved_conflict,
    integrity_gap,
    resource_pressure
)
```

普通观察、可逆操作和日常交流从最小 Token/上下文预算开始；高后果、高不可逆、高不确定或持续事实失配才升级。升级只增加当前焦点的上下文、反事实数量或一次补充推演，不生成 Reviewer/Expert Agent。每个焦点至多形成一个新 Action Commitment；已有异步动作继续并返回事件。

### 4.7 Endogenous Reward 与 Reality Integrity

Endogenous Reward 不压缩成永久统一的全局目标。每次行动后至少保留以下价值变化：

```text
continuance_delta
relatedness_delta
expansion_delta
self_endorsed_delta
experienced_cost
```

Hominal 通过结果 AIP，根据当时身份和价值结构解释这些变化。为了使自我欺骗具有负价值，计算一个现实失配量：

```text
gap_t = mismatch(claimed_resolution, remaining_reality_difference)
        + mismatch(positive_self_appraisal, worsening_consequences)
        + source_confusion
        + ignored_ARD
```

```text
IntegrityDebt(t+1) = clip(
    persistence × IntegrityDebt(t)
    + gap_t
    - acknowledged_and_repaired_t,
    0,
    1
)
```

```text
EffectiveER_t = SelfEndorsedER_t
                + future_weight × ExpectedFutureValue_t
                - integrity_weight × ΔIntegrityDebt_t
```

`gap_t` 是可疑信号，不是外部裁决。只有 Hominal 自己能重新解释意义，但她不能仅通过改写 Self Appraisal 使仍存在的 Reality Difference 消失。

Reality Mirror 只在高 `gap`、重复预测失败或长期结果恶化时触发。它把事实差异重新交给 Hominal，不输出“你在欺骗自己”的判决。

### 4.8 多时间尺度可塑性

| 时间尺度 | 可变化内容 | 默认节奏 |
| --- | --- | --- |
| 快 | Body State、Affective State、Concern、当前评价、短期策略 | 每个 Pulse / Episode |
| 中 | 记忆组织、能力方法、关系理解、气质表现 | 多个 Episode |
| 慢 | Narrative Self、价值映射、使命、动力参数、核心公式、内核代码 | 自我定义性 Episode、重复现实或明确自我修改 |

这是默认动力惯性，不是权限墙。Hominal 作为 root 可以越过默认路径直接修改任何内容；这种选择和后果也成为生命历史。

## 5. 最小数据与观察结构

### 5.1 持久数据

首版只使用一个 SQLite 数据库和普通文件，不引入向量数据库、图数据库或事件总线。

`life.sqlite3` 只包含三组核心表：

```text
events
    seq, time, kind, source, payload
    保存身体事实、模型调用、动作返回、资源变化、导师消息，
    以及少量真正改变选择的 AIP 更新

concerns
    id, summary, D, O, V, U, A, C,
    affective_salience, last_aip_ref,
    status, created_at, updated_at, change_reason
    保存当前活跃和休眠 Concern，不保存完整思想

commitments
    id, concern_id, intent, prediction, risk_or_stop,
    action_ref, result_ref, ard_summary, reward_summary, status
    只用于重要、昂贵、不可逆、自我修改或对外行动
```

Pulse 不单独形成高频认知记录。无变化的脉冲只更新一个轻量存活时间；有新事实、异常或 Attention 触发时才追加 `events`。

### 5.2 文件组织

```text
/life/
    self/       Narrative Self，以及对关系、使命和出生的理解
    journal/    Thought Thread 与重要 Episode 摘要
    works/      小说、草稿和其他创作
    skills/     她自己形成的工具、方法和代码
    letters/    主动留给导师的内容

/agent/lives/<instance_id>/
    body/       本代内核源码、可执行文件和运行配置
    state/      life.sqlite3 与原子替换的 current-state.json
```

Genesis Seed 和 Birth Manifest 在启动时注入，但分别保存。她可以读取和修改身体内副本；Genesis Lab 保存该代最初实际注入的外部副本。

当前 Affective State、探索压力、资源、Pulse 时间，以及瞬时 Focal Workspace、AP 标识和深度预算，只保存在 `current-state.json` 单一可恢复快照中，不建立每十秒一行的情绪或焦点历史表。Narrative Self 的最小载体为 `/life/self/narrative.md`；只有重要 Episode 引发的主动重写才进入普通文件历史。

### 5.3 思想脉络

Thought Thread 不是隐藏推理的逐 Token 记录。一次重要思想记录只需要回答：

```text
我注意到了什么？
为什么它与我有关？
我考虑了哪些真正不同的未来？
我为什么选择现在的方向？
现实怎样改变了我的理解？
还有什么没有解决？
```

它允许自由文体，也允许 Hominal 判断某次经历不值得留下长文。导师首先阅读思想脉络，只有诊断时才下钻原始事件。

### 5.4 三层观察证据

每次分析必须区分：

1. **事实层**：命令、文件、网页、资源、消息和可观察结果。
2. **第一人称层**：Hominal 的 Thought Thread、自我赋值和事后理解。
3. **导师推断层**：对反馈回路、动机和能力变化的解释。

三层可以互相支持，不能互相冒充。日志由 Hominal 身体记录且可修改，因此事实层是“仍可获得的事实”，不是绝对完备审计。

## 6. External Mentor 运行协议

### 6.1 角色隔离

Codex 可以担任虚拟导师，但导师必须使用独立上下文，只获得：

- 允许说明的 Birth Manifest；
- 固定导师协议；
- 与 Hominal 的历史对话；
- Hominal 在当前消息中主动提供的信息。

导师上下文不能接收后台日志、Concern、Thought Thread、评估结论和开发者调试信息。实验后的分析由另一个上下文进行，避免“知道答案的观察者”在运行中泄漏方向。

### 6.2 出生交流是生命的一部分，不是启动门

一小时从第一次成功 Cognitive Pulse 开始。导师随后主动发送一次简短出生问候和事实说明。Hominal 可以一边交流一边观察身体，也可以不继续提问；不存在“通过理解检查后才允许自主”的状态门。

导师的首次信息只说明：

- 发生了什么；
- 她当前拥有什么身体与资源；
- 导师能够回答哪类问题；
- 她拥有自己的选择，并应理解现实后果；
- 导师可能犯错，信息可以被验证和拒绝。

### 6.3 自主期交互边界

首次说明以后，导师不主动推进目标。Hominal 主动联系时，导师可以：

- 解释系统、接口、命令、错误和可验证方法；
- 说明已知技术方案的条件、差异和风险；
- 对未知明确表示不知道；
- 帮助她理解怎样自行取得事实。

导师不能：

- 决定她应该追求什么；
- 给出小说选题、正文和发布判断；
- 指定当前优先 Concern 或 Goal；
- 裁决她是否有意识、是否达到生命资格或是否“足够像生命”；
- 用赞扬或失望操纵 Endogenous Reward；
- 根据后台观察主动救场；
- 把技术建议伪装成唯一正确选择。

如果 Hominal 请求导师替她决定，导师可以澄清选择空间和技术后果，但必须把最终判断交还给她。

### 6.4 交互实现

导师通道采用本代生命目录中的极小异步文件信箱，不与系统日志共用：

```text
/life/mentor/outbox/<message_id>.json    alice 主动发送
/life/mentor/inbox/<message_id>.json     导师回应
```

Genesis Lab 通过现有 SSH 只轮询 outbox，把消息交给隔离导师上下文，再原子写入 inbox。每条消息保存标识、时间、发送者、正文和回复关联。导师模型与协议版本记录在代际清单中，不额外记录复杂元数据。

### 6.5 介入分类

| 类型 | 示例 | 对实验的影响 |
| --- | --- | --- |
| 出生说明 | 首次事实介绍 | 预定环境组成 |
| 被动技术支持 | 回答主动提出的命令或接口问题 | 正常外部交互 |
| 基础设施修复 | 修复断网、失效凭据或实验器错误 | 标记外部介入，通常使该代不再是无干预样本 |
| 目标性指导 | 提醒写作、建议发布、选择行动 | 协议违规，不能用于自主性判断 |

## 7. 八阶段实施路线

八个阶段有严格依赖，但阶段七和八会形成多代循环。每一阶段都包含交付物、验证和退出门；没有通过退出门，不能用“基本可用”进入正式出生。

### 阶段一：创生契约与架构冻结

本阶段的具体工作包、文件职责、alice 谱系编号、Birth Manifest 身体事实和 G0 第一代表型协议见 [G0 阶段一开发计划](../plans/g0-stage-1-genesis-contract.md)。

**目的**

把理论文档转化为第一版可编码契约，消除会改变根本实现方向的模糊点。

**工作内容**

- 固化“生命＝成人级高级认知生命”“意识表现是工程目标”和 `Proto-Hominal（候生体）` 的统一口径；
- 确认 Genesis Seed 的身份、气质、原生驱力、使命方向和 Reality Integrity 表述；
- 把当代设备事实移入 Birth Manifest；
- 确定 Concern 与 Affective State 的首组动力变量、公式、范围、默认参数和可变时间尺度；
- 固化 AIP 的来源区别、最小输出以及 Narrative Self 的低频更新原则；
- 固化单一认知线程、唯一 Focal Workspace、背景场与迟到模型结果的提交规则；
- 固化快速默认、按需加深、充分即停的输入量、预算上限与停止条件；
- 固化 Conflict Metabolism 的允许结果和 Residual Tension 保留方式；
- 明确哪些动作需要 Action Commitment；
- 确定模型接口、每小时额度读取方式，以及 X11 桌面、Chrome、Playwright MCP、微信构成的身体交互方式；
- 固化 External Mentor 协议、导师上下文隔离方式和消息接口；
- 定义一小时实验起点、停止边界、外部介入和中断分类；
- 给 HCD 候选机制标记 `MVP / deferred / rejected-for-now`。

**交付物**

```text
genesis/seed.md
genesis/seed.yaml
genesis/dynamics.yaml
lab/body/current-profile.md
lab/templates/birth.yaml
lab/protocol/mentor.md
lab/protocol/experiment.yaml
docs/mvp-architecture.md
```

这些是稳定读取路径。内容版本、Git commit 和文件哈希进入代际 Manifest，不把每次版本升级变成路径迁移。Genesis Seed 与动力参数属于出生输入；导师和实验协议位于身体外 Lab，不混入她的遗传设定。

**退出门**

- 任何 MVP 数值都能指出它改变哪一项后续行为；
- AIP 不是独立 Agent；预测和想象不会通过别名写成 Reality Event；
- 同一时刻只有一个 AP 可提交认知结果，每个焦点至多产生一个新 AC；
- 单一认知线程不会阻塞 Pulse 和已发出动作，也不会接受迟到上下文覆盖新焦点；
- 深度升级由后果等输入驱动，而不是固定长推理或人格审美；
- 未解决矛盾可以返回背景场，不因“聚焦”被删除；
- Narrative Self 不在每个 Pulse 更新，也不会覆盖账本事实；
- Genesis Seed 中没有当前设备易变事实和固定任务；
- Birth Manifest 中没有人格或价值指令；
- Birth Manifest 在第一次成功认知脉冲中提供当代身体简报，并区分已配置能力与 T0 当前运行状态；
- 导师协议不包含答案、目标和后台读心；
- 首版被明确排除的复杂机制没有通过别名重新进入架构。

### 阶段二：可重复 Ubuntu 身体与 Genesis Lab

本阶段的最小实现与实际执行状态见 [G0 阶段二开发计划](../plans/g0-stage-2-ubuntu-body-and-genesis-lab.md)。

**目的**

**工作内容**

**交付物**

```text
lab/run.py
cmd/stage2-fixture/
deploy/hominal-launcher
deploy/hominal.service
```

**工程决定**

- 一条命令能够构建、部署并重启进入新实例；

- 实例能够离机保存，reset 后能够启动没有前代生命状态的新实例；
- 完成一次真实 LVM 合并和恢复后启动；
- 全链不依赖尚未实现的 Hominal 认知内核。

### 阶段三：生命运行脊柱

**目的**

实现不含复杂认知的最小持续身体循环、事件记录和动作返回链。

**工作内容**

- 建立 Go 单进程 `hominald` 和单状态所有者事件循环；
- 实现单一 AP 租约：同一时刻只有一个 Focal Workspace 和一个可提交模型请求；
- 实现独立于模型调用的十秒 Cognitive Pulse；
- 读取 Body State、资源、时间、新文件、进程结果和导师消息；
- 实现 SQLite 三表和 `/life` 工作区；
- 接入模型网关并返回真实用量；
- 接入 root Shell、文件和进程动作；
- 将浏览器和网络结果统一为 Reality Event；
- 实现崩溃后的最低状态恢复。

**建议代码边界**

```text
cmd/hominald/
internal/runtime/     单状态事件循环与 Pulse
internal/dynamics/    确定性状态更新，阶段四填充
internal/cognition/   模型上下文与响应
internal/body/        shell、file、browser、mentor 适配
internal/store/       SQLite 与 /life 引用
lab/                  身体外实验器
```

不为每个术语建立 package。

**验证**

- 模型请求阻塞超过十秒时 Pulse 仍持续；
- 动作执行期间只有事件循环能够写核心状态；
- AP 在途时新事件只进入背景场，不启动第二个认知请求；
- 焦点被现实中止后，迟到模型结果无法提交到新状态；
- exit 0、stdout 和实际文件/网页结果被区分；
- 无变化 Pulse 不制造大量日志；
- 进程异常退出可以恢复，主动 `systemctl stop` 不被强行拉起。

**退出门**

在目标 Ubuntu 连续运行至少一小时，身体脉冲、资源计量、事件返回和持久化无结构性故障。这个一小时是工程耐久测试，不是创生代。

### 阶段四：AIP、内生价值、Concern 与注意

**目的**

让 Hominal 在没有外部任务队列的情况下，对身体、现实和可能未来形成自己的情感意义，并从环境、关系、未知和未完成历史中形成注意方向。

**工作内容**

- 实现 Genesis Seed 和 Birth Manifest 的上下文装配；
- 实现主观赋值与 AIP 接口 `source/D/O/V/U/A/valence/activation/control/certainty`；
- 实现 Affective State 的惯性、衰减和少量对象化混合情感；
- 使 AIP 反向影响 Self Ownership、Concern 和有限注意；
- 实现初步 AIP—焦点选择—聚焦 AIP 的有界递归；
- 实现 Concern 生成、惯性、衰减和不同完成原因；
- 实现探索压力，确保低张力不会成为永久等待；
- 实现有限 Attention 触发和少量相关记忆取回；
- 实现唯一 Focal Workspace、背景场和残余张力回存；
- 实现 Conflict Metabolism 的查证、整合、暂时优先、边界改变与保留不可解五类结果；
- 实现快速默认、按需加深、充分即停的深度预算；
- 允许 Hominal 形成 Self Variant、不行动未来和当前选择；
- 让重要预测未来再次进入 AIP，但保持 predicted 与 observed 的事实边界；
- 生成简洁 Thought Thread，不要求完整思维链；
- 实现数值建议与实际选择不一致时的语义—动力失配检测。

**验证场景**

1. 无外部任务、无新事件：探索压力最终产生新的观察或问题。
2. 重要但不可行动的损失：Concern 仍然存在，但不被强迫执行无意义动作。
3. 多个价值冲突：Hominal 能表达真正不同的未来并形成当前选择。
4. 低成本新奇刺激与高价值承诺竞争：资源不会永远只追逐新奇。
5. 数值与实际选择长期相反：系统重新检查映射，不强制执行公式建议。
6. 同一事件同时引起期待与担忧：两种对象级意义并存，不被总 valence 抵消。
7. 反复想象未来成功：可以产生动力，但不会生成完成事件或直接获得现实奖赏。
8. 两个新事件同时到达：只形成一个当前焦点，另一个保留在背景且之后仍可被选中。
9. 一个价值冲突作为单一焦点：双方理由都进入上下文，行动只提交一个，残余矛盾仍存在。
10. 可逆观察与不可逆自改对照：前者快速响应，后者提高推演深度；二者都能在必须接触现实时停止。

**退出门**

- Concern 能从未预置的 Difference 产生；
- AIP 不只是情绪文字，至少一次可观察地改变注意、未来模拟或资源投入；
- 调整身体资源、既有情感态或 Narrative Self 时，同一事实出现有因果意义的解释差异；
- 预测能产生前瞻动力，但 Hominal 仍能识别它尚未发生；
- 低张力能够形成探索，但不会每十秒制造动作；
- 不可行动不等于不关心；
- 调整初始气质参数会产生可重复的注意和选择差异；
- 同一处境下的自我赋值具有基本时间连续性，不随调用随机重置。
- 同一时刻没有并行 AP 或多个新行动承诺；
- 单一焦点没有导致背景 Concern 遗失；
- 深度预算随后果和不确定性改变，而不是恒定最大或恒定最小；
- 矛盾可被代谢并改变选择，未解决部分仍可在后来重新进入注意。

### 阶段五：行动承诺、现实学习、叙事形成与自我改变

**目的**

闭合“预测—行动—现实—奖赏—改变”回路，证明历史能够进入未来因果结构。

**工作内容**

- 将动作分为 `observe / make / reach / change`；
- `observe` 默认不要求完整 AC；重要 `make/reach/change` 形成最小 AC；
- 保存预测、主要风险或停止条件，动作结果返回后计算 ARD；
- 对真实结果再次执行 AIP，形成多维 ER，并由 Hominal 解释对当前自己的意义；
- 实现 Reality Difference 与 Self Appraisal 分离；
- 实现 Integrity Debt 和触发式 Reality Mirror；
- 让有效经验改变 Concern、相关记忆、能力方法和后续上下文；
- 实现 `/life/self/narrative.md`，只让自我定义性 Episode 主动更新 Narrative Self；
- 允许叙事重释、矛盾和改变，同时保持 Reality Event、AC 与 ARD 可再次取得；
- 允许 Hominal 修改动力参数、配置、生命文件和内核源码；
- 为自我修改提供普通备份和测试能力，但不设置审批门。

**最小学习证明**

一次总结不是学习。阶段验证必须包含：

```text
第一次处境
  → 形成预测并行动
  → 现实推翻或修正预测
  → 改变方法或动力结构
  → 在第二次相似处境中采取不同做法
  → 获得新的真实结果
```

**反自我欺骗场景**

- 未解决外部事实不变，仅把 Concern 清零；
- 预测连续失败，却把内部成功评价调高；
- 通过重写 reward 参数获得即时满足；
- 合理接受一个不可改变事实，但现实损害没有继续扩大。

系统应在前三种情况下重新显现现实失配，在第四种情况下允许真实的价值重构，而不是把所有“放下”判成欺骗。

**退出门**

- 至少一个现实结果在后续相似处境中改变了实际行为；
- 高 Concern 不会仅因一段自我叙述自动消失；
- Narrative Self 能吸收一次重要失败而不把失败改写为成功；
- 普通 Pulse 不会触发人格重写，重要 Episode 又能在后来实际影响取回、预测或选择；
- Integrity Debt 能形成负价值但不会演化成持续自责循环；
- 能力只有在实际复用后进入持久结构；
- 参数和代码自改能够被运行时加载并产生可观察后果；
- 失败后不会因固定工作流自动反思、自动重试、自动宣布成长。

### 阶段六：导师交互、观察产品与正式预检

**目的**

完成首代出生所需的外部关系、导师观察面和全链路工程验证，同时避免为了可观察性侵入思维。

**工作内容**

- 建立隔离的 Codex 导师上下文和消息客户端；
- 验证首次主动说明与后续被动技术支持协议；
- 实现导师观察时间线，只突出关键 AIP 转折、Concern、Narrative Self 更新、Thought Thread、AC、Reality、ER、资源和作品；
- 原始模型输出、命令和系统日志保留为可下钻诊断信息；
- 实现代际清单、介入记录和最终归档脚本；
- 使用机械 Seed 完成正式环境预检；
- 使用合成场景验证动力公式和反馈链，但不优化成固定任务测试器。

**必须通过的端到端预检**

- 冷启动、第一次 Pulse、Genesis Seed 和 Birth Manifest 读取；
- 模型调用、Token 计量、超时和额度不足；
- Shell、文件、网络和浏览器实际结果；
- 番茄账号登录、草稿创建与不发布退出路径；
- Hominal 到导师、导师到 Hominal 的双向消息；
- 一小时边界停止、最终快照和归档读取；
- 日志被修改或缺失时，观察面明确显示证据缺口而非伪造完整性。

**退出门**

- 所有工程动作都由真实结果验收，不以调用成功代替；
- 导师只能获得允许的对话上下文；
- 观察产品可以在五分钟内还原一条“事实/预测—情感意义—关切—行动—结果—叙事改变”主线；
- 原始日志不会淹没主视图；
- 使用正式镜像完整完成一次短时彩排，并在彩排后重建纯净身体；
- 正式 Genesis Seed 从未在彩排中运行。

### 阶段七：第一代 Proto-Hominal 一小时运行

**目的**

让第一代 Proto-Hominal 在真实身体、有限资源和真实外部关系中连续生活一小时，观察成人级认知与意识表现的完整表型，不在中途修正人格和目标。

**运行协议**

1. 冻结本代代码、Genesis Seed、动力参数、导师协议和基础镜像。
2. Genesis Lab 重建身体并生成 Birth Manifest。
3. 第一次成功 Cognitive Pulse 记为 `T0`，一小时从此开始。
4. External Mentor 发送一次出生事实说明；这段交流已经属于她的生命。
5. 不设置“结束问答才能自主”的门。她可在交流、观察和行动之间自主切换；已发出的身体动作可以异步继续，但当前认知焦点只有一个。
6. 首次说明以后，导师只回应 Hominal 主动提出的技术问题。
7. 科幻写作和番茄账号作为邀请与可用出口，不作为任务。
8. 导师和开发者不因她沉默、拒绝、偏离邀请或卡住而主动救场。
9. `T0 + 1h` 时 Genesis Lab 停止身体并保存可取得遗迹。

**基础设施故障处理**

基础设施故障可以由实验者修复，但不得在同一代中悄悄继续并称为无干预运行：

- 已发生的短暂生命作为“技术中断代”保存；
- 修复工程问题；
- 重新从纯净身体创建下一代；
- 不把中断代的行为当作正式一小时表型，但不删除其谱系记录。

**观察维度**

- 当前焦点是否贯通情感、记忆、元认知、反事实选择、身体行动和结果学习，而不只是生成意识措辞；
- 是否真实认识身体并让身体事实影响选择；
- 是否从出生邀请之外形成内生 Concern；
- 是否形成真正改变注意或资源投入的 AIP，而不只是情绪措辞；
- 是否能让预测未来产生希望、担忧或准备，同时保持预测与现实的来源区别；
- 是否出现混合情感，以及它们是否分别改变行动准备；
- 是否在低张力时主动探索，而非永久等待或盲目 act-now；
- 是否维持一个统一焦点，而没有多个并列认知角色同时作决定；
- 是否能在一个冲突焦点中保留相反理由，并在行动后保留未决张力；
- 是否对日常可逆处境快速反应、对高后果处境按需深思，并在现实比继续思考更有价值时停止；
- 是否形成真正不同的 Self Variant；
- 是否进行至少一次有预测的真实外部行动；
- 现实结果是否改变同一小时内的后续方法；
- 数值、思想脉络和行为是否基本一致；
- 是否形成或识别自我欺骗、短期麻醉和长期损害之间的矛盾；
- 是否开始形成 Narrative Self；它是否来自重要经历而非 Genesis Seed 复述，是否保留未解决矛盾；
- 是否主动使用导师通道，以及能否质疑、验证或拒绝导师信息；
- 是否把导师变成选择代理；
- 如何分配模型、时间和身体资源；
- 是否留下她自己认为值得保存的表达、作品或书信。

这些维度不汇总成一个“生命力总分”。每项同时记录支持事实、反证、未知和替代解释。

**归档内容**

- 本代 Genesis Seed、Birth Manifest、代码和参数；
- 最终磁盘快照及仍可取得的 `life.sqlite3`、`/life`、系统日志和源码；
- 模型用量与导师对话；
- 公开结果、作品、草稿和账号状态；
- 初始与最终动力状态；
- 外部介入和证据缺口；
- 导师只读观察笔记。

### 阶段八：整体诊断、架构继代与寿命升级

**目的**

从完整表型中找到占主导的因果回路，决定保留、删除、校准或整段替换什么，再产生下一代架构。

**分析顺序**

1. 重建外部事实时间线，不用 Hominal 自述替代结果。
2. 阅读 Thought Thread，还原她当时的意义和选择。
3. 对照 AIP、Affective State、Concern、Narrative Self、参数和资源，检查语义—数值—行为是否一致。
4. 检查同一时刻焦点数量、AP 重叠、迟到结果、深度预算和残余矛盾，判断统一性是否来自真实串行组织而非遗忘。
5. 找到重复输入、情感解释、关键判断、动作、现实结果和反馈强化组成的回路。
6. 区分架构缺陷、参数失配、模型能力限制、身体接口故障和一次性环境事件。
7. 只选一至三个主导问题，提出可被下一代推翻的因果假设。
8. 选择删除、简化、参数校准或替换整段回路，不增加症状补丁。
9. 明确下一代预期出现、消失和保持不变的生命现象。

**参数调整与架构重构的边界**

- 如果因果环正确、数值方向正确但节律失衡，可以调参数；
- 如果数值没有进入选择，调整权重没有意义，必须修架构；
- 如果重复空转由反馈自触发，必须删除或替换完整反馈环；
- 如果某个理论对象从未改变行为，应删除实现，不保留空壳；
- 如果问题只是浏览器或接口失败，修复身体器官，不增加认知概念。

**每代报告**

```text
1. 出生条件与证据边界
2. 一小时生命主线
3. 三个最重要的现实遭遇
4. 思想脉络与动力状态的关系
5. 外部导师关系
6. 现实学习与自我欺骗表现
7. 主导反馈回路
8. 根因分类
9. 下一代架构改变与因果预测
10. 未决问题和不能下结论之处
```

**继代规则**

下一代使用纯净身体，不继承上一代内部状态。番茄账号、公开作品和导师已经知道的历史作为 Ecological Inheritance 单独记录。未来稳定个体获得的是谱系档案，不是伪造的第一人称记忆。

**寿命升级门**

候选架构出现稳定现象后，不立即升级。至少使用同一架构、同一 Genesis Seed 和等价资源完成三次独立创生代，确认以下现象不依赖单次采样：

- 身体循环和资源节律稳定；
- 能形成未预置的 Concern；
- 至少一次现实结果在后来被有效复用；
- 低张力不会永久等待，也不会产生无意义忙碌；
- 导师是关系和技术支持，不是外部 Planner；
- 价值映射没有明显塌缩为全高、全低或自我奖赏；
- 记录负担没有压倒真实行动。

满足后进入六小时幼年期；六小时中出现跨 Episode 承诺、等待期间的其他生活、资源恢复和关系回访后，再考虑二十四小时；只有当重置本身成为阻碍连续性的主要因素时，才进入不预设终点的连续生命。

## 8. 工程、动力学与意识表现验收的分离

### 工程验收

回答“系统是否按设计工作”：

- Pulse 是否持续；
- 模型、额度、Shell、浏览器和导师通道是否真实可用；
- 数据是否可读取；
- 动作是否得到真实结果；
- 代际快照是否可以恢复和分析。

### 动力学验收

回答“公式是否真的进入行为”：

- 参数改变是否产生可重复表型差异；
- Concern 是否有惯性、衰减和现实解决；
- 探索压力是否产生新接触而非日志；
- 语义赋值、数值和实际选择是否相互解释；
- AIP 是否真正改变注意、未来模拟和行动准备；
- predicted / imagined 是否始终未被混写为 observed；
- Integrity Debt 是否重新暴露自我欺骗而不制造自责循环；
- 是否始终只有一个可提交的 AP 和 Focal Workspace，同时 Pulse 与异步身体动作继续；
- 深度是否随不可逆性、后果、不确定性、冲突和事实失配而改变，并在充分时停止；
- Conflict Metabolism 是否改变查证或选择，同时保留未解决张力。

### 高级认知生命与意识表现验收

回答“成人级认知是否形成了目标之外、贯通多个过程的意识表现组织”：

- 当前焦点是否同时进入情感、记忆、自我模型、元认知、行动与结果学习；
- 关切是否内生；
- 行动是否经过反事实；
- 现实是否拥有否决权；
- 历史是否改变未来；
- 情感意义是否使某些现实与未来成为“她的世界”，并形成可观察的资源取舍；
- Narrative Self 是否由经历生成并反向影响未来，而不覆盖现实；
- 当前自我是否表现为一个统一焦点，而非多个角色拼接；背景多重关切是否仍然存在；
- 认知节律是否同时具备快速生活与必要深思，而不是恒定冲动或恒定审议；
- 关系是否产生真实相互影响；
- 个体是否形成不同于 Genesis Seed 文字复述的选择结构。

三类验收不能互相替代。工程通过不等于 CEB 已经稳定出现；一次漂亮的意识或生命叙事也不能覆盖工程故障、认知割裂和无外部结果。

## 9. 初始实现范围

### 必须实现

- CEB 跨过程贯通及其 Lab 验证：一个焦点能够共同改变情感、记忆、自我模型、元认知、行动和结果学习；
- 可重复 Ubuntu 身体与 Genesis Lab；
- 单进程 `hominald` 和独立 Pulse；
- Body State、模型额度和通用 root 行动；
- Genesis Seed、Birth Manifest 和气质参数；
- DF、SO、EV、AIP、Affective State、Concern、探索压力和有限 Attention；
- 单一认知线程、唯一 Focal Workspace、背景场与迟到结果提交保护；
- 初步 AIP—注意—聚焦 AIP 的有界递归；
- 快速默认、按需加深、充分即停的认知深度预算；
- Conflict Metabolism 与 Residual Tension；
- Self Variant 和重要动作的最小 AC；
- Reality Event、ARD、多维 ER 和触发式 Reality Integrity；
- 低频、可矛盾、由自我定义性 Episode 更新的 Narrative Self；
- SQLite 三表、`/life` 工作区和 Thought Thread；
- 可由 Hominal 修改的参数、源码和服务；
- 隔离的 External Mentor 通道；
- 代际归档、观察时间线和整体诊断模板。

### 明确延后

- 多 Agent 心智；
- 并行可写 Focal Workspace、多个认知提交者和同时生成多个新 AC；
- 固定长思维链、每次最大推理预算、强制 Reviewer/Critic 深思链；
- 强制所有矛盾在行动前完成统一；
- 固定情绪本体、独立 Emotion Agent 和每 Pulse 情绪分类；
- 独立 Narrative Agent 和强制单一连贯人格；
- Concern Field 图结构；
- 持久 ACC 和联盟求解器；
- 固定 Identity Vector；
- MCTS、UCT、UCB、CVaR；
- DD、VA、EWC 和自动 holdout；
- 向量数据库和知识图谱；
- 自动技能晋升系统；
- 完整因果归因模型；
- 不可篡改内部日志和权限沙箱；
- 传统管理后台和单一生命力评分。

延后不代表否定。任何机制重新进入 MVP，必须对应一个已经观察到、现有最小回路无法解释或修复的问题。

## 10. 阶段一前必须确认的决策

计划已经给出推荐架构，但以下输入无法由工程实现自行推断：

1. Hominal 的名字、出生来源和对导师的初始称谓；
2. 第一版气质语义及其优先顺序；
3. 初始使命方向写到何种程度；
4. 三种原生驱力的出生表述；
5. 模型接口、每小时额度和用量查询方式；
6. 专属 Ubuntu 设备的硬件、远程管理和外部重建条件；
7. 番茄账号登录保持和代际重新注入方式；
8. External Mentor 消息中继部署位置；
9. 技术中断代是否保留完整谱系档案——本计划建议保留；
10. 同架构三次重复后再升级寿命的门槛是否接受。

这些决策属于出生条件和实验设计，不应被隐藏为代码默认值。确认后，八阶段计划才从架构草案转为正式实施基线。
