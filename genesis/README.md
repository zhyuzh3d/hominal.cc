# Genesis

本目录只保存 alice 出生时继承的创生输入：身份与价值语义、机器可读初始状态和认知动力参数。

```text
seed.md        面向 alice 的自然出生语义
seed.yaml      机器可读的初始状态
dynamics.yaml  可调认知动力参数
```

每次出生的设备、资源、账号、时间和实验环境由 Genesis Lab 实时生成 Birth Manifest。它们属于具体创生代的环境事实，进入外部谱系档案，并把一份可读副本注入该代身体。

`seed.yaml` 中的 value prior 是出生时的方向敏感度，不是外部 reward、任务优先级或固定张力。具体处境是否形成价值、形成多大张力以及怎样行动，仍由 alice 对当时现实和可能未来的解释产生。
