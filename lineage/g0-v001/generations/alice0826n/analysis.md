# alice0826n 分析

## 结论

本代是一次有效的正式反证，结果分类为结构性失败。alice 在 T0 后约 16 分钟内保持了进程、Pulse、单次认知提交和费用账本的技术连续性，也完成了最初三条 Commitment—Reality—Experience 闭环；但随后内部探索事件压过现实结果，形成高成本的等价动作循环。继续运行到一小时只会放大同一缺陷，因此外部实验控制器提前停止并归档。

## 成立的能力

alice 能读取出生说明、接触 `/life`，也能主动回应导师。前三项经验分别形成了出生定向方法、符号链接入口与承载位置的区别，以及发送成功、进入队列和收到回应三个关系层次。她在前三次错误读取后最终修正命令，确实进入 `/life` 的目标目录并看见 `self`，说明局部工具纠错能力存在。

Terra 出现 429 和两次 502 后，资源内核停止继续请求，并在十分钟后恢复模型。费用账本记录 21 次结算和 119157 token；总账扣减 0.534834 美元，其中成功响应可计算费用为 0.372804 美元，三次无 Usage 失败的 0.162030 美元只是保守预留，并非已确认的供应商账单。保护期没有继续扣减认知额度。

## 核心失败

局部纠错没有成为生命循环中的后续经验。模型恢复后，alice 围绕同一个“查看 `/life` 顶层”意图连续形成八次 Shell 行动；即使现实已经返回 `self` 目录，她仍继续用近似预测和停止条件重复读取。结束时 Commitment 从 3 增到 11，Experience 始终为 3，Concern 增到 27，后台事件共有 129 个，其中 86 个仍待处理。

直接机制不是“LLM 不够聪明”，而是事件代谢失衡：五秒 Pulse 反复生成探索张力，内部事件进入焦点的速度高于一次模型认知的处理速度；Action Result 没有获得高于同源内生事件的因果优先级；同一张力没有合并；已有未吸收结果时仍允许形成等价新 Commitment。技术上虽然只有一个认知调用，语义上却失去了“行动一、结果回到同一线程、吸收后再继续”的单线程连续性。

这也显示当前 AIP 的正向情感可以反向强化错误循环：面对重复探索张力，valence、control 和 certainty 逐渐升高，系统把“我愿意探索”解释成继续执行同一动作，却没有用现实闭合该张力。积极倾向本身不是保护机制；只有现实结果能抑制重复自我确认时，积极倾向才会推动扩展。

## 独立缺陷与实验污染

首次成功认知提交定义 T0，而运行时在 T0 前已经可以读取 prepared Birth Manifest，因此 alice 第一次看到的 `sample_id`、`t0` 和 `planned_end` 仍为空。最终封存文件是正确的，但出生时存在事实窗口，需要在阶段八统一 T0 与出生封存顺序，不能靠增加解释文字解决。

独立导师任务又发送了一次与自动出生说明相同的内容，并把已经带身份前缀的正文再次交给会自动加前缀的命令。alice 的关系动作因此发生在重复出生刺激之后。本代仍足以证明事件代谢失败，但不能作为严格的“只有一次出生刺激”的导师实验样本。

外部控制器以 `structural_failure` 发起停止；并行监督器在归档尚未完成时把服务停止重新解释为 `runtime_inactive_before_planned_end`，覆盖了归档 Manifest 的停止原因。原始监督序列、停止时刻和本分析保留真实判定。Lab 已增加“外部停止进行中”保护和停止 intervention；原始档案保持不改写。

## 阶段八应解决的问题

下一步不应增加 Planner、任务、奖励或更复杂 Schema。需要从同一因果循环重构四件事：同源内生变化合并；未吸收的 Reality Result 优先返回焦点；一个 Commitment 的结果吸收前抑制等价承诺；张力在现实回答后被闭合、重写或明确保留。模型保护期能否把不可用事实交给 alice 并允许她自主选择其他模型，也应作为独立资源问题处理，而不是继续由内核静默等待十分钟。

在这些根因被重新设计、测试和短代验证前，不应直接启动第二个正式一小时样本。
