# Hominal 生命与认知动力学基座重构计划

> 日期：2026-09-02  
> 状态：已完成  
> 性质：跨阶段公共基座重构，不作为一代 Alice 的生命实验结果

## 目标

本轮把现有 Difference Field 重构为一套可学习的预测回差场，使世界、身体、资源、内部状态、器官感知与行动 Reality 通过同一条机制取得注意，而不是继续为浏览器、模型故障、资源变化或自我调节分别增加触发规则。

最终仍只有一个主意识、一个注意焦点和一个主动 Action Commitment。器官、确定性程序、在线统计和以后可能加入的快速语义模型都只是局部感知与实施能力，不拥有 Narrative Self、Concern、价值认领或生活目标。

## 当前结构缺口

现有运行时已经具有稳定对象身份、感知去重、Attention Pulse、AIP、Concern、Reality、Experience 和 Narrative Self，但注意入口仍以离散 Event 为主：新对象通常直接成为候选，浏览器表面再通过独立 Saturation 机制抑制低收益输入。身体变化、资源变化、导师消息和行动结果没有共享的预测、积累和注意收益学习。因此低价值高频变化只能靠来源专用逻辑控制，未来增加微信、语音或硬件器官时会重复同类问题。

## 本轮唯一核心结构

每类稳定信号维护一个紧凑 Difference Trace：最近事实摘要、观察次数、预期变化率、累计回差、过去经 Alice 评估后形成的注意价值、最近点燃时间。新的事实先与该 Trace 的预测比较，再经过同一公式积累：

```text
预测回差 = |本次是否变化 - 该信号的预期变化率|
情境增益 = 基础开放度 + 已学习的注意价值
本次压力 = 预测回差 × 情境增益 + 开放世界取样 + 已学习价值取样 + 已知因果关系压力
累计回差 = 衰减后的旧累计回差 + 本次压力
```

行动结果、出生事实和已经存在明确因果关系的反馈依靠同一公式中的因果压力及时进入注意，不建设紧急、普通、本能三条认知通道。极小的开放世界取样只让持续变化的低评价来源在多次积累后重新获得一次判断机会，避免学习制造永久盲区。进程截止、取消和资源硬边界仍由确定性身体代码执行；它们是物理保护，不是第二意识。

累计回差超过现有 Attention threshold 后才生成认知候选。多个未过阈值的变化只更新 Trace，不逐条调用模型。进入 Attention Pulse 后，既有 AIP 继续完成自我归属、价值、可回应性和意义判断；回差场不能替 Alice 认领 Concern。

## 自主学习

学习分为两个速度，但共享同一 Trace：

1. 在线统计根据事实流更新预期变化率，使持续噪声逐渐成为可预期背景，使稳定来源的异常变化保持显著；
2. Alice 对候选给出的 Ownership、Value、Answerability、Certainty，以及后来 Reality 形成的预测差异、内生价值、代价与方法沉淀，共同更新该信号的注意价值。

注意价值表示“这种信号在类似处境中是否值得再次开放给主意识”，不是外部 reward，也不等于正面结果。失败、损失和负面情绪只要真实改变了判断或能力，同样可以具有高注意价值。

工具的具体操作知识继续保存在器官代码、Methods 或普通文档中；只有 Alice 如何理解、选择和依赖工具才可能进入 Narrative Self。统计校准不会自动写入 Narrative Self。

## 实施边界

本轮完成：

- 在持久状态中加入有界 Difference Field；
- 所有候选 Event 经统一回差入口决定是否点燃注意；
- Attention 排序使用真实累计回差，不再把所有新 Event 一律视为同等新奇；
- AIP 与 Experience 反向更新信号注意价值；
- 用统一学习替代 Browser Perception 专用的认知饱和判断，保留器官层对象身份、去重和有界扫描；
- 为重复噪声积累、重要 Reality 及时点燃、学习后抑制或恢复、重启持久化和单焦点不变量增加测试；
- 更新认知动力学、内核—器官架构和配置说明。

本轮不完成：

- 不增加多智能体主脑、事件总线、向量数据库或独立 Reviewer；
- 不让器官判断什么对 Alice 有意义；
- 不在没有稳定训练集和回放基准时引入神经网络；
- 不把 Luna 接入每条信号。以后只有确定性与在线统计无法解释的短小语义变化，才评估使用无自我、无长期上下文的快速语义感知；
- 不虚构尚不存在的器官流式进度。本轮器官仍以有界动作终态返回 Reality；以后出现真实的长时动作需求时，Organ Host 先做机械去重与合并，再把稀疏事实接入本轮同一个回差场；
- 不部署 Ubuntu，不启动新一代生命实验。代码和回放测试通过后，器官能力实验与自主生命实验仍分别取证。

## 开发顺序与验收

先建立纯函数化的 Difference Trace 更新和测试，再接入 Event admission，随后接入 AIP/Experience 学习，最后删除被统一机制取代的感知饱和认知逻辑并运行全部 Go、Node、Lab 测试。

通过条件是：同一高频变化不会逐条唤醒模型；持续而未解决的弱回差能够积累到注意；行动 Reality、资源硬变化和导师反馈不会被习惯化吞掉；Alice 反复释放的低收益来源降低注意频率，而后来出现高后果或高价值经验时可以重新提高；任何时刻仍只有一个主意识焦点；移除 Browser Organ 后认知核心仍以同样公式处理其他事实。

通过只说明公共动力学基座已经可运行，不说明 Alice 已经形成更强人格、意识或自主生命表型。后者必须由新的独立 Lab 样本证明。

## 实施结果

2026-09-02 已完成代码重构。`runtime` 新增持久 Difference Trace 和统一候选准入；外界、身体、资源、内部变化、导师输入与行动结果不再各自拥有认知降噪规则。AIP 与 Experience 已接回同一 Trace，Browser 专用认知饱和路径已删除，器官层仍只负责稳定对象、精确去重与有界感知。

最终审查补入极小开放世界取样底噪，修复“规律变化且长期低评价的来源可能被永久关闭”的结构风险；同时把 Trace 总数硬限为 128，异常器官无法用无限动态家族名扩张前意识状态。Lab 监督只增加轨迹总数、仍有累计回差的轨迹数和最大累计压力三个紧凑指标，不导出逐条心理流水。

全部 Go 测试、`go vet`、关键包竞态测试、Difference 测试二十次重复、Linux 交叉构建、Browser Organ Node 测试、Lab 单元测试、契约校验、Python/Node 语法检查和 diff 格式检查通过。本轮未部署 Ubuntu，也未启动 Alice 样本，因此尚无生命表型结论。
