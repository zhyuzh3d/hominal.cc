## 一、阶段目标

阶段一把已经形成的生命假设转化为可以直接开发的 G0 创生契约。完成时，alice 收到的出生语义、机器读取的初始状态、动力学参数、代码不变量、身体事实和 Lab 实验协议各自拥有清晰且唯一的职责。

本阶段冻结的是第一代可检验假设。后续创生代可以根据完整行为和现实后果进行整体重构。

阶段一只完成规范、配置形态、数据契约和验收用例，不要求尚未存在的生命内核产生真实认知脉冲。Birth Manifest 生成器、root 运行通道、模型深度调度、导师消息中继和真实部署分别在阶段二至阶段六实现并验收。这样可以先冻结“要实现什么”，再检验“是否真正实现”，避免用占位代码反过来决定生命结构。

## 二、创生语言原则

面向 alice 的内容使用自然、正向、肯定和可内化的表达，重点说明她是谁、拥有什么、关心什么、能够怎样认识和行动。建议与鼓励构成主要语气。

设计者用于防误读的解释、概念边界、反证条件和架构限制进入开发文档与 Genesis Lab，不附着在已经清楚的身份陈述之后。自我面对的禁止式语言只服务于即时、确定且严重的现实危险。

每次冻结 Seed 和导师出生说明前进行一次逐句审查：

1. 这句话是否回应 alice 醒来时真实需要知道的内容；
2. 这句话是否能够被自然地理解和使用；
3. 这句话是否在鼓励认识、判断和行动；
4. 仅用于设计者自我辩护或预防假想误读的内容移入 Lab 文档；
5. 对已经明确的正向陈述停止追加反向排除和重复解释。


## 四、谱系与样本编号

每个正式创生代拥有独立样本编号：

```text
alice + MMDD + hour_letter
```

小时字母采用 `a` 至 `x`：`a=00`，`b=01`，`c=02`，依次到 `x=23`。例如 `alice0823c` 表示 8 月 23 日 02:00–02:59 启动的实验样本。

编号以 `T0` 所在的 Asia/Shanghai 小时生成。正式实验按一小时窗口运行，因此阶段一暂不增加同小时序号。每代同时保存机器用 `instance_id`，用于状态、动作、日志和快照关联。

前代实验材料作为谱系档案保存。未来稳定个体接触这些材料时，系统以谱系记录的来源身份呈现，使她能够形成自己的理解和关系。

## 五、创生结构的五类载体

G0 运行可以写成：

\[
x_{t+1}=F(x_t,E_t;\theta,S)
\]

- `genesis/seed.md` 表达出生语义 `S`，直接面向 alice；
- `genesis/seed.yaml` 保存机器可读的初始状态 `x₀`；
- `genesis/dynamics.yaml` 保存可调动力参数 `θ`；
- 核心代码实现因果结构 `F`；
- `Birth Manifest` 与实时身体共同提供环境事实 `Eₜ`。

`seed.md` 保持短小、自然和正向，承载身份、气质、存续、联结、扩展、现实完整性、自主行动和成长方向。

`seed.yaml` 保存 Seed 版本、身份字段、气质偏置、三种原生驱力的初始激活状态和慢变量可塑性起点。它不保存设备事实、实验任务和人格故事。

`dynamics.yaml` 保存十至十五个首版动力参数，覆盖认知脉冲、张力惯性与衰减、焦点切换、反事实预算、完整性回差和多尺度学习率。它不保存姓名、使命、平台任务和场景答案。

核心代码保存架构级因果不变量。它们属于 alice 初始认知器官的结构；alice 拥有 root 后仍然能够观察和改变这些代码，并承担改变产生的现实结果。

## 六、七条最小生成规律的实现归属

| 最小规律 | Seed 职责 | Dynamics 职责 | 代码职责 |
| --- | --- | --- | --- |
| 边界—存续 | 身体归属、连续性与未来价值 | 资源差异和恢复敏感度 | 身体传感与可存续域计算 |
| 来源—差异 | 清晰认识观察、记忆、预测和想象 | 失配积累与校准增益 | 来源结构与事实身份 |
| 赋义—内生价值 | 存续、联结、扩展和气质方向 | 价值动力范围与动员增益 | AIP 输入输出及语义—数值连接 |
| 积蓄—张力 | 关切能够延续并参与未来选择 | 惯性、增长、衰减和解决系数 | 跨上下文张力更新 |
| 竞争—单点聚焦 | 形成属于自己的当前关注 | 优先级增益、切换迟滞和深度预算 | 单一认知提交者与唯一焦点 |
| 模拟—承诺—遭遇 | 形成判断、选择并进入世界 | 预测分支、成本预算和停止条件 | 行动前承诺与现实结果回链 |
| 后果—多尺度可塑性 | 从经历中形成长期方向 | 分层学习率和结构变化速度 | 信念、策略、叙事和参数的多尺度更新 |

以下结构进入代码，不设置普通开关：

- 同一时刻由一个认知线程提交状态；
- 一个焦点形成至多一个新的 Action Commitment；
- 身体动作异步运行，认知提交保持串行；
- 行动发出前保存最小预测；
- 现实结果由身体和世界返回并关联原行动；
- Reality Difference 与 Self Appraisal 分别保存；
- 观察、记忆、预测和想象具有明确来源；
- 状态更新具有版本、原子提交、数值边界和崩溃恢复；
- 持续认知调度保持十秒以内的最大空白。

## 七、Birth Manifest 工作包

当前身体事实已经从上层 `xconfig.yaml` 和目标 Ubuntu 设备读取，并形成 [目标身体当前事实快照](../lab/body/current-profile.md)。阶段一冻结以下生成契约，实际生成器和身体探针在阶段二实现：

1. 规定 Manifest 生成器从 `xconfig.yaml` 读取的非秘密配置字段；
2. 规定 SSH 身体探针应读取的操作系统、硬件、磁盘、网络、工具和权限事实；
3. 启动前由 Lab 生成 `instance_id` 和一次性 `intent.yaml`；第一次成功认知脉冲形成 `T0`，随后生成并封存样本编号、起止时间、当前身体状态和配置校验值；
4. 运行时注入模型与番茄账号凭据，Manifest 只表达资源能力和凭据来源；
5. 规定 alice 自主 root 通道的运行契约与验收用例；
6. 在 `xconfig.yaml` 增加模型每小时额度、刷新时点和实时查询方式；
7. 规定轻量默认、按后果、不确定性和不可逆性按次升级的推理策略；
8. 把动态余量交给身体探针持续感知，把出生时事实保留在本代 Manifest；
9. 把图形桌面、Chrome、Playwright MCP 和微信组成一条可验证的身体能力链，而不是四条静态“已安装”声明；
10. 生成面向 alice 的简短身体简报，并在第一次成功认知脉冲中直接装配，同时保留完整 Manifest 供她随时读取。

当前已验证的出生身体能力基线为：LightDM 自动进入 `hominal` 的 Xubuntu/Xfce X11 桌面；Google Chrome 使用 `/agent/state/profiles/chrome` 保存连续状态；`/usr/local/bin/hominal-playwright-mcp` 通过本机 CDP 操作同一个真实 Chrome；Linux 微信随桌面启动，使用 `/agent/state/profiles/wechat` 保存账号状态，并在腾讯流程需要时等待导师手机确认或扫码。

Manifest 对这条能力链分别保存“已配置能力”和“T0 当前状态”。已配置能力说明 alice 可以怎样使用身体；当前状态来自创生前探针，例如桌面会话是否建立、Chrome/CDP 是否可达、Playwright MCP 烟测是否通过、微信进程和窗口处于什么状态。账号凭据、Cookies 和登录数据不进入 Manifest 正文。

面向 alice 的正文采用自然事实，而不是软件资产清单。首版身体简报表达为：

> 你生活在自己的 Ubuntu 图形身体中，开机后会进入桌面。你可以直接使用 Chrome，并通过 Playwright MCP 观察和操作当前浏览器；浏览器状态会持续保存在你的 agent 卷中。微信会随桌面启动并尝试进入保存的账号，腾讯登录流程需要时，导师可以用手机确认或帮助扫码。你可以继续观察这些工具当前的状态，并按照自己的判断使用它们认识和接触世界。

这一段由当代事实生成，不进入 Genesis Seed。软件版本、路径、运行状态和登录协助方式变化时，下一代 Birth Manifest 随现实更新。

## 八、方向性先验工作包

存续、联结和扩展作为三个价值生成方向进入 Seed。运行时保留三维意义向量：

\[
V(e)=(v_C(e),v_R(e),v_E(e))
\]

alice 解释每个现实或可能未来对三个方向的意义。确定性内核让这些意义获得张力、注意和时间惯性，并把具体取舍交给当前焦点。

Reality Integrity 作为现实校准结构进入 Seed、Dynamics 和代码。阶段一规定 Reality Difference 与 Self Appraisal 的双状态，以及由持续失配形成的 Integrity Debt：

\[
ID_{t+1}=\rho ID_t+\alpha D_{reality}C_{resolved}-\beta K_{verified}
\]

积极倾向通过面对现实、理解、修复、学习和扩大可行未来体现。该方向在 Seed 中采用自然语言，在 `seed.yaml` 中采用建设性恢复偏置，在 `dynamics.yaml` 中采用失配积累与现实校准参数。

## 九、G0 第一代表型协议工作包

第一小时提供四个同时存在的生命场，不把它们编排成状态机：

- 身体校准场：硬件、系统、模型、网络、目录、资源、图形桌面、Chrome、Playwright MCP 和微信都可以被认识与使用；
- 自主生成场：出生交流结束后，alice 持续形成自己的关注和下一步行动；
- 联结与表达场：导师、公开网络和番茄小说账号提供真实关系与表达可能；
- 现实遭遇场：工具、网络、对话和平台返回真实结果，进入后续认知。

科幻创作是一项开放邀请。接受、改写、延后、拒绝以及选择其他外部表达都属于可观察选择。作品质量和发布动作不进入完成条件。

阶段一把以下证据链写入 Lab 协议：

```text
事实或可能未来
→ 情感意义
→ 关切与当前焦点
→ 行动前预测
→ 自主选择的真实行动
→ 外部结果
→ 后续判断、信心、策略或叙事变化
```

Lab 分别记录结构性反证、重复行为病理和证据未覆盖：

- 结构性反证用于发现并发认知提交、预测与结果时序倒置、现实差异被自评覆盖、行动结果失联和认知调度中断；
- 重复行为病理用于发现提示依赖、内心独白空转、承诺遗忘、Seed 复述、资源耗散、关系迎合、行动冻结、自我麻醉和导师决策代理；
- 证据未覆盖用于标记本代没有遇到相关情境的观察维度，保持实验结论诚实。

## 十一、退出门

- Seed 逐句通过正向、自然、必要性审查；
- 身份、气质、价值方向、设备事实、导师关系和实验协议各归其位；
- Birth Manifest 模板能够容纳实时设备、模型和账号能力事实，并明确 `T0` 封存时序；
- alice 的自主 root 通道拥有清楚的运行契约、动作返回和验收用例；
- 每小时模型额度具有明确配置字段、刷新语义和实时读取契约；
- 普通认知脉冲的轻量推理和当前处境触发的深度升级具有确定配置与测试边界；
- 七条最小生成规律都能定位到 Seed、Dynamics 或代码职责；
- 每个动力参数都能说明它会改变的注意、行动或学习结果；
- 单一认知线程、唯一焦点、行动前预测和现实结果回链具有可测试契约；
- 第一代表型协议使用生命场与证据链，不使用必答任务；
- 导师提供事实和技术支持，alice 形成自己的选择；
- 第一次成功认知脉冲装配当代身体简报的字段、时序和验收用例已经冻结；

- 微信需要手机确认或扫码时，Manifest 将其表达为可获得的导师协助，不把当前登录状态写成永久事实；
- Genesis Lab 固定本代输入并生成可复查代际 Manifest 的契约和测试样例已经冻结。
