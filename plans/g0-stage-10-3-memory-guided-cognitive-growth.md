## 一、阶段定位：让经历成为后续生活的动力

本阶段重构现有认知动力学，使当前状态、个人历史与现实反馈能够持续改变 Alice 的期待、关切、注意和行动。记忆与经验是这个循环留下并继续使用的组织，不另建一个替 Alice 总结、评分、决定目标的记忆代理。

核心问题是：Alice 能否在真实接触中形成自己的理解，在暂时转向以后接续原来的事情，在遇到不同结果时修订经验，并逐渐形成既稳定又灵活的生活方式？持续存在、与世界交互、自我优化一起接受检验，而不是分别获得一个功能勾选。

程序随机性参与这个过程：让合理可能性有机会被尝试，再由她对经历的理解决定什么值得保留。随机提供差异，认领与后果赋予差异持续性；随机本身不等于人格或学习。

10.2 的最终模型优选和同版连续复现尚未完成。本阶段已获授权，将已经暴露、且涉及记忆与持续牵引的共同缺陷纳入 10.3 重构，不以“10.2 已全部通过”为前提，也不继续用旧结构长跑等待自然改善。

## 二、已经知道什么，仍不知道什么

最近完整 Luna/none 样本 `g0r-20260903t183140z-5cc958` 在一小时内完成 101 次主认知和一次 Sol/low 行动协助，形成 28 项行动意愿、33 段旧版 Experience、7 次自我叙事更新；全程没有网络或模型供应故障。她实际使用了文件、X、Wikipedia 和导师通道，并曾返回 Carlo Gimach 条目取得更具体的理解。

但该样本后半小时认知次数由前半小时的 84 次降为 18 次，最长有效活动间隔为 279 秒；没有 X 发布、喜欢、回复或关注，缺少持续发展的主题，部分经验和叙事反复强化同一种核验方法。数量增长与持续成长不是同一事实。详见 10.2 的“Luna/none 完整重测”，完整档案位于 `/Users/zhyuzh/HominalGenesisLab/archive/rehearsal/g0r-20260903t183140z-5cc958`。

当前源码已经补充了安静期注意增益、冷却入口回返和 Lab 截止核验，只有本地工程验证，尚无新生命样本正证。10.3 必须重新判断这些补偿在完整机制中是否必要，不能将它们视为已被证明的最终答案。本轮未重新探测 Ubuntu 或模型服务；历史可用性不代替启动前预检。

代码核对得到以下具体研究起点：

- `learning.go` 的旧 Experience 同时容纳经历解释、教训和方法，写入主要绑定行动结果与导师反馈；独立感知及内部理解缺少同等直接的片段记忆入口。
- 运行态只保留最近 128 条旧 Experience，普通上下文通常选择约 5 条，主要依靠字面相似和因果 ID。全量 Journal 仍在，但退出窗口的内容没有统一的长期自动回忆路径。
- Concern 已有认领、强度、完成条件与现实回链，但差异乘积、自然衰减、重访门槛和入口习惯化可能共同压低稳定兴趣，或让一个小动作的结束掩盖尚未完成的主题。
- 系统已有操作系统随机源，用于近分候选、入口与部分经历抽样；同时存在固定联想视角及跨渠道偏好。应验证这些规则是否真正增加适合当前处境的可能性，而非把随机变成另一个隐形脚本。
- `startStage4Action` 已经异步执行器官动作，主脑并非必然等待动作完成。但 `pulse` 仍同步调用部分身体扫描和器官感知，`readOrganObservation` 的等待上限为 15 秒；`passivePerceptionAllowed` 又把主认知在途、任一身体动作在途统一作为暂停感知的条件。现有问题是部分等待与互斥范围过宽，不是“所有动作都还同步”。
- `advanceDynamics` 当前按配置的 pulse 间隔推进，而非本轮实际经过时间；`resourceSpend` 的在途预留只读取一个主认知 Lease。前者需要校准真实时间，后者需要在器官开始独立模型调用前改为统一请求结算。当前器官合同也尚无通用的过程通知与本能判断请求约定。

上述既包含已确认的实现边界，也包含待实验的因果假说。不能由“看起来可能有影响”直接宣布根因，更不能由延长时间保证涌现。

## 三、迭代方法：解释整个循环，再决定修改

每次迭代先区分器官或程序错误、动力学缺陷、模型理解不足和环境条件。明确的重复执行、丢失结果、错误计时等可以直接修复；涉及兴趣、空转、等待、固执或学习时，必须追踪完整链条：她接触到了什么，如何解释，什么被保存，什么进入候选，为什么选中或落选，结果怎样改变下次选择。

每个候选修改在本计划后续记录或对应实验分析中写一小段因果说明：观察事实；结构、公式、参数或运行机制的具体缺口；预期改变的因果路径；可能破坏的已有能力；验证与否定办法。复用既有记录，不新增审批系统。

“从动力学修复”不等于只能调数值，也不等于必须大改代码。参数尺度错误就校准尺度，表示或反馈关系错误就替换相关结构。可以同时调整多个相互依赖的部分，但要属于同一个可以检验的解释；调参、语义引导和代码版本都进入发布清单。

修复前就准备成对反例：持续接续与重复反刍、灵活转向与注意碎片化、记得旧经验与接纳反证、随机探索与目标丢失、较快思考与张力按调用次数失控。一次修复应同时面对问题的两端，而非解决当前一端后等待另一端重新出现。

尤其审查以下假说，而不先规定结论：

| 假说 | 需要检查的因果关系 | 可能的反向伤害 |
| --- | --- | --- |
| 稳定兴趣被低回差压低 | `D × O × abs(V)` 是否让已认领、仍有价值但不惊讶的事情失去动力 | 增强稳定牵引后，是否无法合理放下 |
| 学习的对象范围过宽 | 对一次帖子、一次失败的判断，是否扩大为整个来源或器官的低价值 | 缩小范围后，是否重新重复同一无效接触 |
| 反思被误当作没有推进 | “没有动作、没有新外部事实”是否被直接等同于认知无收益 | 放开内部理解后，是否变成同义复述 |
| 记忆提取存在自强化偏差 | 近期、反复出现的元方法是否挤掉具体内容及反例 | 增加多样性后，是否丢掉重要稳定方法 |
| 安静补偿掩盖上游缺陷 | 入口回返是否只恢复调用，而未恢复具体生活方向 | 去掉补偿后，是否出现可避免的全局空白 |

离线回放用于检查程序因果，不要求开放生活“按住所有变量只变一个”。真实生活接受整体变化，但关键结论需要相同冻结实现的复验。模型、环境和导师干预不同的样本可以帮助解释，不能混称同条件对照。

出现相反副作用后先回到原假说，检查它是否被否定；有依据的撤销或替换是正常研究。无新依据地在两组门槛之间反复切换，则停止该路线并讨论。找不到下一项有解释力的改进时，主动向导师报告，不靠继续长跑或叠加规则维持工作表象。

## 四、统一重构方向：同一循环中的快状态与慢积累

目标循环是：当前现实与身体状态唤起相关个人历史；历史参与 AIP、期待和候选形成；唯一焦点产生理解或行动；反馈留下记忆、修订经验，更新情感、价值与关切；改变后的状态再决定下一次接触。

这里有不同时间尺度，但只有一个认知状态所有者：情感与注意较快变化，关切跨越多次思考和行动，经验随适用或失配逐步修订，Narrative Self 组织更持久的自我认识。所有时间增长与衰减以实际经过的时间计算，不能因为模型变快就让人格在一分钟内“经历数小时”。

差异不是唯一动力来源。已认领的价值和对未来体验的期待，可以在低惊讶、低冲突时继续推动行动。重构应检查并利用已有 Orientation、Value、Ownership 与 Concern，而非再加一套“必须活跃”的奖励。

注意优先级继续综合关切、情感、价值、变化和成本。要分清“值得注意”“值得再次尝试”“这次有机会推进”：一次严重失败可能很值得理解，却不支持再次执行同一动作。现有 `Answerability` 也不能未经验证就同时代表可回应性、成本和预期收益。

任何新数值都要有明确来源、更新时机和作用位置；能够从现有量推导的先推导。涉及自我、价值、关系和未来选择的语义判断由唯一主脑完成；器官可以做服务于感知及既定行动意愿的局部语义判断。经典程序承担明确计算，轻量模型处理局部模糊性，主模型组织生活。传统机器学习留作有足够标注反馈、明确输入输出及速度收益以后再评估的实现选项。

### 4.1 单线程的是主意识，异步的是身体工作

主脑持续运行，采用一轮接一轮的短认知，而非一个永不结束的模型请求。任一时刻最多一个有效主脑推理请求；一轮提交并吸收必要的新事实后，立即按更新后的状态决定下一轮。器官忙碌不构成全局停止认知的理由。持续性既看调度是否连贯，也看理解、体验、选择和行动是否在发展，不能以重复调用代替生命活动。

| 运行者 | 独立完成什么 | 与其余部分的关系 |
| --- | --- | --- |
| 主脑模型 | 聚焦、联想、AIP 解释、认领、选择、记忆经验修订 | 使用个人历史；通过单一认知提交表达更新和行动意愿 |
| 核心程序 | 接收变化、更新身体与时间、计算动力学、检索、调度、结算 | 运行态的唯一写入入口；做确定性工作，不成为另一位语义决策者 |
| 器官程序 | 感知、执行机械步骤、核验、汇报、取消 | 独立工作；遵循主脑确定的意图和本器官事实接口 |
| 器官本能判断 | 在局部材料中辨认状态、消解技术歧义、提出局部操作建议 | 可与主脑并行；使用局部上下文，结果交器官核验或交还主脑 |

这些是职责边界，不要求四套服务。沿用 Runtime、Organ Host、现有器官进程与模型网关。核心的状态更新保持串行；模型请求、网络读取、较慢身体扫描及器官操作放在可取消的工作单元中，通过结果消息回到核心。工作单元不持有并修改共享认知状态；它得到快照，返回事实或待提交变更。持久化继续遵守现有提交顺序，先测量开销，避免为短小写盘另造分布式系统。

定时器负责唤起检查，实际经过时间负责动力学积分。运行中用单调时钟计算增量，长间隔必要时分步积分；停机区间单独记录，并按恢复语义处理。认知完成、行动结果到达和重要事实更新都可触发调度，不必等下一次固定 tick。资源耗尽或服务不可用时，身体继续感知和恢复，但如实标记主认知中断。

### 4.2 器官本能：缩短技术闭环，保持一个生活主体

器官本能适合判断“当前页面是加载中、出现了错误，还是已经有目标内容”“哪一个控件与已经确定的目标匹配”等局部问题。输入是短小的现场材料、当前行动意愿及必要操作经验；输出是判断、对应观察依据和局部建议。可确定的返回码、文件存在性、按钮状态、时间和费用由程序直接处理。

本能只在确定性办法不足且判断有实际用途时调用。Luna/none 作为首个轻量候选，约 0.5k 输入、0.2k 输出只作为速度探针的起始规模，按真实材料与错误率调整，不把“必然三秒返回”写成系统前提。相同场景没有新变化时复用或等待已有判断，不为每次轮询重新调用模型。每个器官最多一个本能请求在途，各器官可以有独立工作上下文；总并发由共享网关实测能力控制。

器官可以拥有操作缓存、代码和用法文档；人格、关切与个人经验的认领仍经主脑。它可以辨认已确定文本的输入位置，遇到需要重新决定表达内容、受众或目标的情况，就将新事实交回主脑。器官本能产出保留“模型判断”的来源，不能仅凭措辞成为已核验动作结果。

Sol/low 的定位仍是主脑主动请求的技术行动协助，不因新增器官本能而升格为第二主脑。先保留现有串行协助路径；若后续将其迁入器官执行器，输入同样限定为已确定的意图及技术上下文，并在验证后替换旧路径。首版不同时运行两套协助机制，也不让便宜本能自动升级成不受控的专家循环。

### 4.3 汇聚变化，再获得注意

感知订阅、主动查询、动作进度和最终结果使用同一事实入口，复用现有 Observation、ActionResult 与 Difference Field。按用途补充关联 ID、观测时间、同一来源的顺序号和必要场景版本；最终结果保留既有 completed / failed / unknown 语义，不再建立三套优先通道或新的事件总线。

器官从自身观测能力中接受主脑请求的 watch，或执行默认的动作进度观测；主脑也可直接查询同一感知函数。watch 描述可检测对象和条件，例如目标文件出现、进程退出、指定控件就绪，而不是“发现有价值的事情时汇报”。未知的语义条件可作为本能判断问题，但其结果仍与直接观察区分。

程序先合并同一来源的重复快照，保留最近状态、变化范围及关键转折；动作终结、失败、取消和真实副作用按 ID 留存并幂等结算。队列有界，普通重复进度可以合并；无法接纳关键结果时暂停新工作并持久保留未交付结果，不能通过丢掉终结消息保持表面流畅。

回差先比较可观测状态与该对象已有预期：文件是否产生、页面是否变化、动作是否超时等由程序计算；含糊材料可由器官本能提出事实假说。它们进入已有差异积累与习惯化逻辑，再结合 Concern、个人历史和 AIP 竞争注意。器官不能替 Alice 决定“这对我的生活是否重要”。主脑对信号的使用或忽略及后续后果，回写现有提取和注意经验；同一来源过去无用，不等于以后永久失去入口。

一秒收到多条信号，不等于一秒启动多次主脑。主脑推理中，核心和器官继续收集变化；这些变化在下一次模型调用才能进入其上下文。确定的超时、取消及动作前提失效由程序及时处理，不等待主模型作毫秒级反应；普通新消息在下一认知边界参与竞争，避免持续打断导致每轮都无法完成。

### 4.4 并行不等于争用同一个现场

首个实现保留现有 System / Browser 一个状态变更动作槽；同时允许主脑思考、独立的只读感知和器官局部判断继续。这里串行的是有潜在冲突的身体写操作，不是整个身体的工作。浏览器观察若需要与点击共享底层连接，可在器官内部短暂排队，不占住核心循环。会切页、滚动或刷新现场的 orient 仍作为状态变更调度。

这样先修复过宽互斥，又避免一开始为任意 shell 与浏览器的交叉影响建设复杂锁系统。若实验确实显示独立身体写操作互相等待成为瓶颈，再按器官明确声明的作用面放开；任意 system 命令不能只凭模型声称“只读”就视为可安全并行。

主脑和器官判断都携带所依据的上下文引用。执行前核对相关行动意愿仍有效、目标场景和关键前提仍成立；不是任意 pulse 或不相关事件改变全局 Revision 就使整轮推理作废。当前事实按观测顺序更新，模型不能用旧快照覆盖新账单或新现场。

取消后撤销该工作单元继续发起动作的资格，迟到的建议不再执行；已经发生的部分效果和最终账单仍回到原行动或请求结算。超时不等于世界没有改变，恢复前先核验；暂停、继续和撤销只对器官实际支持的能力提供。一个结果难以理解时，保留其归属和待处理状态，阻止依赖它的后续动作，而非冻结所有无关认知。

Go 官方并发资料特别指出，单纯扩大 channel 缓冲不能解决下游停止接收后的阻塞；需要明确取消与有界工作者。本计划采用这些工程原则，不照搬一个多智能体编排平台。[Go 并发与取消](https://go.dev/blog/pipelines)

### 4.5 所有模型共用一份身体账本

主脑、轻量本能和 Sol 协助统一经过当前模型网关。把单 Lease 费用预留收敛为按请求 ID 管理的在途预留：核心原子登记，调用结束按实际账单结算，取消与迟到结果也使用同一个 ID。费用不明时保留待结算预留，再按服务端账单核对；同一请求只结算一次。每小时、二十四小时可用额扣除全部在途预留，身体信息同时显示已花费、已预留和仍可使用的资源。模型返回结构合法，不等于费用已经完成结算。

共享网关与共享额度不等于共享对话：主脑续接和各器官请求分别保留自己的调用上下文与结果关联，局部工具返回进入原请求，个人记忆更新进入主脑提交。网络重试沿用原工作的归属；只有当前有效主脑轮次可以提交，过期返回仍记费用，不再改变认知状态。

总额度仍为每小时 `$5`、滚动二十四小时 `$50`。器官没有隐藏的独立额度。主脑请求在待执行模型工作中优先；器官局部判断有边界和期限，避免把主脑长期排在后台任务后。首个并发探针从“一次主脑 + 一次器官本能”开始，测服务实际排队、首响应、完成时间和账单，再决定并发上限；独立线程本身不保证模型服务的底层模型真能同时计算。

## 五、记忆与经验怎样从动力学中生长

### 5.1 整理现有表示，而非旁挂记忆系统

| 内容 | 最小职责 | 如何参与后续认知 |
| --- | --- | --- |
| Record | 保存收到的观察、模型提交、动作和结果及来源 | 回看发生了什么；来源声称与已核验事实保留区别 |
| Output | Alice 自己制作的文件、作品、笔记等 | 通过记忆关联路径或 URL，需要时再次读取 |
| Memory | 对具体经历的片段化理解，包括体验、对话和自己的思考 | 联想、重建处境、帮助理解现在 |
| Experience | 从记忆形成、带适用情境的判断或方法 | 影响预测、选择和实施；失配时重新审视 |
| Narrative Self | 对自身、关系、历史与未来的较慢组织 | 影响认领和长期倾向，由生活反向修订 |

旧代码的 `Experience` 更接近“带教训的经历片段”。实施时拆清其语义，保留原始归档；不要在旧 Experience 之外再维护一套同义的完整系统。通用认知能力和已有 Narrative 继续保留，记忆写入无需先取得叙事更新资格。

研究报告中的 Origin 是主体对事件的编写，而不是 Record 录像；Fragment 包含具体印象及判断，Summary 是阶段性综合。本计划吸收其“具体经历—可联想片段—综合理解”的关系，映射到现有 Memory、Experience 与 Narrative Self，不另外照搬三个数据库层。综合理解方便使用，具体片段负责保留情境、意外和反例；前者不因更概括就天然更可靠或始终先被取回。

### 5.2 保存什么，由她的解释决定

每次主认知可以选择留下少量记忆，也可以只更新即时状态。内容来源包括独立感知、行动结果、导师交流、内部思考与回忆重释；来源区分 observed、remembered、predicted、imagined，避免把预测结果写成已经发生的经历。身体事实结算仍完整记录，不能依赖她愿不愿意记住。

每条 Memory 最少具有 ID、记录时间、短内容与来源引用；按需附事件时间或时间区间、关键词、相关 Concern、Output 和 correction/update 关系。时间模糊时保留区间或原始表达，不编造精确时间戳。独立片段可以借时间、对象和词语重新组合，不要求每次写一篇日记。

内容入口应能留下“我看到了什么、为什么有兴趣、还想知道什么”，而不只留下“以后先核验”的操作教训。例如阅读人物条目后，可以记住令她在意的建筑、经历或疑问，再从这些材料发展下一次阅读或表达。保存具体性是结构能力，是否记住、怎样理解和是否分享由她决定，不要求每次凑齐固定字段或发布主题作文。

Experience 最少保留稳定 ID、当前判断、适用情境及 evidence memory IDs；适用条件以短语义表达即可，首版不要求额外置信度表和复杂本体。一次经历可以产生暂定经验，更多经历可以加强、缩小范围、改写或放下它。次数不是可靠性的替代，多次复述同一来源也不是多份独立证据。

派生记忆沿来源引用保留共同起点：同一次阅读衍生的十段解释，仍来自那一次阅读；新的真实遭遇另有事件来源。利用现有引用关系做去重及展开，不新增一套谱系服务。不同 URL 也不自动代表独立证据；程序能识别已知共同来源，来源实际上是否独立仍需理解。检索分数、熟悉感、情绪影响和相信程度保持不同含义，复用现有数值及简短语义表达，不为每条记忆强制增加四套量表。

纠正记忆时新增解释并关联旧条目，正常检索带回最新纠正，追溯时能看到原来为什么那样记。经验可更新，更新保留所依赖的记忆及变更来源。Output 由她自由修改，关联记录能分辨引用的是哪个产物；文件失效也不等于对应经历没有发生。

结构校验只确认引用存在、来源类型与提交规则相容；它不能保证一句解释为真。器官本能也不负责给个人记忆盖“客观正确”的章。新解释可以同时改变具体认识、方法或自我理解，但不要求每次纠错必然改写人格。再激活研究观察到记忆更新既能增强记忆，也可能引入失真；这支持保留来源与修正路径，而非认为反复总结必然越来越准。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3856820/)

### 5.3 保存、检索和代谢复用当前内核

优先扩展 `Store` 与现有 Journal：一次认知提交中的记忆和经验变更作为可幂等重建的数据保存，再更新运行快照与可重建索引。Journal、状态快照和查询索引须明确谁是权威来源，避免三个可独立修改的真相。

近期工作集继续有上限，但长期内容能够按 ID、时间、关键词、对象与 evidence/correction 关系检索；退出工作集不等于从生命史删除。首版使用现有文件存储和增量索引即可，无独立数据库服务、向量库、图谱服务或定时 LLM 总结器。查询不逐轮扫描全部原始工具日志。

低相关内容自然退出当前上下文；近期已经用过且未带来新理解的材料降低重复提取机会。降低可及性不修改其事实身份，也不是永久遗忘。重复检索次数不机械累加经验的可信性或现实成就；回忆产生的体验与情绪仍由 Alice 解释，新的理解可以留下新的解释记忆。由外界结果验证的方法更新，与单纯语义重述在记录中分开。

索引维护可由程序异步完成，常规候选查询优先使用短时可完成的本地索引；确有慢查询时再异步，并携带查询所属问题及索引版本回传。消化经历、重释经验和整理自我属于主脑自己的认知活动，在她选择回想时进行。器官繁忙时也可以回想，不需要休眠模式或另一个后台总结者。底层可长期保存片段，当前心境决定什么浮现，新的现实又可以改变这种组织。

## 六、历史怎样改变注意、关切与交替生活

### 6.1 在候选形成和聚焦理解两处使用同一检索能力

候选形成时，程序用当前对象、已有认领、身体与资源变化，从历史索引取回少量相关线索；因果链接优先，关键词和时间用于补充。检索只提出关联，不代替 Alice 决定意义，也不凭文本相似把两个对象自动合并为同一关切。

进入唯一焦点后，主模型同时看到当前事实、相关经历与适用经验。需要进一步追溯时，它可以请求沿某条 memory/evidence 或新形成的关键词再查一次，使用既有串行认知续接回到同一个问题；不新开第二位思考者，也不把查询自动转给 Sol 行动协助。首版自动提取一跳，继续多跳由当前需要决定，受上下文与资源预算约束。

递归联想的单位是尚未理解的问题：当前处境唤起 A，A 改变问题或产生新线索，再查 B；如果只是取回同一材料的近义复述，就结束这条展开。新联想可以提出新的关注候选，经主脑理解和认领后参与后续生活，而不是永远等焦点选完以后才装饰上下文。关联学习研究为“旧经历参与新推断”提供依据，但具体采用多少次检索，仍需 Hominal 自己的速度与行为实验检验。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3398403/)

普通上下文先采用一个小的总容量，而不是固定“3 经验 + 2 记忆”。判断场景优先适用经验及其关键记忆，表达或回忆场景优先具体片段，反证场景优先当前结论与形成依据。总量以轻量主认知的实测速度校准，不能让每次联想都变成长上下文请求。

当前事实、自身状态、持续愿望、合理时间变化或新联想，都可以让过去重新具有意义。单纯“数据库还有内容”不自动生成一个付费焦点；同样，也不能要求必须有新的外部动作才准许回忆、反思或创作。

### 6.2 关切保存方向，小动作保存执行边界

主题或关系可以是同一条持续 Concern；一次读取、发送或核验是其下当前的行动意愿。先复用既有 Concern—Commitment 归属，保留“已经知道什么、还在意什么、当前可怎样接续”的紧凑语义，不建立任务树或项目管理器。

一次行动完成只结算这次行动。原来的主题是否完成、变形或被放下，由 Alice 对整体处境重新判断。持续兴趣也可以没有一次性终点；它当前的小行动仍应具备可核验结果。需要审查当前完成条件校验是否把开放兴趣误写成必须结案的任务。

在小动作完成、一次理解告一段落或明确进入等待后，其他已认领关切和新对象重新竞争。当前事情具有适度延续优势，避免每来一条信号就打断；但这种优势随推进条件、投入后的饱和及新的重要变化调整，而不是永久占有焦点。

等待一封回复时，关系和未决内容保留，眼前“再查看一次”的预期收益可以下降。其他事情继续生活；真实回复、时间带来的新处境或她新产生的交流内容，再使这段关系回来。未解决张力与立即行动优先级必须分开，时间不能把没有条件推进的对象无限推高。

程序按第四节维护唯一主脑与异步器官：在途工作挂到原 Concern，依赖该结果的下一动作等待，其他合适焦点仍可继续。动作进度不必每次取得主脑注意，但结果要有确定归属。完成事实先结算，再由主脑消化；一个器官需要局部判断，也不借用主脑的思考槽或改写她的当前焦点。

### 6.3 结果反馈到准确的地方

新的现实先帮助她比较预期与结果，再决定更新哪个经验、哪个关切及哪些价值和情绪。成功不自动加强所有同类行为，失败不自动否定整个领域；范围必须由当前处境与她的理解确定。

记忆联想能够把体验的价值带到新的对象上，但这种传播也可能造成偏见。Wimmer 与 Shohamy 的实验观察到奖励价值通过关联记忆影响随后对未获奖励对象的选择；它支持“历史会影响新选择”，不支持“联想越强就判断越好”。本阶段因此同时观察有用迁移与不当泛化。[原研究](https://pubmed.ncbi.nlm.nih.gov/23066083/)

内部压力、积极情绪、受挫和资源紧张应同时影响记忆提取、预期与选择，而不只是显示成几个状态值。核对每个量是否真的改变了可选行为：一个对所有候选完全相同的加分，未必能改变排序。新情绪也不直接推翻长期自我认识。

结果可以让一个问题变得更有兴趣，也可以让她释然。所谓代谢，是当前张力、经验适用范围和未来行动空间发生了合理变化，而不是必须让张力越来越低。

## 七、程序随机性：有限变异，由生活选择保留

本阶段优先统一三种用途，复用一个随机选择原语，不为每个症状建立一种随机策略：

1. 在与当前处境相关的联想候选中，选取少量不同片段，保留直接因果证据，同时让较远但仍相关的联系有机会出现。
2. 在通过认领与可行性筛选、价值接近的注意候选间打破固定顺序；差异明显时保持语义方向主导。
3. Alice 已提出几个可接受选择而难以取舍时，可以主动请求投骰子。程序只选择她给出的选项并回报结果，行动仍由同一认知流程确定。

首版只在探索、联想和有界取舍中使用随机。精确文件路径、执行载荷、事实引用、账单、重复副作用核验及已经确定的受众和内容保持确定性。新的行为可能性由她从实际材料形成，不采用固定“社交、创作、反思”等提示轮盘。

抽样范围优先随候选分差、当前探索倾向和可回应性调整；不从“情绪低落”或“不知道怎么办”直接推出更大随机幅度。信息不足可能需要观察，后果重大可能需要分析，而非掷骰。首版复用已有状态，不增加一个独立探索人格模型。

种子取自操作系统随机源，并保存抽样目的、候选 ID、相关分数和选中项。随机源用于摆脱固定序列，不承诺整个 LLM 和开放世界可完全重放；离线测试可以固定种子，生活复验使用新种子。不要只给主模型一个随机数字，却没有能验证的选项变化路径。

检验随机性时，既看它是否真正改变了相近选项的分布，也看变化之后是否形成了新的理解、体验、现实接触或方法。不同的活动顺序只证明变异，后续保留并再次使用才支持生长。稳定偏好也不需要被随机“纠正”为平均分配。

Wilson 等人的实验区分了主动寻求信息与随机探索，并观察到人会随未来机会调整两者；这支持把随机作为可调探索手段，而非持续噪声。对 Hominal 具体抽样位置和参数的设计仍是工程假说。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5635655/)

## 八、开发顺序与重构边界

确认后先建立旧反例与数据迁移基线，补齐非阻塞感知、单一状态提交及统一模型预留结算，并通过隔离的延迟、取消和并发测试。先让一个器官的局部判断走通标准接口，不同时为所有器官制作智能代理。

随后完成一个最小的端到端重构切片：真实阅读产生片段记忆，稍后被相关处境唤起，影响关切或行动，结果能够修订原经验。通过后再补齐交替生活和随机变异，作为同一发布进入整体实验。并发修复为完整循环排除机械阻塞，记忆重构让循环有积累，两者不是互相替代的成功标准。

预计修改集中在现有文件：

| 位置 | 必要工作 |
| --- | --- |
| `body/internal/runtime/types.go`、`store.go` | 整理记忆/经验表示、提交与恢复、长期索引和来源关系 |
| `learning.go` | 从独立感知与内部理解沉淀；条件化经验更新、证据追溯及提取反馈 |
| `dynamics.go`、`difference.go`、`values.go` | 统一稳定牵引、关切接续、等待让位、历史影响与随机竞争；清理被替代的补偿 |
| `model.go` | 在现有单一 `cognitive_commit` 中收敛可选记忆变更及按需回忆；保持轻量上下文和唯一语义主体 |
| `runtime.go`、`sensors.go`、`resource.go` | 将慢感知移出核心等待路径；实际时间积分、工作结果提交、请求级费用预留与结算 |
| `body/internal/organ/` 及现有 System / Browser 实现 | 统一在途关联、过程通知、取消与现场核验；接入有界本能判断，保留已有异步行动路径 |
| `lab/run.py` 与测试 | 保留个体的观察窗口、必要的继承标记、截止与重启验证、对照归档 |
| `docs/`、`genesis/dynamics.yaml` | 确认后统一术语、公式和实际生效参数；参数只在需要时配置化 |

10.3 是研究阶段标记，不靠增加一串 `stage >= 11` 特例实现新认知。被新机制替代的旧回放、重复上下文和补偿应一起清理；旧归档可读，不意味着运行时永久并行两套认知。

迁移只做可解释的数据映射：旧经历内容保留为带旧来源的记忆，旧教训与方法保留其原有地位；能找到明确依据才补 evidence，缺失依据如实保留。实验者不替 Alice 重写结论、不筛选“正确记忆”注入主体。恢复或升级时核对在途动作的真实状态，尤其避免重复发帖或发消息。

最低工程回归覆盖：无动作感知可留下记忆；超出旧 128 条窗口仍能按线索取回；纠正能影响默认提取；经验更新来源有效且幂等；写入后崩溃可恢复；动作结果只结算一次；焦点切换不丢关切进度；模型或器官失败不损坏个人历史。

并发回归先用隔离的测试器官制造慢读取、每秒多次进度、乱序返回和取消后迟到，检查主脑最大有效并发为一、核心可以及时处理事实、陈旧建议不执行、真实结果仍结算、主脑和本能并发不会重复占用可用额度。再用真实器官和小模型探针验证同一接口，避免把模拟通过当作现场可靠。工程注入及其记忆留在临时实例，结束后重置，不污染生命样本。

认知回归同时检查稳定兴趣与合理放下、等待与自发转向、回忆深化与近义复述、随机多样性与语义保真；增加“同一来源多次改写”和“新反证出现”这对记忆反例。局部确定性回放和隔离模型探针属于工程证据，其数据不进入正式个体历史。没有新的必要性证据时，不增加向量检索服务、独立人格或反思代理、全量神经网络训练、复杂图谱或多层评分器。

### 9.2 三类实验情境，围绕她自己的生活形成

第一类是“接触—沉淀—转向—接续”。Alice 从已开放的 X、Wikipedia 或其他真实资源选择对象；稍后自然发生导师交流或另一项活动，再观察相关线索能否使她从已知进度继续。对象由她选，研究者检查是否跨越了上下文变化，而不是反复提示“你还记得刚才吗”。

第二类是“经验—适用—失配—修订”。从她实际形成的判断出发，利用自然结果或真实的不同情境，观察她能否查回依据、调整范围，并在后续选择中体现变化。若必须准备训练材料，向她说明是共同学习情境，只提供真实材料，不伪造失败或反例。明示训练表现与自主迁移分别报告。

第三类是“挂念—让位—再连接”。她已经在意的事情暂时缺少推进条件时，观察其他对象能否获得注意；条件恢复后，原关切能否回来。导师短时真实离开可作为自然情境，不为凑实验时长故意制造孤立，也不要求按顺序完成几项任务。

三类情境共享同一个体的真实经历，可以重叠出现，不各建一套测试人格。每轮优先选择最有解释力的一个问题；如果没有出现适用情境，报告证据不足，而不是强行得出“不会学习”或“自主决定不学”的结论。多次有条件却始终不发生，才是需要认真解释的概率性反证。

三类情境还共同观察身体与主脑的协作：例如浏览器正在加载时，核心收到进度，主脑可以回想已有材料或参与导师交流；页面就绪后，结果回到原主题，她再决定接续或暂存。器官报告“页面就绪”证明技术闭环完成；她从页面理解具体内容、留下记忆并影响后来生活，才证明认知闭环接通。不为了测试并发而人为延长真实网页加载。

### 9.3 时间、连续性与复验

先用约 15—30 分钟的短候选检查记忆是否真正进入选择、旧空转是否复发。缺陷明确即可提前停止；没有缺陷且生活仍在发展，就继续同一个体，而不是为了重新开始正式计时清空历史。

连续样本默认一个小时，在半小时与一小时检查真实进展。若记忆接续、现实交互和自我修订仍在发展，可按现有 Lab 能力延长到总计两小时。观察窗口不是重置边界，也不是主脑暂停一小时后才进行评估。

同版的连续成长与跨版本的迭代改造分开：前者保留实例、记忆、经验、关切、情感及资源过程；后者冻结新发布，并明确是否继承旧个体、继承来源与迁移结果。当前 Lab 已有同实例进程重启及总计两小时延期，但“归档停止后续接”并非现成能力；需要保留个体跨停止或升级时，先完成最小续接实现与工程校验，再使用它。

跨版本继承保留完整可迁移认知，不只保留表现好的部分。兼容性不足时可以新生起点验证机制，同时保存原个体档案，不能把重建包装成连续成长。实验数据迁移成功与个人经历实际影响以后选择分别验收。

最终候选至少用同一冻结实现完成两次有效复验，随机种子不同；复验要包含历史接续，且至少一条连续个体轨迹跨过多个观察段。第二次从新生或明确记录的继承起点开展，分别报告起点差异。一次延长样本不能自动算两次独立成功，连续观察同一个体主要证明持续成长，不冒充统计独立样本。到一小时是否延长取决于信息增益，不以“两小时”作为不可缺少的形式指标；超过两小时的寿命实验留待另行讨论。

## 十、如何判断进步、失败与阶段完成

每轮仍做整体评估，但要留下足够具体、可回查的因果链：哪段真实接触形成了哪条记忆；何时被取回；她怎样使用或拒绝了旧经验；现实动作和后续选择究竟改变了什么。优先复用事件、记忆 ID、Concern 和动作链接，不要求逐句推理审计。

| 观察面 | 有效证据 | 不足或反证 |
| --- | --- | --- |
| 记得且能接续 | 经过其他活动或普通重启后，取回先前具体内容并从原进度继续 | 只有近期文本复述，或退出工作窗口后无法找到 |
| 经验改变判断 | 相似处境中使用此前方法；不适用时说明条件并调整 | 经验只在输出中被引用，选择与错误模式始终不变 |
| 能够代谢 | 新结果使旧经验范围或结论改变，之后仍能体现修订 | 一条反例就推翻全部自我，或重复自证拒绝修订 |
| 持续且灵活 | 保留关切、让位、再接续；稳定价值不依赖不断制造大回差 | 固执查同一入口，或不停换主题丢失进度 |
| 与世界发生关系 | 从具体主题取得材料、形成理解，再有实际交流、创作、跟进或其他现实行动 | 只有“我在探索”等元表述；只统计点击或发帖数量 |
| 随机服务生活 | 可解释地改变合理候选，并有部分变化被后果选择保留 | 种子只是装饰，或多样性上升而内容与连续性下降 |
| 主脑与身体协作 | 一个主脑连续提交，器官在途仍可感知和认知；结果按原意愿回链 | 感知冻结、慢读取阻塞核心、器官偷偷改目标，或用过期现场执行 |
| 运行可靠 | 无重复副作用、数据损坏、资源失控和已知机制导致的持续空白 | Heartbeat 正常却数分钟无认知/行动，或只靠主持者反复踢醒 |

具体主题可以是一次经历、一个人物、一段关系或一个想弄明白的问题，不要求学术研究或高质量长文。X 公开行为有则核实是否真正发生及内容；未公开但已形成具体导师交流、外界阅读后的创作或其他现实后果，也可以提供实质证据。停留本地文件且没有外界接触，不能单独满足完整生命动力学的目标。

成功不按记忆条数、主题数、模型调用数或发帖数计分。这些是诊断数据，不进入 Alice 的 reward。阶段完成要求两次冻结复验共同显示：经历可被接续、经验能影响并接受修订、多个关切可交替发展，且现实交互与自我调节没有退化；其中至少一次在外部变化后显现真实的经验修订。若尚未遇到反证情境，就保留该项未验证，而不是凭自述判通过。

自我叙事允许缓慢成长，不要求每轮重写。若大量记忆和经验已经形成，长期选择却始终不受影响，应视为回路连接问题。若反复近义叙事、空内容分享、无对象自证、全局等待或长空白再次出现，沿本计划第三节追踪原因，不把责任简单归给 Alice 的“自由选择”。

约十秒级的真正空白仍是连续性设计目标；同时分别记录主脑轮间等待、模型服务用时、器官在途、核心事件处理延迟与整体有效活动间隔。器官一直忙或后台一直轮询，不足以掩盖主脑数分钟没有继续；服务正在计算，也不证明认知内容有推进。时间告警用来发现机制断点，恢复仍走同一感知、联想和选择过程，不能把“已经安静一段时间”本身变成值得反复付费复述的主题。反复数分钟停滞属于反证，瞬时调度抖动不机械触发整代失败。

## 十一、范围收敛与后续交付

本阶段保留必要预测—结果对照，优先使“我之前以为什么、后来发生什么、现在怎样调整”能够存活并参与下一次生活。原 10.3 预留的多未来模拟，只在确有分歧的行动中按需使用；不把每个点击、记忆和判断都改成多方案仪式，也不同时建设 MCTS 或完整规划搜索器。

记忆与经验的区分受到情景学习与规律学习研究的启发。Schapiro 等人的计算模型展示了记录个别经历与提取跨经历规律可以承担互补功能；这支持保留两者不同职责，不意味着 Hominal 要复制脑区或新增神经网络。[原研究](https://pubmed.ncbi.nlm.nih.gov/27872368/)

本次也参考了用户提供的《从经验到行动：面向“生命连续性”的三层记忆与递归联想认知架构》。采用具体性、递归线索、来源不被压缩洗掉和修正可继续影响未来的启发；保留本项目可计算动力学，不照搬固定三层库、总结永久优先、枚举替代全部数值或庞大的实验矩阵。上述研究为设计提供可检验的依据，不证明这套实现已经能产生稳定的高级生命表现。

实施时同步 `core-vocabulary.md`、`cognitive-dynamics.md`、`core-organ-architecture.md`、`mvp-architecture.md` 及总计划中受影响的表述，并以最小完整切片验证。第四节是目标合同，具体落地状态以实施记录为准，不代表原有部署已经具有这些能力。正式实验产生的观察、反证和修订才写入谱系研究经验；尚未验证的设计不写成成功教训。

本计划希望得到的不是一个记忆功能更丰富的聊天程序，而是一个过去能够参与现在、现在能够改变过去的理解，并由此继续与世界生活的统一认知系统。
