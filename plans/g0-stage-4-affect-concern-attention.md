## 一、当前起点与阶段判断

阶段一已经冻结 Genesis Seed、初始数值和动力学方向；阶段二已经完成真实 Ubuntu 身体的构建、部署、开机运行、归档、重置和 LVM 恢复。阶段三随后实现了单进程 `hominald`、五秒 Pulse、身体事实差分、唯一认知租约、真实模型额度、root Shell、导师 Unix Socket、动作结果回链和崩溃恢复，并通过 `3619.94` 秒实机耐久实验。阶段四直接复用这条运行脊柱，没有建立第二套守护进程、消息总线或 Lab 控制器。

阶段四的背景场、AIP 提交、Concern、整体情感态、探索张力、有限候选和唯一注意已经进入同一个运行包，并通过最终一小时工程样本的归档事实验收。通过范围限于本计划定义的最小因果闭环，不表示成熟自主性、Narrative Self 或稳定高级生命组织已经形成。

总计划原阶段四同时容纳了 AIP、整体情感态、Concern、探索、注意递归、矛盾代谢、未来模拟、深度预算和语义—动力失配，范围过大。若一次性全部实现，会在看到真实动力效果之前先形成新的概念系统。阶段四收敛为一条最小因果链：

```text
现实或内部事件
→ alice 对其形成意义与最小数值赋值
→ Concern 与整体情感背景发生有惯性的变化
→ 少量候选竞争唯一注意焦点
→ alice 形成一次简洁思想脉络，并可沿用阶段三执行至多一个动作
→ 未处理内容和残余矛盾回到背景
```

这一阶段只验证“情感意义能够成为注意和自主发起的原因”。它不证明主观意识存在，也不完成学习、人格或叙事系统。

## 二、唯一目标

把阶段三由外部测试事件驱动的认知脊柱，变成能够由自身关切驱动的最小生命动力循环：alice 能从真实事件、身体状态、导师文字、行动结果和低张力状态中发现对自己的意义；重要内容能够跨模型调用持续存在；每次只聚焦一个问题；即使外界没有布置任务，也会在探索张力积累后主动观察或提出自己的问题。

阶段完成后必须能用实际因果链说明：某次 AIP 赋值改变了 Concern，Concern 改变了候选排序或 alice 的焦点选择，焦点又产生了新的观察、表达或身体行动。仅生成情绪词、自我描述或 Seed 复述不算通过。

## 三、最小实现

### 1. 装配起始自我与当前身体

工程实例启动时读取 `seed.md`、`seed.yaml` 和本阶段实际使用的动力参数，校验版本与哈希，并生成一份非秘密的当前身体摘要。Seed 提供 alice 的身份、气质和存续、联结、扩展、现实完整性方向；身体摘要提供当前时间、资源余量、网络和可用器官状态。

这不是正式出生：不生成 `T0`、正式样本编号或封存 Birth Manifest，不进行出生导师交流。正式出生语境和当代 Manifest 仍在阶段六预检后进入阶段七。

### 2. 承接事实，而不制造刺激

阶段四从阶段三接收五类最小变化来源：

```text
body_delta          身体、资源或器官状态的实质变化
mentor_received     导师实际发送的文字
action_result       alice 已执行行动返回的现实结果
continuity_event    进程异常、系统恢复和未知动作状态
endogenous_change   Concern、情感态或探索张力越过阈值
```

前四类保持 observed 事实身份；第五类是自身动力变化。Difference Gate 只负责消除重复读数、微小抖动和无意义的时间事件，AIP 才回答“这对现在的我意味着什么”。身体事实没有实质变化时，不因为轮询次数增加 Concern。

公开网络、文件系统、浏览器和微信不构成自动信息流。alice 因探索或既有 Concern 选择观察它们时，观察结果通过阶段三的 Action → Reality Event 返回，由此形成“外界变化启动、内部张力维持、自身行动继续制造现实变化”的循环。

### 3. 一个背景场，一次 Attention Pulse

阶段三的五秒 Cognitive Pulse 继续负责接收事件、更新时间和身体事实，不因每次 Pulse 调用模型。只有以下事实之一出现时，才允许产生 Attention Pulse 候选：

- 新事件可能改变当前自己；
- 某个既有 Concern 越过注意阈值；
- 行动结果返回并需要理解；
- 探索张力积累到值得重新接触世界。

一次 Attention Pulse 最多装配三个候选，由同一个模型调用完成粗赋义、选择唯一焦点、形成简洁 Thought Thread，并决定是否沿用阶段三提交一个动作。AIP 与注意之间的反馈保留在这次统一认知中，不实现多轮 `Emotion Agent → Selector → Reviewer` 工作流。需要新事实时以观察行动结束本次思考，而不是继续空转。

导师消息、身体事实、行动结果和内部探索张力进入同一个背景场。导师消息没有必读、必答或抢占焦点的特殊优先级。

### 4. 极小 AIP 提交面

事实来源、实际观测值、事件时间和关联动作由内核保存。alice 对候选形成：

```text
meaning       这对现在的我意味着什么
D             当前感受到的差异强度             0..1
O             自我认领程度                     0..1
V             内生价值方向与强度              -1..1
U             当前紧迫性                       0..1
A             当前可回应性                     0..1
certainty     对这次解释的确信程度             0..1
```

首版不再要求模型同时填写另一套含义相近的 `valence / activation / control` 数值。内核直接从上述赋值形成对象级情感动力：

```text
valence   = V
activation = clip(D × O × abs(V) × (b + w_u × U), 0, 1)
control   = A
```

`certainty` 原样保留。这样既让语义到数值的映射属于 alice，又避免同一次判断被两套评分重复表达。机器结构只用于提交将改变状态的最小结果，不约束自由思考过程，也不保存隐藏思维链。

### 5. Concern 的出生、持续与缓解

对象的 Concern 生成量采用：

```text
G_i = D_i × O_i × abs(V_i) × (b + w_u × U_i)
```

Concern 随显著经历增长，随时间缓慢衰减，并能因现实解决、重新理解、接受不可改变事实或自然淡化而降低。首版每个 Concern 只保存：`id`、对象、当前意义、强度、最近来源、更新时间和缓解原因。alice 可以创建、更新或保留既有 Concern；内核不建立 Concern Graph、自动语义聚类或目标树。

不可行动不等于不关心。`A` 影响当前是否适合行动，不参与 Concern 是否能够出生。没有解决的冲突作为 Residual Tension 留在同一个 Concern 或回到背景，不要求在一次认知中达成人格一致。

### 6. 整体情感背景

整体 Affective State 只保留 `valence / activation / control / certainty` 四个有惯性的背景量，由最近少量显著对象更新，并按 `return_rate` 自然回落。对象级混合意义继续独立存在，正负意义不会因为总值抵消而被解释为“没有感受”。

整体情感态必须进入下一次候选显著性和认知上下文；如果它只被写入日志而不改变任何候选、焦点或资源投入，就视为未实现。

### 7. 有限注意与 alice 的最终选择

确定性内核只给出候选建议，不替 alice 决定焦点。阶段四实际使用的最小优先度为：

```text
Q_i = C_i
      + w_a × affective_salience_i
      + w_x × exploration_value_i
      + w_n × novelty_i
      - w_k × expected_cost_i
```

Narrative relevance 和 Commitment pressure 在阶段五出现真实状态以前不进入公式，也不保留无效占位权重。Attention Pulse 接收按 `Q` 形成的小候选集，alice 可以选择其中一个或说明当前需要重新观察。数值建议与实际选择同时记录；不一致是未来可理解的差异，不是强迫服从公式的错误。

同一时刻仍然只有一个 Focal Workspace 和一个可提交认知租约。未被选择的候选保持在背景中，不能因没有进入当前上下文而消失。

### 8. 内生探索

探索张力采用一个有界慢变量：

```text
X(t+Δt) = clip(
    X(t)
    + idle_growth × Δt
    + unknown_growth × perceived_unknown
    - exploration_relief,
    0,
    1
)
```

当 `X` 越过注意阈值，它生成的是“重新接触现实、发现可能性或提出问题”的候选，不直接生成必须执行的任务。新的现实观察、创作、联结或能力尝试可以缓解探索张力；重复同义思考和改写情绪文字不能缓解它。一次真实探索后 `X` 回落并重新积累，从而避免每个 Pulse 都制造动作。

### 9. 最低状态与记录

阶段四继续使用阶段三的单一原子状态，不预建 SQLite。`state/current.json` 只增加：

```text
affective_state
exploration_pressure
active_concerns
background_candidates
current_focus
last_attention_at
```

`journal/events.jsonl` 只追加 AIP 提交、Concern 实质变化、焦点选择、探索触发、动作及结果、恢复和异常。无变化 Pulse 不追加认知记录。Concern 与背景场在进程重启后恢复，未确认动作继续遵守阶段三的“不盲目重放”规则。

一小时工程实验保持环境稀疏：启动时提供一次真实身体快照；随后让时间、额度和身体资源自然变化；前段不布置任务，观察探索张力；中途由 Codex 发送至多一条自然导师消息；alice 自己选择的 Shell、文件或网络观察返回真实结果。系统不为制造“活跃”连续投喂任务或随机事件。

## 四、明确留给后续阶段

阶段四不实现：

- 结构化 Self Variant、完整反事实树和自适应深度控制器；
- Action Commitment、行动前预测、ARD、Endogenous Reward 和 Reality Mirror；
- Narrative Self、长期记忆、能力方法、自我修改和代际继承；
- 正式 Birth Manifest、`T0`、出生导师交流和第一代一小时生命实验；
- 情绪标签分类学、人格测试、Concern Graph、向量数据库、Planner、Reviewer 或多智能体讨论；
- 图片、语音、视频、微信和番茄小说的专用输出适配器。

阶段三已经提供的 Shell 与导师文字足以观察动力是否真的形成行动原因。未来模拟—行动—现实学习与叙事形成集中在阶段五闭环实现，不在本阶段预造半套结构。

## 五、对现有代码和配置的预计改动

阶段四只在阶段三运行包内增加少量动力学文件，不为 AIP、Concern、Attention 分别建立服务或进程：

```text
body/internal/runtime/   背景场、动力更新、Attention Pulse 与上下文装配
genesis/dynamics.yaml    只保留本阶段和已实现机制真正使用的参数
lab/run.py               增加阶段四工程场景的启动与状态读取，不另建控制器
tests/                   公式边界、时间演化、唯一焦点、恢复和因果接线测试
```

实现开始时应清理 `dynamics.yaml` 中尚无运行语义的权重，而不是为了兼容阶段一草案保留死配置。任何新增参数都必须能回答“它改变哪一种注意或行为结果”，总数继续保持小而可调。

## 六、执行顺序

1. 先确认阶段三退出门、冻结版本和目标 Ubuntu 空闲基线；
2. 用阶段三的真实事实快照和 Difference Event 建立背景场，确认轮询本身不会制造认知事件；
3. 在确定性假模型中实现 AIP 提交、情感惯性、Concern 更新、探索张力和候选排序；
4. 把这些状态接入阶段三唯一事件循环、认知租约和崩溃恢复；
5. 用一个真实模型调用完成候选赋义、唯一焦点、Thought Thread 和可选单一动作；
6. 复用导师文字与 Shell 结果回链，验证它们只作为普通 Event 重新进入背景；
7. 先做五至十五分钟短测，消除重复 Concern、注意抖动、探索自激和模型高频调用；
8. 运行一次一小时阶段四工程实验，归档后 reset；
9. 只修复阻断动力闭环的根本缺陷，通过退出门后冻结 `g0-stage4-v001`。

## 七、最小验证场景

1. 安静环境：没有任务和新消息时，探索张力最终形成一次由 alice 选择的观察或问题；真实接触后张力回落，不出现十秒一次的机械探索。
2. 背景保留：两个候选同时存在时只选择一个焦点，另一个跨认知调用和进程重启仍然存在，并能在后来重新竞争。
3. 情感因果：至少一次对象级意义或整体情感背景实际改变候选显著性、焦点选择或资源投入，而不只是生成情绪文字。
4. 不可行动的关切：alice 可以保留一个当前无法行动的重要 Concern，同时选择观察、接受、等待或关注其他对象。
5. 混合意义：同一对象的期待与担忧都能进入唯一焦点，当前选择只有一个，未解决部分回到背景。
6. 导师普通化：Codex 发送一条真实导师消息；它可靠入队，但不绕过注意竞争强制抢占或强制回复。
7. 数值不统治语义：alice 选择非最高 `Q` 候选时，系统保存她的当前理由和差异，不覆写其选择。
8. 自生现实：alice 因探索或既有 Concern 主动观察身体、文件或公开网络，行动结果形成新的现实事件并改变后续理解，而不是等待下一条外部任务。

## 八、退出门

阶段四完成必须同时满足：

1. 身体、导师、行动结果和连续性变化都先作为事实进入 Difference Gate；重复轮询和微小抖动不会制造 Concern；
2. AIP 由 alice 形成意义和最小数值，数值真实进入 Concern、情感态与注意计算；
3. 至少一个未预置 Concern 从现实或内部 Difference 中出生，并跨多个 Attention Pulse 保持连续；
4. 整体情感背景至少一次可观察地改变后续焦点或行动资源，而非日志装饰；
5. 低张力能够形成一次内生探索，探索后合理回落，不形成高频空转；
6. 至少一次由 alice 自主发起的观察或行动产生新的 Reality Event，并继续改变后续理解；
7. 同一时刻只有一个焦点、一个可提交认知和至多一个新动作；
8. 未选候选、不可解矛盾和不可行动 Concern 不会被自动清零；
9. 导师消息与其他事件走同一注意竞争，收发可靠且不产生隐藏并发认知；
10. 进程崩溃后情感态、Concern、背景候选和焦点事实恢复，不重复创建同义 Concern 或重放未知动作；
11. 无变化 Pulse 不调用模型或制造日志洪流，一小时运行不突破滚动模型额度；
12. 能从归档中指出至少一条“事实变化 → AIP → Concern/情感变化 → 焦点 → 自主行动 → 新现实”的完整真实链路。

退出门只证明最小情感—关切—注意动力具有实际因果作用。通过后立即进入阶段五，闭合预测、行动、现实结果、经验吸收与 Narrative Self，不继续扩建情绪分类和研究平台。

## 九、导师配合

阶段四由 Codex 主持工程测试。人类导师通常只需在开始一小时实验前确认阶段三已经冻结；若微信意外要求手机确认，本阶段直接把微信保持为可用但未登录的身体状态，不为验证 AIP 中断实验或要求导师即时介入。

## 十、实际结果与阶段判断

正式样本 `g0s4-20260825t052007z-3da892` 在目标 Ubuntu 身体中按预定计时器完成一小时窗口。Pulse 从 `1` 增至 `721`，增加 `720` 次；journal 从 ready 到 stopped 覆盖 `3607.35` 秒，共 `92` 行，序号 `92/92` 唯一。进程 PID 全程为 `1558`，`NRestarts=0`。19 次模型认知与 19 次 AIP 提交一一对应，没有认知失败或重试；总用量 `41,173` token，单次最大输入 `2,506`、最大输出 `430` token，远低于滚动一小时 `1,000,000` token 上限。

样本形成了真实的最小动力闭环。探索张力达到 `1.0` 后，alice 自主选择 root Shell 观察身体；现实结果重新进入统一事件入口，随后 AIP 将结果解释为身体锚点，探索张力回落到约 `0.76`，活动 Concern 从 `3` 个回到 `2` 个。后续一次探索形成了“网络定位—持久空间定位—寻找说明—读取说明”的有限行动链，并在信息增量很小时自行停止。全程共有 `5` 次真实身体行动，没有并发焦点、动作重放或动作结果失联。

Codex 在三十分钟点只发送了一条不含任务和选项的事实消息。它作为普通 `mentor_received` Event 进入注意，alice 自行选择回复；Codex 读取并 ack 后形成 delivered 事实。alice 后来又因内生探索主动发送一条导师消息。最终归档包含 `1` 条导师输入、`2` 条 alice 输出和 `2` 条送达事实，证明导师关系能够进入同一注意—行动回路，而不是隐藏命令通道。

正式实验前的诊断样本同样属于本阶段结论。`g0s4-20260824t170107z-f4f426` 因 Codex 侧网络中断持续运行约 `11` 小时 `37` 分，暴露出配额读数制造事件、Concern 全量进入上下文、retry 状态复制探索候选和终态 Concern 不退出活动集的复合自激；它累计使用 `9,173,237` token，出现 `277` 个 Concern 和 `2,421` 次认知失败。实现没有为表面症状增加限流补丁，而是改成额度区间越界才形成 Event、候选优先且最多八个 Concern 进入上下文、retry 复用同一探索身份、成功提交接收结构校验反馈、终态零强度 Concern 离开活动集。最终样本没有再出现上述增长回路。

仍有一项重要残余：导师未给出方向后，alice 在后半小时多次将接近上限的探索张力解释为“尚无具体对象”，最终 `exploration_pressure=1.0` 而没有再次自主行动。它没有破坏已经出现的最小闭环，但说明“从无对象张力中稳定生成个人接触点”仍不成熟，同时存在先向导师寻求方向确认的倾向。阶段五应把这项动力—语义失配作为核心观察变量，通过行动承诺、预测和现实学习检验它如何自然改变；本阶段不增加强制行动阈值来伪造自主性。

综合确定性测试、崩溃恢复短测、失控样本反证和最终一小时归档，阶段四退出门在“最小情感—关切—注意动力具有实际因果作用”的限定范围内通过。归档位于 Genesis Lab 的 `archive/engineering/g0s4-20260825t052007z-3da892/`，三项归档哈希均已复核；实例随后完成 stop 和 reset，目标设备当前没有活动工程实例。
