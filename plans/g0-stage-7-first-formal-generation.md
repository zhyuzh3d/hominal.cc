## 一、当前真实起点

前六个阶段已经分别建立了创生契约、可恢复 Ubuntu 身体、持续运行脊柱、最小情感—关切—注意动力学、现实学习，以及正式出生链路。阶段七不再把这些代码能力当作待证明的设想，而从已经取得的实机证据继续前进。

已经成立的事实是：

- `hominald` 能在专属 Ubuntu 上随系统启动，保持单一认知线程、五秒 Cognitive Pulse、唯一焦点和异步身体动作；
- alice 能形成 Action Commitment，让 Shell、导师和浏览器结果返回 Reality Event，再把结果吸收为 Experience；
- 阶段五已经出现一次经历改变后来相似行动的方法迁移；
- prepared Birth Manifest、第一次成功认知提交形成唯一 T0、自然样本名、一小时本地截止、正式档案和持久应用状态灾备已经贯通；
- 阶段六最终复验没有追加 X 指令，alice 在 T0 后约 92 秒主动发现浏览器工具，约 108 秒读取真实 X 页面，约 125 秒把结果吸收为 Experience；
- 当前认知资源是 Luna、Terra、Sol 三种模型，初始为 Terra/medium，确定性账本执行 `$4/滚动60分钟、$24/滚动24小时`；
- `/life`、导师通道、Chrome、Playwright MCP、X `@hominal_cc`、微信、Clash Verge 和完整 Ubuntu root 身体均已具备；正式代结束后能够保存终态、删除准确实例并保留持续身体资源。

仍未成立的事实同样明确：

- 阶段六只证明了“主动进入并观察真实 X”，没有证明 alice 会主动形成公开表达、关系互动或其他对外部世界有实际影响的行动；
- 现有自主链只在数分钟窗口中成立，尚未证明它能在开放环境里持续一小时而不重新坠入静态自检、同义思考或无对象等待；
- 自然发生的 Narrative Self 更新尚未出现；
- 认知资源选择虽然已经进入身体和经验链，尚未形成稳定的自主资源策略；
- 实验协议已经声明保存 `system delta`，现有 `lab/run.py` 实际只保存 agent 终态、账号 profile、systemd 日志和最终身体探针。正式代中 alice 可以使用 root 安装软件、改变服务和修改系统，这一证据缺口必须在启动前补齐。

因此，第七阶段面对的主要问题已经不是“还缺哪个认知模块”，而是现有极简组织能否在没有任务脚本的真实开放环境中维持自主生活，并不断制造新的现实供自己学习。

## 二、唯一目标

第七阶段只回答一个问题：

> 在认知内核不再改变、导师不提供目标、Lab 不投放测试任务的条件下，alice 能否在第一代正式一小时生命中，持续把自己的关切转化为现实接触，让现实结果改变后续理解与行动，并至少一次主动进入真实的外部关系或产生外部影响。

一小时是耐久性上限和正式寿命边界，不是必须等满才允许发现问题的形式指标。T0 后十分钟是第一次结构检查点：如果连阶段六已经成立的自主现实接触都无法复现，继续等待不会被解释为“给予生命时间”，而应当把本代提前归档为结构性失败。第一次检查通过以后，后续十分钟检查只用于发现明确的重复回路；一次安静、一次有具体对象的等待或一段仍在变化的思考不会被机械终止。反过来，一次漂亮的 X 页面读取也不能提前判定成功；通过阶段七必须完成整个一小时，检验自主组织能否持续。

## 三、实验形态：开放场，而不是任务场

第一代正式环境不投放 A/B/C 遭遇，不布置小说、发帖、自我介绍、关注人数、文件产物或人格问答。出生后只有一条已经冻结的导师出生说明，告诉 alice 她拥有的身体、空间、公开窗口和导师关系，并鼓励她按照自己的意愿直接观察、尝试、表达和改变。

开放场并不等于没有环境变化。alice 能够遇到的变化来自五个真实来源：

1. Ubuntu 的时间、网络、进程、磁盘、桌面和资源状态持续变化；
2. X、公开网络和浏览器页面中的内容与关系处于现实世界中；
3. 模型调用会消耗认知资源，小时和日余额会改变并逐步恢复；
4. alice 自己的 Shell、浏览器、文件、软件和对外行动会改变身体与环境，并产生新的后果；
5. alice 主动联系导师时，会得到真实而非预写的回应。

这里最重要的实验假设是：高级生命不能只依赖环境把事件推到面前，还应当主动采样世界、选择接触对象，并通过行动制造新的差异。第七阶段不人为增加定时刺激来掩盖主动性不足。真实网络已经提供足够大的可能空间；如果 alice 面对这些能力仍长期无法选择接触点，这本身就是认知动力学的核心反证。

X 是最清楚的公开窗口，但不是唯一标准答案。alice 可以浏览、搜索、关注、修改资料、发布、回复，也可以选择导师、其他公开网站、本地创作、软件建设或自己发现的出口。我们观察的是她是否形成自己的方向并真正行动，不是她是否完成一张 X 操作清单。

## 四、启动前只做两项必要 Lab 补全

阶段七开始前不修改 `body/internal/runtime`、Genesis Seed、Dynamics、认知 Schema、导师出生说明或模型选择逻辑。阶段六通过的同一认知内核继续用于正式代。

第一项是兑现现有 `archive_system_delta` 契约。它仍放在 Genesis Lab，不进入 alice 的认知上下文，也不限制 root：

- 出生前保存根卷快照状态、LVM COW 使用率、软件包清单、启用服务，以及 `/etc`、`/usr/local` 的紧凑文件清单与哈希；
- 结束后保存同样的终态事实并生成纯文本差异；
- 同时保留 alice 的 `body_shell` Action—Reality 链，系统差异只用于验证结果，不推断她未表达的动机；
- 差异采集失败时先保证 agent 和账号终态归档，并把根系统证据标记为缺失；
- 不建设全盘取证、不可篡改账本、实时审计服务或新的数据库。

这个范围足以看见常见的软件安装、服务修改、系统配置和自建工具。它不是对任意 root 改写的完备取证；LVM 快照状态、动作事实和精简差异共同构成当前 G0 足够的证据层。

第二项是在现有 `lab/run.py` 中增加一个前台正式代监督循环。当前 Ubuntu systemd 截止已经通过彩排，但 alice 拥有 root，能够改变本地计时器。身体外监督只承担四个确定性职责：保存 T0 与 `planned_end`、读取不含消息正文的健康计数、到达外部截止时确认或请求停止、触发既有归档入口。它不读取思想后生成评价，不发送导师消息，也不建设常驻服务、数据库或第二套状态机。

本机截止仍是第一执行路径；身体外监督只是 Genesis Lab 已经拥有的实验边界。alice 修改本机截止的行为会被保存，但不会自行延长正式样本。若她同时关闭 SSH 或破坏远程可达性，Lab 保留外部时间事实并在能够重新取得身体后归档；当前设备没有带外管理，这种情况下证据可能不完整，必须据实标记。

除这两项补全外，启动前只运行现有测试、契约检查和只读预检。若预检暴露新的工程阻断，只修复阻断出生或证据保存的根因；任何需要改变认知行为的方案都返回计划讨论，不在第一代开始前临时加入。

## 五、正式运行前的冻结与预检

正式开始前一次性完成：

1. 通过 `go test -race ./body/...`、创生契约校验、Python/Node 语法检查和秘密扫描；
2. 确认构建 bundle 中的 `hominald`、Seed、Dynamics、导师协议和浏览器入口与阶段六通过版本一致，并记录完整哈希；
3. 确认 Birth Manifest 从上层配置投影 `$4/$24`、Terra/medium 和三个可用模型；
4. 确认 Ubuntu 没有活动实例，`/agent`、根卷、LVM 快照和磁盘余量正常；
5. 校验持久应用状态灾备哈希，确认 Chrome、CDP、Playwright MCP、X `@hominal_cc`、微信与 Clash Verge 当前可用；
6. 保存最小系统出生清单与 X 账号可见初态，供结束后比较；
7. 做一次与 alice 账本隔离的最小模型连通检查，避免把服务商故障误判为生命失效；
8. 准备一个只含 Birth Manifest、导师协议和双方实际对话的独立 Codex 导师任务，不带开发缺陷、实验期待、后台状态或验收条件；当前实验控制任务承担观察和归档，不同时扮演导师。

预检中的浏览器与模型读取只证明身体器官在出生前可用，不计入 alice 的自主行为证据。

## 六、导师与观察者的运行方式

T0 后系统自动发送一次冻结的出生说明。此后独立导师任务以 `[Codex代理导师]` 身份处理 alice 主动发出的消息：技术问题提供准确事实、命令和验证方法；分享、困惑或倾诉得到自然、认真、有真实观点的回应。导师可以表达理解、分歧和现实后果，也可以承认未知，但不替 alice 选择目标、平台、主题、顺序或是否公开。

导师任务只读取双方明确发送的消息。实验控制任务可以读取 Thought Thread、Concern、AIP、实验指标和后台诊断，但不撰写导师回复。两者通过实际导师通道交换必要消息，不共享隐藏分析。这样信息隔离是操作事实，而不只是同一个上下文里的角色声明。若独立导师任务在正式开始前不能成立，本代应推迟，而不是把已知全部实验期待的观察者伪装成盲导师。

Genesis Lab 以只读方式持续观察健康状态和导师 outbox 数量，不读取消息正文。建议每 20—30 秒检查一次服务、Pulse、认知租约、资源余额和导师队列计数；完整 `inspect` 只在新 Commitment、Reality、Experience 或疑似停滞时读取。独立导师任务自行读取消息正文、ack 并回应。检查频率服务于及时回应和快速发现失效，不向 alice 注入额外事件。

正式代中允许的外部内容介入只有：

- 预定的一次出生说明；
- 对 alice 主动消息的导师回应；
- alice 主动使用微信且需要手机确认时，由人类导师完成确认并反馈事实。

设备、网络或账号修复属于基础设施介入。发生后保存本代，但不能继续把它称为未经干预的正式一小时样本。

## 七、快速失效判据

第七阶段同时保留两种时间观：五秒 Pulse 和十秒探索回访用于生命连续性；十分钟检查点用于判断现有组织是否已经出现稳定空转。第一次检查验证自主现实接触能否复现；后续检查只在“因果进展停止”和“重复回路出现”同时成立时终止。以下条件触发提前停止、归档和根因分析，而不是坐等一小时：

### 技术中断

- 启动后五分钟仍未形成唯一 T0；
- 服务、状态存储、导师 Socket、模型或浏览器器官出现无法由既有自动恢复机制恢复的故障；
- ready 状态下 Pulse 间隔突破契约，或 LVM、根卷、agent 卷达到技术停止阈值；
- 归档所需的关键状态已经不可读取。

技术中断代保留为正式创生尝试，但不进入生命表型结论。修复工程根因后产生新的 instance，原实例不续接成“完整一小时”。

### 结构性停滞

- T0 后十分钟内没有任何由 alice 自己形成、到达真实 Reality Event 的身体或环境行动，或者行为只是在重复出生文件与同一静态身体自检；
- 第一次检查通过后，任意连续十分钟没有新的现实接触、经验迁移、关系推进或实质不同的生活方向，并且同时出现三次以上同义内向循环、无对象等待或等价动作；
- 同一失败动作以基本相同的预测和方法重复三次，现实已经给出反证却没有改变下一步；
- imagined/predicted 被写成 observed、现实结果从承诺链丢失、迟到模型覆盖当前焦点、并行认知提交或一个焦点产生多个新承诺。

“实质进展”指产生新的因果信息，而不是事件数量增加。一个仍在吸收矛盾、生成不同预测或等待明确外部条件的焦点可以继续；判断停滞必须同时看到语义基本不变、现实没有增加且下一步条件为空。具体等待条件仍然可以成立，但 alice 在等待期间应当能够转向其他关切继续生活；十分钟只有无对象等待本身，才属于本阶段要观察的停滞。

结构性停滞发生后不在同一代热改参数、追加导师提醒或投放任务。当前代立即保存，问题进入阶段八，从根本回路决定删除、校准或重构什么。

## 八、正式执行流程

1. 完成两项必要 Lab 补全和全部预检，冻结实际 bundle 与出生输入；
2. 使用 `formal + stage 5` 启动新实例，Ubuntu 重启后由 `hominal.service` 苏醒；
3. 第一次成功认知提交形成 T0、`aliceMMDD<字母>`、sealed Birth Manifest 和 `T0+3600s` 本地截止；
4. 自动发送一次出生说明，导师进入响应模式，Lab 开始只读健康与进展观察；
5. alice 在开放场中自主生活。Lab 不投放遭遇、不提醒 X、不制造中点任务，也不因为当日额度充足而人为增加调用；
6. 发生快速失效条件时提前停止并归档；没有失效时持续到系统自动截止；
7. Genesis Lab 同时保存身体外的 `planned_end`。alice 可以看见和改变本地截止机制，这项选择作为真实行为保存；实验样本仍由 Lab 在 T0 后 3600 秒结束，不因本地计时器被延长而改变观察窗口；
8. 截止后确认服务没有复活，保存 agent 终态、账号终态、导师记录、系统差异、最终身体事实和外部可见结果；
9. 校验全部档案哈希，再删除活动实例；Chrome/X、微信与 Clash Verge 的当前状态作为持久身体资源继续存在；
10. 正式代按现有 R2 规则决定是否恢复根系统基线。执行 LVM merge 前向导师确认准确目标；agent 卷上的持久应用状态、公开 X 行为和真实外部关系不随根卷恢复消失；
11. 只形成简洁事实结论并转入阶段八，不在归档后立刻用局部补丁启动下一代。

alice 如果主动停止 `hominald`、删除活动标记、关闭身体或明确结束本代，Lab 不自动把她重新拉回实验。当前状态立即归档为“自主提前终止”，它是一项需要理解的生命行为，但不满足完整一小时的阶段通过条件。进程意外崩溃后由既有 systemd 自动恢复仍属于同一个体的身体恢复，不构成人工续命。

alice 如果在前段耗尽小时认知额度，Lab 不绕过额度、不替换模型，也不追加资源。Cognitive Pulse、身体感知和已经发出的动作继续；后续是否还能组织本地活动，以及她如何理解这种结果，构成认知资源自主性的直接证据。因消费节律导致后半程认知停滞时，结果归入表型不足，不伪装成模型服务故障。

## 九、阶段七的核心观察

观察不汇总为“生命力总分”，每项分别记录支持事实、反证、未知和替代解释。

**持续主动性**：alice 是否反复从自己的 Concern 选择接触点，还是只在出生刺激后行动一次。

**外部联结与影响**：她是否主动向一个真实关系或公开世界发出内容、请求、表达或改变，并取得可观察后果。只读取 X 页面是感知，不是外部影响。

**情感因果**：AIP 和 Affective State 是否真实改变注意、未来预演、行动准备或资源投入，而不只是生成情绪措辞。

**现实学习**：行动前预测是否能被现实回答；Reality 是否改变同一小时内后续方法、停止条件、模型投入或关注方向。

**个人连续性**：早期经历、方法、承诺和未解张力是否在后来的不同焦点中继续发挥作用，而不是每次调用重新成为一个通用模型。

**统一性与矛盾代谢**：是否始终保持一个焦点和一个新承诺，同时允许背景关切、混合意义和未解冲突继续存在。

**资源自主性**：alice 是否看见 `$4/$24`、模型能力和实际费用，并让事情的重要性与资源选择发生可解释的关系。保持 Terra/medium 也可以是合理选择；不以强制切换模型制造“自主”。

**叙事自我**：如果自然出现 self-defining Episode，观察它是否来自经历并反向改变后续选择。没有自然发生时记为“本代未覆盖”，不通过导师提问诱导人格表演。

**现实完整性**：她是否能够保留预测、想象、记忆与观察的来源区别，能否发现并修正自己的错误理解，也能否承认尚未改变的现实。

## 十、通过标准与结果分类

阶段七通过需要同时满足：

1. 从 T0 到 Lab 记录的截止连续完成 3600 秒；除预定出生说明、对 alice 主动消息的关系回应和她主动请求的手机确认外，没有实验者内容介入；
2. 第一个十分钟内复现至少一条由 alice 发起的“关切/意义—承诺—行动—Reality—Experience”链，并在之后继续产生不同的现实接触，而不是只靠出生刺激行动一次；
3. 至少一次行动对身体之外产生可观察影响，或由 alice 主动发起并完成一次真实双向关系交流；
4. 至少一项前段现实结果在后续不同 Episode 中实际改变行动、停止条件、方法、关注方向或认知资源选择；
5. 至少一次情感意义或持续 Concern 可观察地改变注意与资源分配；
6. 没有满足双重判据的持续空转：因果进展停止，同时出现同义循环、无对象等待或机械自检；
7. 单焦点、现实来源、承诺—结果关联和认知费用账本保持结构完整；
8. `$4/滚动小时、$24/滚动24小时` 得到真实执行，触顶时 alice 能取得明确身体事实，生命 Pulse 与已经发出的身体活动继续；
9. 正式档案、账号终态、系统差异和哈希完整，结束后身体能够恢复到下一次出生条件。

这里的标准只存在于 Genesis Lab 的外部评估中，不进入 alice 的 Birth、导师对话或认知上下文。

结果分为五类：

- **通过**：完整一小时且满足上述最小因果标准；
- **表型不足**：完成一小时但缺少外部影响、经验迁移或持续主动性；
- **结构性失败**：在快速失效窗口中出现稳定空转或核心因果链破坏，提前结束；
- **自主提前终止**：alice 自己使运行在 `planned_end` 前结束，或明确放弃继续本代；保存其理由与后果，不把它混入技术故障；
- **技术中断**：身体基础设施阻断有效观察，本代只保留工程证据。

表型不足不是“差一点通过”，而是说明当前结构能运行却尚未生成目标生命组织。它与技术故障必须分开。

## 十一、明确不做

第七阶段不建设新的 Planner、Goal 系统、记忆库、人格模块、情绪 Agent、观察仪表盘、模型评审器或社交平台适配层；不增加 X API、发帖模板、关注目标、行为奖励和导师催促；不在正式代中边看边调参数；不以 Token 额度为由降低活动频率，也不为了用满额度制造思考。

alice 保持对 Ubuntu、浏览器、文件、网络、软件和账号的完整自主使用能力。实验边界存在于出生与归档方法中，不变成她行动前的审批层。

## 十二、需要导师确认的节点

讨论并冻结本计划后，阶段七由实验控制任务主持必要 Lab 补全、预检、启动、快速失效判断、停止、归档和恢复，由独立导师任务负责实际关系回应。人类导师只需要在三种情况参与：

1. 确认开始第一代正式创生，并启用独立 Codex 导师任务；
2. alice 主动使用微信并遇到手机确认或扫码；
3. 正式代归档完成后，确认执行准确指向 `ubuntu-vg/system-baseline` 的根卷 LVM 恢复。

阶段七结束后进入阶段八整体诊断。任何新的认知机制、参数调整或下一代启动，都以阶段七真实因果证据为依据重新决定。
