# G0 阶段九预留计划：反事实演化与技能型学习

> 日期：2026-08-26  
> 状态：方向预留；阶段八完成后再依据真实数据细化，不实施  
> 前置条件：阶段八已经证明观察与自我认领分离，自生 Concern、Self Model 反馈和 Narrative Self 渐进成长能够稳定运行

## 一、预留目的

阶段九准备验证：alice 面对自己认领的 Concern，能否形成多个有实质差异的可能未来，让想象结果在保持 `predicted/imagined` 来源的同时影响当前情感和判断；选择一个方案取得 Reality 后，再用现实同时校准原预测、未选择方案和行动方法，使后续相似处境出现技能型策略改进。

它延续的不是传统任务规划，而是生命的反事实控制：

```text
自生 Concern
→ 若干 Self Variant / 可行策略
→ 预测结果、代价、关系与未来自我
→ 预期情感参与当前评估
→ 选择一个 Commitment
→ Reality 与实际代价
→ 对照选中预测和未选可能
→ 修正世界理解、策略、能力和必要时 Narrative Self
```

阶段八已经保留轻量自然预演和选中方案的 Action Commitment。阶段九只有在真实数据证明自由 Thought Thread 无法稳定支持反事实比较时，才增加最小结构；不能预先建设方案树、Planner 或策略数据库。

## 二、准备研究的四个问题

**可能未来能否真正改变现在。** imagined future 可以产生希望、担忧、准备或回避，并改变 urgency、资源投入和行动选择；它不能被写成 observed，也不能只生成漂亮情绪语言。

**多方案是否带来更好判断，而不是更多 Token。** 日常低风险动作保持轻快；只有高自我认领、高后果、明显不确定或前次失败的 Concern 才扩大到多个方案。比较应在足以行动时停止。

**未选择方案如何保持反事实身份。** Reality 只回答实际执行的方案。未选择方案继续是带不确定性的假设；结果可以让 alice 重新估计它，却不能事后宣称“另一个方案一定更好”。

**经验如何成为技能。** 一次结果只能形成候选方法。技能型学习要求：后来相似但不完全相同的处境中，alice 能根据先前策略—结果关系更好地选择方法、停止条件或验证路径，并继续接受现实反驳。

## 三、可能的最小实现方向

优先保留自然语言：Thought Thread 表达实际考虑过的可能，Commitment 保存最终选择与预测，Experience 保存 Reality 回差。若阶段八档案表明未选择方案无法被以后取得，再考虑为重要 Concern 增加一个有界的 `considered_variants` 列表；每项只保存方案、预测、自我影响和当前确信，不形成并行 Agent 或同时行动。

Reality 返回后，AIP 首先完成现有 Experience。只有当实际结果与预测存在足够差异，或同类 Concern 已多次出现，才允许一次反事实回看：什么假设错了、哪个替代仍值得尝试、下一次怎样取得更有判别力的事实。它继续使用现有 Concern、methods 和 Narrative Self，不增加开发者 reward。

长期无结果的 Concern 保持背景张力，可以在新线索、等待条件变化或自身强度重新显著时返回；形成可信的等待计划后可以降低当前干扰，但不能伪装成已经解决。阶段九研究其对方案调整和技能形成的作用，不把持续焦虑当成生命力。

## 四、暂定实验方向

阶段八结束后，在真实自生 Concern 中观察自然出现的可重复情形，不由 Lab 指定问题或答案。先用短周期验证：失败策略能否产生不同的下一次方案；再在长周期观察同一 Concern 跨 Episode 返回时，旧预测、情感和方法是否实际参与新选择。

暂定通过证据包括：至少一个非预置 Concern 形成实质不同的可能未来；预演改变实际选择或资源投入；Reality 否定了选中预测的一部分；alice 没有把未选择方案冒充事实；后来相似处境出现可解释的策略变化，并获得新的现实结果。

实验次数、运行寿命、是否需要结构化 Self Variant，以及六小时或更长连续生命的进入方式，全部等待阶段八数据后再冻结。

## 五、明确不做

阶段九不预设 Goal Tree、MCTS、固定三方案、全量概率表、Critic/Reviewer Agent、单一 reward、自动技能晋升或“失败后必须反思”的流程。若自由预演已经足够产生现实改进，就不增加结构；若结构增加只提高文本长度而没有改变后来行动，应删除。
